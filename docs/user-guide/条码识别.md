# 条码识别

当前源码和开发版已提供条码识别；已安装版本的能力以对应发布包为准。入口位于左侧「工具 → 条码识别」。

## 选择图片

- 选择图片文件，或将一张图片拖入页面。
- 点击「剪贴板图片」，也可在页面空白处按 Ctrl+V。
- 点击「屏幕框选」，在鼠标所在屏幕拖动选择区域，松开后识别。Esc 或右键取消；超过一分钟自动取消。框选期间主窗口暂时隐藏。
- 在图片快速预览窗口的更多菜单中选择「识别条码」，转到主窗口查看结果。

支持 PNG、JPEG、WebP、GIF、BMP；动画图片只识别首帧。文件最大 32 MiB，图片最多 16,777,216 像素，单边最多 16,384 像素。屏幕截图会按连接屏幕数量和尺寸限制分辨率，远处的小条码建议使用原始图片识别。

## 查看结果

页面标题右侧集中放置选择图片、粘贴图片和屏幕框选。左侧为图片，右侧为结果；窄窗口自动上下排列。图片名称、尺寸和清空操作在同一行；识别状态显示在结果标题右侧，成功后只显示耗时；数量保留在结果标题旁。拖入图片时复用文件占用检查页的统一遮罩。图片底部可放大、缩小或恢复适应大小，右上角垃圾桶可清空图片和结果。

一张图片可显示多个条码，最多 64 个。多码时点击结果列表或图片中的轮廓选择条码，查看格式、旋转角度和内容；单码直接显示内容。二进制内容显示十六进制。点击「复制内容」复制当前结果。读取失败或取消新任务时保留上一份结果，直到成功读取新图片或主动清空。

HTTP/HTTPS 链接只在点击「打开链接」后交给系统浏览器；不会自动打开、请求或执行识别内容。包含用户名或密码的链接不提供打开按钮。

识别在后台运行，可随时取消；切换页面会取消当前工作。一次只识别一张图片，超过 15 秒会停止并提示缩小图片或框选区域。图片及识别内容不保存为历史记录，也不上传到服务器；解码引擎随应用提供，可离线使用。

## 已验证的格式

以下 17 类格式通过固定版本的独立上游图片样本核验，包括与预期内容的逐字比较：

| 类别 | 格式 |
| --- | --- |
| 二维码 | QR Code、Micro QR、Data Matrix、Aztec、PDF417 |
| 一维码 | Code 128、Code 39、Code 93、EAN-8、EAN-13、UPC-A、UPC-E、ITF、Codabar |
| GS1 DataBar | Omnidirectional、Limited、Expanded |

UPC-A 样本可能以带前导 0 的 EAN-13 类型和内容返回；UPC-E 可能返回展开后的 GTIN-13 内容。GS1 分隔符、中文和二进制内容按解码器返回值保留，不自动改写成商品信息或网址。引擎的其他格式尚未作为已验收范围公布。

旋转、缩小、低对比度、轻度模糊、局部遮挡和中文已有专项样本验证，不保证任何受损图片均能识别。未识别到结果时，无法仅凭图片判断是未知条码格式还是清晰度不足；页面会如实提示。图片类型不支持、损坏、超限、校验失败及读取错误分别提示。

实现、比较方法和复现入口见[条码识别设计与验收](../development/features/条码识别.md)。
