# 系统信息与磁盘告警

更新日期：2026-10-10。下文标注的代理检测、扫描停止、报告保留与连续列表规则适用于当前开发版；发布包版本见 [项目入口](../../README.md)。

## 代理与网站连通性

入口：**系统信息 → 代理**。首次进入自动查询公网出口并对比预置网站的直连与代理结果。网站包含 TikTok、X、Twitter 旧地址、Grok、Gemini、Instagram、ChatGPT、YouTube、Google、GitHub 等 20 项；X 与 Twitter 分开检测，并显示最终重定向地址。

在“自定义地址”输入完整 HTTP / HTTPS 网址或域名；未填写协议时使用 HTTPS，输入框下方显示请求地址。选择“直连与代理对比”“仅直连”或“仅代理”，点击“检测地址”。“检测列表”检测当前搜索筛选的预置网站，各行“检测”用于单站重测。自定义结果与预置列表使用相同表头、列宽和操作；自定义结果行重测原地址，修改输入后需点击“检测地址”才开始新地址检测。

检测使用 HEAD 请求查看 HTTP 状态与响应时间，最多跟随 5 次重定向，不下载页面正文。401、403、407、429、451 表示认证、访问或请求限制；404、405、5xx 等显示“已响应 · HTTP 错误”，不当作网络不通。网站拒绝 HEAD 时会说明原因。收到 HTTP 响应不能证明账号登录、视频播放或应用功能可用；代理拒绝建立 HTTPS 隧道时单独标注，不能误认为已到达网站。DNS、连接、TLS、超时和重定向失败各有说明。

结果显示本次使用的显式代理地址或直连方式。直连会绕过 HTTP / SOCKS 代理，仍可能经过 TUN / VPN，两个出口 IP 相同不一定是异常。代理优先采用进程中对应协议的 HTTP_PROXY / HTTPS_PROXY，再采用 ALL_PROXY，否则使用系统对起始网址解析出的第一个可识别代理；系统返回 DIRECT 时不强行回退到手动代理。跟随重定向沿用本次代理。不支持含用户名/密码的代理地址，会明确报告配置不受支持；不会静默去掉认证后尝试。

同一时间只运行一组检测，最多 4 项并发；代理解析最多 2 秒、连接最多 3 秒、单次网络请求最多 7 秒。点击“取消检测”会停止排队和正在运行的请求，保留已完成结果，可随时重新检测。检测期间仍可编辑地址及操作其他页面。查询参数仅用于本次请求，在地址预览、结果和诊断报告中隐藏，不写入应用日志；自定义地址不保存到设置。

实现与自动验证范围见[代理连通性测试记录](../history/projects/代理连通性测试实现记录.md)。公网服务是否可用取决于实际网络、代理和网站策略。

## 磁盘告警

入口：**系统维护 → 磁盘告警**。

- 开启“后台容量告警”后，即使关闭主窗口并留在托盘，也会按设定间隔采样本地固定 / 可移动磁盘。退出 One 后停止。
- 后台容量告警、概览和系统信息只采集容量与系统统计；进入写入活动页才收集进程。切换页面沿用同一监控进程，不重启容量告警；重新进入写入活动页先建立计数基线，累计从本次观察开始。
- 每个盘符单独启用规则，按**剩余百分比**或 **GB** 设置阈值。默认未启用任何规则，避免升级后直接弹出通知。
- 跨过阈值时显示系统通知及应用提示；同一次低容量状态不重复通知。恢复时有小幅缓冲区，避免在阈值附近反复告警。
- “写入活动”列出进程、PID、当前写入速率、连续活跃时间、本次观察累计及可用的文件路径，支持“全部 / 网络 / 文件 / 设备”页签。“仅持续写入”筛选当前类型连续活跃至少 6 秒的进程。更新保留展开状态和键盘焦点。
- 普通权限使用进程 **写入 I/O** 计数，包含文件、网络和设备操作，不能据此认定全部是磁盘写入。
- 点击“跟踪写入”启用实时内核 ETW 文件写入及 TCP/UDP 发送事件，并解析路径；已识别的命名管道等设备路径归入设备。需要管理员权限 / 系统跟踪权限；权限不足时继续提供容量及全部写入 I/O 监控，分类页签提示需要跟踪权限，不把普通进程 I/O 推断为文件写入。
- 文件跟踪是实时内存会话：不写 ETL、BIN 或持续增长的日志。记录有数量上限，只保留每个进程最主要的写入路径。部分已打开文件或未收到名称事件的路径可能无法解析；统计仍可显示。
- 主动开启的文件跟踪在离开页面后继续，直到点击“停止跟踪”或退出 One。关闭后台容量告警不代替停止主动跟踪。

监控停止或退出时关闭 One 自己的会话，不停止其他软件的跟踪会话。进程只用于查看和定位，不会自动结束进程。

ETW 的“全部”是所收集事件的字节总量，网络统计发送载荷，不是物理磁盘写入量；未解析的设备路径保留在全部中，不强行归类。不同采集方式的累计值不能直接比较。此版本在普通权限下验证了监控与权限提示；提权后的真实分类采集仍需单独验证。

## 自动扫描与后台清理

进入系统维护时自动扫描当前页签；切换启动项、注册表和磁盘清理页签会启动该页签的扫描。扫描期间可以切换页签 / 功能页，结果归属于发起任务的页签；重复请求合并为同一任务。

**网络端口**与**系统服务**位于系统分组的独立入口“端口服务”，系统维护保留启动项、注册表、磁盘清理和磁盘告警。搜索中的旧端口/服务命令也会进入新页面。首次打开其中一个页签时读取端口和服务快照；切换两个页签复用同一份结果，需要更新时点击“重新扫描”。

当前开发版提供“停止扫描”，只停止所在页签的扫描，不影响其他页签或已经确认的清理操作。停止后保留上次完整结果、所选项目和展开详情；未完成的扫描不会替换结果。每类仅保留最新一份完整报告，共最多三份，避免反复扫描积累候选文件清单。离开页面、隐藏或最小化窗口时暂停界面刷新，返回显示最新状态，后台任务仍按其设置运行。

当前开发版结果完整连续滚动，取消“显示更多”。方向键浏览、Home / End 到首尾、PageUp / PageDown 翻动视区，空格勾选、Enter 展开详情，Ctrl+A 选择当前筛选中可处理的项目。详情展开和所选项目在滚出视区后保留；切换功能页或隐藏窗口时回收列表节点，返回恢复位置。

确认弹窗可浏览全部所选目标，支持方向键与 Home / End；取消不会执行操作。超过 1,000 项的已确认选择按顺序分批处理，每批仍验证目标，并展示已完成数量；单项失败计入跳过，通信或任务错误时停止后续批次。不会因为列表只绘制当前视区而遗漏未显示的选择。

查询采用后台 Worker 和独立辅助进程。注册表检查与缓存遍历使用 Rust；缓存按 4 个工作线程扫描、8 个工作线程清理，最多扫描 200,000 个候选文件 / 类别，达到上限明确标注。清理报告只返回摘要，完整清单留在后台内存中，不建立额外磁盘索引。

清理仍须手动勾选并确认。注册表 / 启动项先备份，可在“操作记录”恢复；缓存及回收站不可撤销。缓存删除使用打开的文件句柄，验证大小、修改时间及真实路径；扫描后变化、占用或超出扫描根目录的文件跳过。分页文件由 Windows 设置管理，不直接删除；关闭休眠会影响快速启动。

## 系统信息

独立侧边栏入口，包含 12 个类别，按需读取、逐组呈现，缓存 5 分钟；刷新按钮仅刷新当前类别。筛选匹配设备名、字段名和字段值，导出按钮保存已经读取的类别为本地 JSON。

| 页签 | 详细内容 |
| --- | --- |
| 概览 | 计算机 / CPU / 内存 / 主板 / GPU / 卷 / Windows 摘要；实时 CPU 使用率、内存使用、运行时间 |
| 处理器 | 插槽、架构、核心 / 线程、地址位宽、报告频率、L2/L3 缓存、家族 / 步进、固件虚拟化及二级地址转换 |
| 内存 | 每条内存的厂商、型号、序列号、容量、速率、DDR 类型、插槽 / Bank、位宽、电压、Rank；阵列插槽及支持容量 |
| 主板与 BIOS | 主板 / 机箱 / 产品标识、BIOS 与 SMBIOS 版本、固件日期、EC 版本、UEFI / BIOS、安全启动、TPM |
| 显卡与显示器 | DXGI 64 位独立 / 共享显存、PCI 标识、GPU 驱动、当前分辨率 / 刷新率 / 色深 / 坐标、EDID 名称 / 序列号 / 生产日期、物理尺寸 |
| 存储 | 磁盘型号 / 序列号 / 固件 / 接口、SSD/HDD、健康状态、支持的可靠性计数器、扇区、分区 / GUID / 挂载点、卷与剩余容量 |
| 网络 | 物理 / 虚拟适配器、MAC、链路速率、驱动、IPv4/IPv6、DNS、网关、DHCP 租约、默认路由；可访问的当前 Wi-Fi 连接 |
| 蓝牙 | 无线电地址 / 制造商 / LMP 子版本、已配对 / 记住 / 连接设备、设备地址 / 类别及 PnP 驱动信息；不主动扫描附近设备 |
| 音频与设备 | 音频、USB、键盘 / 鼠标 / HID、设备标识 / 服务 / 错误及异常设备 |
| 电源与电池 | 交流供电、节能、电量、设计 / 满充容量、电压、充放电速率、循环次数、制造信息及电源计划 |
| 操作系统 | Windows 发行版本 / 完整内部版本、安装与启动时间、地区 / 时区 / 语言、物理 / 虚拟内存、分页文件、DEP、启动与 TPM |
| 驱动 | 设备类别、厂商 / 提供者、版本 / 日期、数字签名与签名者、INF、设备 ID；按设备展开 |

数据来自 Windows 实际提供的原生 API 与 CIM/WMI。部分 TPM、可靠性计数器、电源信息需额外权限；某些固件不报告温度、电池循环或详细传感器数据。未报告 / 未提供 / 权限不足会分别标识。CPU 报告频率是系统 / 固件数据，不等同于厂商标称睿频；旧 WMI 显存接口单独标识，准确显存优先查看 DXGI。没有加入第三方内核传感器驱动，因此不宣称覆盖 AIDA64/HWiNFO 的所有传感器、SMART 原始属性或压力测试。

## 调研依据

- [图吧工具箱官网](https://www.tbtool.cn/)定位为硬件检测 / 评分工具合集，并提供硬件检测 SDK。本版参考其硬件覆盖方向，将信息集中在 One 内展示；未捆绑 / 自动运行其中的工具。
- [Win32_PhysicalMemory](https://learn.microsoft.com/en-us/windows/win32/cimwin32prov/win32-physicalmemory)、[Win32_PnPEntity](https://learn.microsoft.com/en-us/windows/win32/cimwin32prov/win32-pnpentity)：内存及设备字段。
- [GetProcessIoCounters](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-getprocessiocounters)：进程全部 I/O 计数。
- [FileIo_ReadWrite](https://learn.microsoft.com/en-us/windows/win32/etw/fileio-readwrite)、[StartTrace](https://learn.microsoft.com/en-us/windows/win32/api/evntrace/nf-evntrace-starttracea)：实时文件写入及独立系统跟踪会话。
