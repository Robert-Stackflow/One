# AI 对话与快捷命令

侧边栏 **AI 对话** 包含“对话”“AI 服务”“指令”“设置”。“对话”页是固定双栏卡片：左侧搜索和切换历史对话，右侧查看消息、选择模型并继续追问。工具栏的 **打开 AI 对话** 可打开独立窗口；独立窗口的侧栏按钮会扩展窗口宽度来展示历史，不压窄原有消息区域。“设置”页可配置唤出独立窗口的快捷键。

在 **AI 服务** 中添加本机 Codex、Ollama、LM Studio 或 OpenAI 兼容服务，并设置默认服务。Codex 使用本机 Codex 可执行文件和设备码登录，模型列表从本机服务读取；其他服务按地址与密钥连接。新建服务时可直接用尚未保存的地址和密钥读取模型；长模型列表可在下拉菜单中输入文字筛选。对话输入区的模型按钮会展开按服务、模型分列的菜单。输入区还可以添加最多四张图片，或引用当前剪贴板的文字、图片；图片会作为消息内容发送给支持视觉输入的模型。指令页提供翻译、总结、改写、搜索及自定义提示词。

**文件搜索** 的 `ai` 快捷命令可在搜索窗口原地显示回复，并把本次问题与回复转为新对话继续追问。输入已启用的快捷命令触发词时，搜索窗口会提示按空格进入；扩展名模式可用 `.zip ` 或 `.zip|7z ` 筛选格式。搜索历史记录查询、所用命令及 AI 回复。搜索框为空时会显示“收藏”和“最近搜索”标签；可单独收藏或删除历史，也可清空历史。点击“收藏当前搜索”可保存普通搜索、快捷命令及已有的 AI 回复。搜索引擎支持建议词。其他内置快捷命令可在 **文件搜索 → 快捷命令** 中管理。

AI 对话和搜索历史保存在本机 One 配置目录。调用在线 AI 服务或网页搜索引擎时，会向所选服务发送输入；使用本机 Codex、Ollama 或 LM Studio 时，请按相应服务的运行与账户状态配置。
