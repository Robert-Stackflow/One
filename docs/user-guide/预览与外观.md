# One 0.12.1 预览、外观与取色

更新日期：2026-10-01。对应项目 `D:\Repositories\One`。

## 窗口与阅读

- 默认失去焦点后关闭预览。鼠标指针框图标“保持”开启后不自动关闭；图钉“置顶”只控制窗口层级，两者互不代替。
- 左侧栏默认关闭，切换“文件 / 详情 / 目录”；详情统一在该面板。目录不存在时隐藏页签，PDF / DOCX / PPTX 另有“概览”显示页面缩略图。文件夹单击预览，双击进入目录。
- 左侧分界可拖动或用方向键调整，动画展开 / 折叠；栏宽、侧栏开关、页签、换行、置顶和保持即时保存。代码及文档均支持连续滚动。侧栏与源码 / 预览使用主界面同款胶囊分段控件。
- 主窗口、预览、独立搜索和文件选择统一自绘方形窗口按钮，保留 Windows 原生厚边框、阴影与调整大小。预览弹出时置于前台，不显示任务栏图标。透明 HUD / 附着弹层不添加多余窗口边框。
- 功能图标使用 Lucide，文件和目录图标直接使用 [VSCode Icons 扩展官方 SVG](https://github.com/vscode-icons/vscode-icons)；One 品牌标识独立。打开方式分栏按钮列出推荐应用，并从 Windows 读取其实际图标，缺少图标时回退。
- 浅色预览左栏采用纯白。详情以紧凑文件标识、元数据和位置排列；复制路径、查看占用统一放在标题栏右上角“更多”菜单，标题栏不再显示文件类型文字。
- 界面标题、按钮、导航等不可选；编辑器、文档正文、表格值与详情可选。Ctrl+A 不选择整个应用界面。快速预览页只保留入口与设置，不列举格式说明。

Office、EPUB、字体文件最多 50 MB；在隔离 Worker 中预检归档实际解压数据，单条目 32 MB、总声明展开量 128 MB，异常大小/错误文件返回提示。解析有 15 秒超时。HTML/Markdown 在禁用脚本的 iframe 中显示；文件令牌由主进程分配，图片/CSS 只允许当前目录内部解析到的资源，外部网络请求被阻止。

大文本超过 1 MB 通过受控本地文件 URL 交给 Worker 解码、分行，再建立 CodeMirror 文本树；不经大型 IPC 字符串传送，也不一次生成全部行的 DOM。关闭或切换取消前端 Worker、释放编辑器。格式化仅影响显示，不写回文件。

图片、视频与音乐切换为深色媒体布局，仍使用同一窗口的文件导航与详情；从文件夹点击媒体后可通过返回按钮回到原目录。

## 外观与浮层

默认浅色：工作区 `#ffffff`、侧栏/辅助背景 `#f6f6f6`。默认深色：工作区 `#181818`、侧栏/辅助背景 `#141414`。

支持跟随系统/浅色/深色、强调色预设及自定义、明暗模式分别保存背景/前景、系统/无衬线/等宽预设及 Windows 已安装字体、舒适/紧凑间距、4–16 px 圆角。预览、复制菜单和文件选择跟随已保存外观。

“字体”使用自绘搜索下拉菜单，中文、英文及本地化别名均可查找；鼠标悬停或方向键移动时显示样张，Enter 选择、Esc 关闭。选择后立即持久保存并同步窗口。新装字体可点击列表右上角刷新。已卸载的字体保留原选择并提示回退到系统字体，也可切换“系统默认”或恢复默认外观。此设置作用于界面文字，代码、数据表等专用等宽区域及文档自身字体保持原用途。

音量/亮度浮层为独立透明窗口上的短条，包含 Lucide 图标、数值、进度轨道。按键显示独立键帽。HTML、body、app 根节点均透明；鼠标穿透，不抢焦点、不记录按键日志。原生截图检查已确认浮层四角 alpha 为 0。

## 热角与取色

每个角落可选：关闭、显示桌面、任务视图、锁屏、打开 One、Windows 开始菜单、资源管理器、系统截图、屏幕取色、自定义快捷键、自定义命令。

自定义快捷键直接点击输入框并按下组合键录入；Esc 恢复，清除按钮移除组合。命令分别保存程序路径、参数数组、可选工作目录，通过独立进程执行，不隐式解析 Shell。需要 Shell 命令时明确设置 `cmd.exe` 和 `["/c", "命令"]`。原有停留、冷却、热区、全屏暂停和排除规则继续生效。

取色入口在“屏幕取色”，默认快捷键 `Ctrl+Alt+C`，可通过按键录入修改或清空。放大镜在鼠标附近实时显示桌面像素；不会冻结或覆盖整屏，也不抢占原窗口焦点。滚轮改变放大倍数，左键/Enter 选取，右键/Esc 取消，对应输入不传到下方应用。

支持 HEX、RGB、HSL、HSV、CMYK、HSB、HSI、HWB、NCol、CIEXYZ、CIELAB、Oklab、Oklch、VEC4、Decimal、HEX Int。可勾选显示格式和选择默认复制格式；保留最近 20 色，可编辑和清空历史。CIELAB 为 D65 数值表示，不是 CSS D50 的 lab()；Decimal 为 Windows BGR 整数。

独立 Worker 复用 31×31 像素 GDI 采样面，只在内存中传递小图。已验证静止鼠标下色块动态变化、前台焦点不变、选色点击被拦截。HDR、广色域、远程桌面、混合 DPI 多屏及受保护内容尚未完成兼容验证；当前为 SDR 8 位取样。详细源码研究见 [取色实现调研](../research/取色实现调研.md)。
