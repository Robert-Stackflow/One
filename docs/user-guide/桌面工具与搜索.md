# 桌面工具与文件搜索

更新日期：2026-10-02。本说明随当前源码更新；历史实现见 [版本记录](../history/README.md)。功能独立实现，不要求安装 PowerToys 或 Listary。

## 唤醒

在“操作增强 → 唤醒”选择关闭、持续、定时或截止时间；可独立保持屏幕亮起。锁屏时暂停电源请求，解锁后按原截止时间继续；到期、关闭功能或退出 One 时释放请求。不修改 Windows 电源计划，不阻止用户主动睡眠或关机。

Electron `powerSaveBlocker` 提供对应 Windows 电源请求，PowerToys 的模式和锁屏处理是交互参考。

## 始终置顶

开启后，默认 `Ctrl+Alt+T` 切换前台窗口置顶，也可从窗口列表选择。支持录入快捷键、应用排除、全屏暂停快捷键、原生彩色边框和取消全部由 One 管理的置顶。

只恢复 One 自己设置的窗口，不取消其他软件已有的置顶。窗口关闭后移除记录；进程身份变化时不继续操作复用的窗口句柄。DWM 边框颜色以 Windows 11 为目标，部分应用自绘边框可能不显示。对高权限窗口的操作可能被系统拒绝。

## 文件工具

选择文件或文件夹时，可手动输入路径，也可从左侧的常用位置、收藏、最近目录和资源管理器已打开的目录进入；“已打开”旁的小按钮可刷新。最近目录最多保留 20 项，重复路径合并并移到顶部，“最近”旁的垃圾桶按钮可清空记录。

右上角“显示选项”可切换隐藏文件和文件扩展名，设置会保存。隐藏文件按 Windows 的文件属性判断；隐藏扩展名只改变显示，选择、打开和保存仍使用完整文件名。列表支持当前目录筛选、方向键、Home/End、PageUp/PageDown，文件夹双击进入；工具栏可后退、前进和返回上级。Ctrl+L 可编辑路径。

选择窗口记住大小和位置；显示器断开后会把窗口放回可见区域。选择范围时优先打开输入框里已有的有效路径，未指定时从最近选择的位置开始。文件工具的路径输入与浏览按钮共用一圈边框，仍可粘贴路径。

“文件工具”提供重复内容查找、文件/目录比较、批量重命名和文档全文搜索，任务在后台执行。主动任务在切换功能页或隐藏窗口后继续；自动重命名预览和待发搜索在不可见时暂停，返回按最新输入恢复。

结果可连续滚动浏览全部项目，支持方向键、Home/End 和 PageUp/PageDown；无需逐批点击“加载更多”。切换页签或功能页保留位置和选择，尚未加载的项目就近读取。窄窗口点击重复组进入成员列表，点击“返回重复组”回到原组；完整差异文本和正文片段可选择复制。

正文索引首次提取所选范围，后续更新复用未变化的文档。提取单个文档失败时保留其上次完整正文，并在未完成项中报告；修复文件后可重新更新索引。取消不会提交正在提取的部分正文。

当前开发版可以在任务准备、扫描或比较时点击“停止”。停止和失败后保留上次完整结果，回收本次已标记的只读任务临时文件；正常退出先等待自己的辅助线程和文件句柄关闭。启动时也回收这类未完成任务，未标记的旧目录及含未知内容的目录不会自动删除。

批量重命名按“处理范围、替换规则、编号与格式”分组。编号与格式默认收起，可点击或用键盘展开；收起只隐藏选项，不清除规则。替换文本支持序号、日期和正则分组，选项修改后沿用自动预览。

执行重命名必须先预览并确认。已经开始写入的重命名不强行终止，退出时等待完成；操作和恢复记录保留，支持撤销。正常完成的正文索引与任务结果沿用原有保存规则，与可清理的未完成任务分开。

## 文件占用（File Locksmith）

入口在侧边栏“系统 → 文件占用”、预览标题栏“更多”及空间分析右键菜单。可添加文件、文件夹，或拖入多个目标；目录匹配包括后代文件。扫描显示进度、占用进程和文件，并报告无权访问、查询超时及模块读取不完整的进程数。停止时保留已有结果。

“结束进程”需确认具体进程，可能丢失该进程未保存的内容。执行前重新校验 PID 和创建时间，拒绝关键进程、Windows 系统目录中的进程及 One 自身。不会强行关闭单个远程句柄。

扫描系统文件句柄、映射模块和进程镜像。原生检查放在独立进程中，最多同时检查四个进程；单次检查超时 2 秒，整体上限 90 秒。普通权限无法完整检查所有系统或高权限进程；结果中的未完成数不能当作“没有占用”。未实现 PowerToys 的系统右键 Shell 扩展、提权重启按钮或全部映射对象类型。

## 文件搜索

主侧边栏按“文件、工具、系统”分组，概览独立置顶，设置保留在底部。分组只有浅色小标题和间距，不需要展开；收起侧边栏时隐藏标题，保留分组间距。

1. 在“文件搜索”添加索引目录，可配置排除目录和收藏文件夹，添加后开始扫描。
2. `Ctrl+Alt+F` 打开独立搜索窗口。也可启用双按 Ctrl。
3. 按上下键选择，Enter 打开，Ctrl+Enter 定位，Alt+P 预览，Esc 关闭。

按文件名和路径搜索，支持空格分词、引号短语及 `folder:`、`file:`、`doc:`、`pic:`、`video:`、`audio:`、`ext:txt;md`。显示匹配总数与前 100 项。独立搜索还支持系统已注册的程序和 Windows 设置，无需添加索引目录。文件正文搜索使用“文件工具 → 文档全文搜索”的独立正文索引。

独立窗口的类型筛选使用统一分段页签，支持左右方向键、Home 和 End。后台索引更新时，独立搜索和直接输入搜索均保留已有条目、图标与悬停按钮；按文件路径恢复当前选择和滚动位置。选中项确实离开结果时选择邻近项。新的关键词或类型筛选重新开始选择，过期响应不覆盖最新输入；输入法组合输入期间不发起后台刷新。

Rust 辅助进程并行扫描目录，预计算名称、全拼及首字母；最多 200 万项，二进制缓存为 `file-index.bin`。旧 NDJSON 缓存不再读取，升级后按原目录重新建立。缓存加载后立即可查，后台核对离线变化；监听新增、改名和删除，按子树更新，跳过链接和排除目录。输入时取消过期查询，界面只接受最后一次结果。

“季度报告”可用 `jidubaogao`、`jdbg` 或 `jd bg` 搜索；支持多音字有限组合、不连续缩写和一个字符的增删改/相邻交换。名称精确匹配优先，其次前缀、包含、拼音、模糊/近似。当前文件夹内结果获得加分。拼音和模糊分别可关闭；带引号的词禁用近似匹配。多音字最多保留 8 种组合，暂不按中文词组消歧。

未采用 NTFS MFT/USN，首次全盘扫描速度仍不等同于 Listary/Everything；名称搜索不读取文件正文，也没有云端或网络搜索。

## 资源管理器与文件对话框

各入口默认关闭，以免与已安装的 Listary 同时响应。启用同一种手势时，建议只保留一个软件处理它；One 不会自动修改 Listary 设置。

- **直接输入**：焦点位于资源管理器或桌面文件列表时，首个可打印按键展开附着式搜索框并带入输入。输入在下方，结果向上展开；搜索框跟随原窗口，Ctrl+1–9 选择前九项，Esc 返回原窗口，失焦隐藏。地址栏、搜索栏和重命名编辑框不触发。首次切换使用有界输入缓冲，不保存按键日志。
- **双击空白处**：在鼠标位置显示自定义快捷菜单，支持文件夹、文件/程序、命令、网址、分组、分隔线，以及收藏、已打开目录、最近访问等内置动作。选择文件夹后在原资源管理器窗口的当前文件系统标签中跳转；双击文件不属于菜单入口。
- **文件对话框 Ctrl+G**：显示已打开目录与收藏，输入可搜索索引中的文件夹。Enter 将原打开/保存对话框导航到该目录，不自动选择文件、不确认打开/保存、不修改文件名。

目前针对 Windows 11 Explorer 文件系统目录和标准 `#32770` 打开/保存对话框。通过 Shell COM 识别活动视图，通过 UI Automation 确认地址栏后导航。虚拟目录、自绘文件对话框、管理员应用、复杂 IME/多标签/混合 DPI 组合需继续兼容验证。路径消失或目标窗口身份变化时显示错误。

## 快捷菜单自定义

在“文件搜索 → 双击快捷菜单”添加、编辑、隐藏、排序项目，选择所属分组和 Lucide 图标。文件夹可以悬停或按右方向键展开内容，点击则直接跳转；上下键选择、Enter 执行、左方向键返回上一层，Esc 退出。收藏按钮保存当前文件夹，设置图标打开菜单配置。

命令的程序路径与参数分别填写，参数每行一个、不需要外层引号。支持 `%USERPROFILE%` 等环境变量、`{folder}` 当前目录、`{selected}` 首个选择、单独一行 `{selection}` 展开选择列表（最多 32 项）。工作目录默认当前文件夹。需要 Shell 语法时显式选用相应解释器；One 直接传递参数，不自动执行拼接的 Shell 字符串。

菜单配置可以 JSON 导入/导出，最多 200 项、五层分组，拒绝重复 ID、循环分组和无效动作，导入失败保留原配置。目录按需读取，每层展示前 150 项；最近访问保留 30 个目录。暂不提供 Listary 插件市场、完整命令别名系统或菜单项独立快捷键录制。

## 编辑与保存

设置自动保存；“搜索 / 索引 / 快捷菜单”分区独立。菜单左侧为可展开的层级树，右侧编辑选中项；修改即时生效，添加项目需补齐必要内容后点击“添加”。可选择上级菜单或拖入子菜单，也可用上下箭头调整同级顺序；最多五层。图标从 Lucide 本地图标库搜索选择，支持常用中文词和英文名称。导入会替换整套菜单，导出保留图标、层级和参数。

资源管理器监听接受远程桌面输入，仅忽略 One 自身重放事件；在地址栏、重命名输入框中打字不会启动内嵌搜索。快捷键录入完成或失焦后恢复监听。

## 搜索窗口与级联菜单

独立搜索不显示标题栏或窗口操作按钮。空输入时为 64 px 高的横条，在鼠标所在屏幕靠上居中；有查询时展开到约 560 px，受屏幕工作区限制。结果数量改变不改变窗口高度，清空输入后收回；可拖动输入框旁的空白区域移动窗口。

搜索输入提前准备并复用；菜单按使用时机准备，隐藏闲置 45 秒后回收，下次自动重建。资源管理器上下文读取通过常驻原生进程和独立 COM 线程完成，不在每次触发时启动新进程；菜单先显示静态项目，目录内容按需读取。弹出时请求前台焦点并使用临时置顶层级。

分组和文件夹内容在独立的级联菜单中显示，不扩宽主菜单。悬停或右方向键展开，左方向键返回；收藏当前目录使用星形图标。桌面目录跳转会打开新的资源管理器窗口。

搜索结果使用统一自定义右键菜单，支持打开、预览、打开方式、定位、复制/剪切、复制路径、重命名和移入回收站。打开方式在独立子菜单中展开，展示应用自身图标；只有超过屏幕上下留白的可用高度时才出现滚动条。“更多系统操作”保留 Windows Shell 菜单及已安装扩展，具体项目和响应取决于系统配置。
