# 压缩与解压

以下能力已在开发版实现，尚未随新的安装器发布。侧边栏“文件”分组最后一项为 **压缩与解压**。

## 创建与解压

“创建压缩包”左侧添加文件或文件夹，也可以点击 **粘贴或编辑路径**，每行输入一个完整路径。列表中可以移除单项或清空内容；右侧选择格式、填写保存路径，再点击 **创建压缩包**。密码、分卷和资源选项在 **高级设置** 中调整。

ZIP、7Z 支持密码和分卷；TAR、TAR.GZ/TGZ、TAR.XZ/TXZ 可容纳多个项目，GZ/XZ 只压缩单个普通文件。RAR 目前只支持读取，不支持创建。

RAR4/RAR5 分卷需放在同一个文件夹，从首卷（通常为 `.part1.rar`、`.part01.rar` 或 `.rar`）打开。缺少后续卷时会提示文件名，补齐后重新打开；直接选择后续卷会提示改选首卷。支持加密文件名和固实加密包；同一个包中的项目若使用不同密码，可分别选中项目并填写对应密码解压。

ZIP、RAR4 和 RAR5 支持显示压缩包备注，浏览页可在 **更多 → 压缩包备注** 中查看。RAR4 支持普通或压缩的 CMT 备注、中文 UTF-16 及旧式内嵌备注；旧式文本按 Windows OEM 编码解释，较新文本按系统编码解释。RAR4 备注读取上限为 256 KiB，超过上限、数据损坏或校验不符会明确报错，**测试完整性** 也检查备注。加密头中的 RAR4 备注及单独加密/分割的 CMT 记录暂不支持，不影响引擎原有的加密文件解压能力。

ZIP、7Z、RAR 分卷在浏览后若任一已读取分卷被替换、改变大小或修改时间，旧选择及风险确认会失效，需要重新打开。读取、解压和拖出期间会锁定分卷，防止其他程序同时改写或替换；操作结束后释放。此检查用于识别文件变化，检查内容是否损坏仍应使用 **测试完整性**。

One 的 ZIP 密码默认使用 UTF-8，保持已有压缩包的行为。与其他软件交换中文等非英文密码 ZIP 时，可在创建页 **高级设置 → ZIP 密码编码** 中选择 **Windows 系统编码**、GBK / CP936、Shift JIS / CP932、Big5 / CP950 或 CP437。Windows 版 7-Zip 读取 ZIP 密码使用系统代码页；需要互读时，双方应使用相同代码页。本机代码页 936 下的中文 AES ZIP 已通过 7-Zip 25.01 校验。[7-Zip 的 ZIP 密码处理源码](https://github.com/ip7z/7zip/blob/main/CPP/7zip/Archive/Zip/ZipHandler.cpp)。

密码正确却无法解密时，展开浏览页的 **ZIP 密码兼容**，选择创建时使用的密码编码，再重试校验或解压；选择同样用于保存修改和拖出文件。这里的编码与文件名编码独立，程序不会自动猜测或依次尝试。旧编码无法表示某个密码字符时停止操作，不用问号替换；可改用 UTF-8、其他可表示该密码的编码或 7Z。密码及本次密码编码选择不写入设置或备份，切换外部打开的归档时恢复默认。7Z/RAR 等其他格式仍使用各自原有密码处理。

“浏览与解压”顶部选择或粘贴压缩包路径，点击 **打开**（也可以按 Enter）。左侧浏览和搜索包内文件，打开文件栏右侧的 **更多** 菜单，可添加、重命名、删除项目或编辑备注；右侧设置目标目录、解压方式；密码和编码在 **密码与编码** 窗口中填写，选择 **全部解压** 或 **解压选中项**。旧 ZIP 文件名显示不正确时，打开 **密码与编码**，尝试选择 GBK、Shift JIS、Big5 或其他对应编码。加密包需要输入密码；密码不会保存在设置或备份中。

读取和处理期间显示进度遮罩，可点击 **停止**；最终保存等不能中断的阶段不显示停止按钮。完整性校验结束后显示结果窗口，成功时展示已检查的项目数量，失败时保留原因，手动关闭后继续操作；即使校验瞬间完成也会显示结果。其他操作的结果和错误显示在右侧操作区域，错误可展开查看完整详情。

解压到同名文件夹会创建以压缩包命名的目录。智能解压时，只有一个顶层项目就直接放入目标目录，多个顶层项目则放入同名文件夹。遇到同名项目会另取序号，不覆盖已有文件。创建压缩包时，已有目标文件也不会被覆盖。

**解压至此** 将内容直接放入上方选择的目标目录。同名文件夹合并，保留其中其他内容；同名文件可选择自动重命名（默认）、跳过或替换。设置页可以保存默认处理方式，当前任务仍可单独调整。文件与文件夹互相占用同一名称时，请选择重命名或跳过；替换模式不会删除整个旧文件夹，也不能替换正在解压的源包或其分卷。

提交到现有目录时可以取消，程序会回滚本次新增和替换。若文件已被其他程序修改或占用，无法恢复的部分会保留，并提示 `.one-recovery-…` 恢复目录；其中包含原文件副本和路径清单。原生进程异常退出时，主程序也会提示本次留下的恢复目录。不要把这些目录当作临时缓存清理。

新清单记录完整写入计划、文件身份和发布阶段；全部提交完成后，先保存完成标记再删除原文件副本，便于区分未完成发布与完成后的清理中断。此流程不是整个目录的原子替换。重启后可通过页面的恢复资料入口检查、显式还原和清理；不会自动还原，真实断电后的持久性仍需验证。不要直接按清单中的路径覆盖或删除文件；保留恢复目录及现有文件，避免丢失中断后新修改的内容。

压缩和解压完成后，默认只显示结果，不打开资源管理器。页面上的 **完成后打开文件夹** 与 **设置 → 压缩与解压** 使用同一个选项；关闭后，双击智能解压也不会打开结果文件夹。选择会保存，重启后继续生效。

## 查看文件信息

浏览列表每行右侧的 **文件信息** 按钮，可查看完整包内路径、原始大小、压缩后大小、节省空间、修改时间、压缩方式、加密状态及 CRC32。信息按需读取，不为整个目录提前收集额外属性，也不提取或运行所选文件；复合格式沿用浏览时的中间 TAR 缓存准备。信息窗口中的路径和校验值可以选择复制，关闭后保留列表选择。

仅显示压缩格式实际记录的字段，缺失时显示“未提供”。固实压缩可能由多个文件共享一个压缩块，此时会注明共享，不计算单个文件的节省空间。未单独记录的文件夹只显示由包内路径合成的目录信息，不虚构文件夹大小或时间。旧 ZIP 的 DOS 时间不带时区，按本机引擎解释后以本地时间显示。

CRC32 是压缩包记录的值，不代表已经验证内容；需要检查文件完整性时仍应点击 **测试完整性**。AES AE-2 ZIP 可能以认证码代替 CRC，此时不将占位零误报为文件校验值；真正的空文件 CRC `00000000` 正常显示。原压缩包修订变化后，需重新打开才能查看。

## 解压磁盘空间保护

解压前根据本次选中内容的声明大小检查可用空间，并预留 256 MiB。解压写入过程中按字节量和时间间隔重新查询磁盘余量，结束写入时再次检查；采用当前用户可用空间，包含系统磁盘配额的限制。空间不足或无法查询时停止任务并提示原因，未发布的暂存结果会清理，释放空间后可重试。

检查覆盖普通解压、选中项、复合格式的中间文件以及拖出内容的暂存；只浏览普通归档或测试完整性不要求解压空间，复合格式首次浏览仍需空间准备中间文件。此机制不是磁盘空间预留，其他程序仍可能在两次检查之间写满磁盘；系统写入失败也会停止任务。目录元数据等额外开销不计入文件声明大小，实际大文件、网络磁盘及配额环境仍需进一步验证。

## 压缩与资源选项

创建页面右侧的 **压缩选项** 打开独立设置窗口，可调整本次密码、分卷大小、压缩等级、压缩线程数和每个归档进程的内存上限。长期默认值在 **设置 → 压缩与解压 → 压缩与资源** 中保存，也包含在设置备份中。默认标准等级 6、2 个压缩线程、1024 MB 提交内存上限；旧设置自动补入这些默认值。

等级为 0–9，0 为最低档（ZIP/7Z 仅存储，其他压缩流按引擎最低档处理），1 偏重速度，6 为标准，9 偏重压缩率；实际效果取决于格式与内容。TAR 仅打包，不使用压缩等级；TAR.GZ/TAR.XZ 对外层压缩流应用等级。7Z、XZ 压缩与 7Z 修改使用线程参数；ZIP 创建可按文件并行压缩，单个文件仍为一个压缩流，GZ 使用单线程。自动线程按可用 CPU 和当前任务总线程预算选择，旧配置保留原来的手动线程数。ZIP 并行时暂存有限数量的已压缩条目再组装结果，会增加磁盘读写，不保证所有磁盘和内容都更快。

内存上限可设为 128–8192 MB，由 Windows 限制每个独立归档辅助进程的提交内存，覆盖浏览、创建、解压、校验与修改。它不是整应用总内存或工作集限制，也不承诺引擎一定能在指定上限内完成；高等级、大字典或复杂目录可能需要提高上限。任务开始时固定参数，修改设置只影响新任务。分配失败或无法应用限制会报资源错误，未发布的创建结果会回收，可降低等级或提高上限重试。

## 页面与任务反馈

创建和浏览共用左右两栏布局，页面本身不垂直滚动，文件列表在各自区域内滚动。标题、目录路径、搜索和更多入口共用一行；压缩包备注在更多菜单中按需查看。

读取、创建、解压、校验和修改期间，工作区显示进度遮罩，可点击停止。最终保存和原生拖放传输阶段有对应提示，不能中断最终保存。读取完成不显示常驻状态条；完整性校验结束后显示结果窗口，保留通过或未完成的结果及项目数量，关闭后继续操作。

## 快速预览

快速预览支持 ZIP、7Z、RAR4/5、TAR、TAR.GZ/TGZ、GZ、TAR.XZ/TXZ、XZ，以及受支持的 ZIP/7Z/RAR 分卷入口。使用与主页面相同的独立归档引擎，按目录、搜索和每页 200 项读取列表；可输入密码，手动调整旧文件名编码及 ZIP 密码编码。普通归档浏览不提取文件；复合压缩格式首次浏览需准备中间文件，受现有资源和磁盘保护限制。

预览只提供当前文件的只读列表，不接受任意路径或写入操作；切换或关闭预览会取消旧任务并丢弃过期结果。APK、JAR 等 ZIP 应用容器保留原有预览方式。

## 浏览目录与搜索

默认按目录查看，可点击目录名称进入，使用上方路径或左侧目录导航返回。未单独记录目录条目的压缩包也会显示文件夹，勾选后可整组解压或拖出。**更多 → 显示全部文件** 切换为递归清单；搜索查询当前目录及全部子目录，不限于当前这一页，忽略文件名大小写。

列表每页最多 200 项，翻页、进入目录和搜索都会保留已勾选项目，可在底部清除选择。打开另一个压缩包、调整文件名编码或重新打开时清除选择；已有未保存修改需要先确认。压缩包被其他程序修改后，需要重新打开才能继续浏览或解压，避免使用过期索引。

未单独记录的文件夹也可以直接重命名或删除，操作包含所有子项，覆盖其他页面上尚未显示的内容。变更先加入预览，确认保存后才写入原包；重命名到已有文件夹会拒绝保存，避免意外合并。目录导航只保留近期浏览分支和当前页目录，前端不会加载完整清单。百万条目的原生目录解析、内存和搜索耗时仍需性能验收。

## 双击压缩包

**设置 → 压缩与解压** 可以选择：

- **智能解压**（默认）：打开后自动解压到压缩包所在目录，遵守上述智能解压及同名保护规则。密码错误等情况会停留在浏览页，处理后可以重新解压。
- **打开并浏览**：只展示文件列表，由用户选择何时解压。

One 内的打开文件操作和关联到 One 的文件双击使用相同偏好。直接拖入压缩页或选择“打开”先展示浏览页。连续收到多个外部请求时依次处理。

## 右键与批量解压

启用 **设置 → 基本设置 → 系统右键菜单 → 解压压缩包** 后，资源管理器的该菜单提供 **智能解压、解压至此、解压到同名文件夹、浏览压缩包** 四种动作。One 文件搜索结果的右键菜单提供同样的动作，以及创建压缩包入口；文件夹和普通文件只显示创建入口。

资源管理器一次可选择最多 128 个受支持的压缩包。批量解压依次处理，默认各自解压到源包所在目录，采用设置中的同名处理方式；一个包损坏或需要密码不会阻断后续包。批量结果分别显示成功、失败和取消，点击失败项的 **处理**，输入密码或调整编码后重新打开并解压。密码不会沿用到下一个压缩包。

多选后选择 **浏览压缩包** 不会自动解压，可在批量列表逐个打开。取消批量解压会停止当前操作并取消尚未开始的包；此前已完成的结果保留。文件夹打开开关同样生效，默认不弹出资源管理器。

这些入口已通过开发版的隔离协议和页面测试，正式安装后的 Windows 10/11 右键显示、更新及卸载行为仍待实际验收。

## 拖出选中内容

在文件列表中勾选多项，再拖动其中任意一项到资源管理器的目标文件夹。直接拖动未勾选的条目会改为只拖出该项。选择文件夹时包括全部子项；同时选择文件夹与其子项不会重复复制。有未保存的包内修改时，先保存或放弃修改。

拖出使用复制操作，不删除原压缩包中的内容。松开鼠标后由接收程序处理同名冲突，按 Esc 可以取消尚未落下的拖放。解压和内容传输由独立辅助进程处理；支持虚拟内容流，也为只接受真实路径的接收程序提供已解压文件路径。内容发布前完成扫描；内容流结束后清理暂存文件，交付真实路径的任务保留暂存内容，后续定期清理超过 24 小时的已标记任务，避免接收程序尚未读取就被删除。压缩包在打开后发生变化时需要重新打开。

当前一次可勾选最多 10,000 项，展开目录后最多 65,536 个描述项。Windows 文件拖放描述中的相对路径须短于 260 个字符；超过时使用普通解压。原生内容流、多格式样本和页面路由已通过隔离测试，实际 Explorer 拖放、管理员启动与正式安装版仍待验收。

## 外部编辑包内文件

在 ZIP 或 7Z 中选择一个普通文件，使用 **更多 → 外部编辑选中项**。支持 256 MiB 以内的常见文档、文本和图片；程序及脚本文件不通过此入口打开。先保存或放弃普通修改草稿，再准备编辑副本。

在 **外部编辑** 窗口点击 **打开编辑副本**，用系统关联的程序编辑。请在外部程序中保存并关闭文件，再点击 **检查变化 → 确认写回**。打开的是临时副本，外部程序保存不会立即修改压缩包。系统关联程序可能复用已有进程，One 不把打开成功当作编辑已经结束，也不会自动写回。

写回使用检查和确认时的文件内容快照，并再次核对原压缩包版本。原包已变化或副本在确认后又有变化时，停止写回并保留副本，请先另存文件再重新打开原包。加密包写回时在窗口中重新输入密码，沿用准备副本时选择的 ZIP 密码编码；密码不会写入编辑记录或设置。

编辑副本跨 One 重启保留，最多 16 份，不按缓存过期时间自动删除。写回后也保留副本；确认不再需要时点击 **移除副本**。有未写回的变化会再次提示；编辑器创建了其他文件时，不自动删除整个目录，请通过 **查看位置** 另存和处理。上次写回结果尚未确认、记录损坏或文件被链接替换时，保留资料并手动检查，不能自动重放写回。
## 修改 ZIP 和 7Z 压缩包

打开 ZIP 或 7Z（包括分卷）后，文件列表右上角 **更多** 菜单提供 **添加内容、新建目录、重命名选中项、删除选中项**；ZIP 还支持 **备注**，7Z 不支持压缩包备注。修改先进入变更列表，可移除某项或放弃全部；点击 **保存修改** 查看完整预览并确认。重命名或删除目录时会包含全部子项，不限于当前已加载的一页。

添加时可以指定包内路径，例如 `文档/说明.txt`。已有同名目录会合并；只有明确勾选 **替换同名文件** 才会替换文件，文件和目录不会互相覆盖。修改加密包需要正确密码。ZIP 保留未修改条目的加密和压缩数据；新增内容在原包存在加密项时使用 AES 加密，替换项沿用原条目的是否加密状态。

7Z 通过引擎更新原归档，单纯重命名保留原压缩数据块；固实包删除或替换部分内容时可能重新压缩受影响的数据块，耗时与数据块大小有关。加密内容和原有的加密文件名模式会保留；原来可见的文件名不会因输入密码而改为隐藏。新增内容随原包的加密设置处理，不把普通包仅因填写密码而自动改为加密包。

单卷保存会先校验原包，再重写到同目录临时文件并完整校验，最后替换原件。原包在浏览后发生变化时需重新打开，避免用过期条目修改新内容。取消在最终替换之前生效；最终保存期间短暂隐藏取消按钮。单卷正常失败会保留原包并清理临时文件，Windows 替换异常时无法自动恢复的原件副本会保留在同目录，错误信息提供路径。分卷保存和中断资料处理见后文“当前限制”。

RAR、TAR 和压缩流目前没有修改入口。开发版已用本机 10 GiB 单文件验证 ZIP64 的创建、校验、解压和包内改名，并比对完整文件哈希；普通 ZIP64 与 ASCII 密码 AES ZIP64 已通过本机 7-Zip 互操作测试。样本主要为零数据，混合文件性能、7Z 大文件、网络盘和断电恢复仍需进一步验证。

ZIP 创建可选择 **Deflate / XZ** 与 **AES-256 / ZipCrypto**，默认 Deflate 和 AES-256；加密算法只有填写密码后才生效。XZ 是 ZIP 容器中的压缩方法，文件仍为 `.zip`，与创建独立 `.xz` 不同；接收软件需要支持该方法。ZipCrypto 用于旧软件兼容，保护能力较弱。

7Z 创建可选择 **LZMA / LZMA2**，默认 LZMA2；固实块可选 **非固实、1 / 2 / 4 / 8 / 16 / 32 / 64 / 128 / 256 / 512 / 1024 MB、固实**，默认 64 MB。同一块中的文件共同压缩；大块可能改善压缩率，但提取其中单个文件可能需要处理前面的数据。最低等级 0 仍仅存储。长期默认值可在设置中的 ZIP / 7Z 压缩设置保存，随备份导入导出；创建页可对本次任务覆盖。算法与固实块设置用于新建归档，修改已有包仍保留原有条目的压缩数据和加密语义，不把这些设置当作批量转换原包的操作。

## 任务中心

概览页的 **任务中心** 会显示压缩、解压、校验、修改和拖出的当前阶段与进度，支持停止仍可取消的任务。停止页面发起的批量解压时，尚未开始的压缩包也会取消，已完成的结果保留。最终保存阶段停止按钮暂时禁用，以保护原文件。切换页面或关闭主窗口到托盘不停止归档任务；退出 One 会取消可取消的任务并等待最终保存阶段结束。

**最近记录** 包含完成、失败和取消的归档任务。点击记录可查看开始时间、耗时、处理数量、压缩包与结果位置，并返回压缩包浏览页；只有主动点击 **查看结果位置** 才打开资源管理器，不受“完成后打开文件夹”的自动打开行为影响。读取目录、翻页与搜索不会新增完成记录。

记录保存在本机，最多保留 100 条归档历史，概览汇总最近 30 条并显示最新六条。记录不保存密码、请求参数或压缩包内部文件清单。上次异常退出时仍在运行的任务会标记为 **上次异常中断**，不会自动重试；该标记不代表输出已完成或已经回滚，需要检查结果及可能存在的恢复副本。

## 任务队列与总预算

在 **设置 → 压缩与解压 → 任务队列** 中设置同时运行的任务数、总内存预算和总线程预算，默认分别为 **2 / 2048 MB / 4**。等待中的任务会显示排队位置，可从概览停止；前面的任务完成后依次启动。多阶段压缩、校验、扫描和最终保存结束前都保留额度。

内存按每个任务配置的进程上限预留，线程按配置值预留；三个条件都满足才能启动。单个任务超过总预算会提示调整资源设置，不会无限等待。开始新任务时应用队列设置；降低预算不会强行终止已经运行的任务，不能再容纳的等待任务会明确失败。

同一 Windows 用户、同一登录会话中的 One 界面与独立命令行共享归档额度。参与实例的三个总预算分别采用较严格值，例如界面允许 2 个任务、命令行允许 1 个时，命令行参与期间共享上限为 1；超出其他实例预算的任务会提示调整。实例首次使用归档功能后参与共享，正常退出时移除；异常退出会回收记录，但仍存活的辅助进程结束前继续预留额度。开发构建与正式安装版相互隔离。

内存预算不是实时占用统计，线程预算也不是系统线程数硬限制；主窗口与其他程序的资源不计入，每个归档辅助进程仍有独立的 Windows 内存上限。命令行批量任务默认逐个执行，可用 `--concurrency` 开启有预算约束的并行；参数和依赖顺序见 [压缩命令行](压缩命令行.md#批量任务)。

## 恶意软件扫描

在 **设置 → 压缩与解压 → 解压防护** 中开启 **解压时扫描恶意软件**，默认关闭。普通解压、智能解压、解压至此、解压选中项和拖出内容都会先检查暂存文件，再发布结果；浏览、压缩、修改和完整性校验不调用扫描。

扫描使用本机 Windows AMSI 提供者，逐文件读取，空文件无需内容扫描。完成后显示“扫描未检出威胁”及已检查文件数；这不代表文件绝对安全。任务详情可查看提供者名称和扫描结果。解压至此的扫描数量对应本次暂存文件，包含随后因同名冲突被跳过的内容。

提供者不可用、扫描失败、超出内存预算或单个文件扫描超过 120 秒时，结果显示“未完成恶意软件扫描”，这次解压停止，已有目标文件不会被替换。检测到威胁或安全策略阻止时同样停止。One 不自动关闭扫描重试；可自行决定是否在设置中关闭该项。扫描提供者可能有自身的文件大小或格式限制，One 不将部分内容扫描冒充整个文件扫描完成。

## 文件关联与长期偏好

**设置 → 压缩与解压 → 解压防护 → 保留下载来源标记** 默认开启。压缩包带有 Internet（ZoneId 3）或受限区域（ZoneId 4）的 Windows 来源标记时，One 在发布结果之前为所有解出的普通文件写入相同区域标记，包括没有扩展名和空文件；文件夹不标记。无标记或本地、内网、可信区域的来源不生成新标记。

标记写入命名流 `Zone.Identifier`，只传递区域编号，不复制来源网址、引用网址和其中可能存在的凭据。输入标记最多 4 KiB，支持常见文本及 UTF-8/UTF-16LE BOM，并兼容下载软件写入的末尾空字符；文本中间的空字符、空值、非法或重复区域会停止任务。目标磁盘不支持命名流、标记无法读取或写入时明确失败，暂存文件不会作为成功结果发布；可选择支持命名流的目录，或手动关闭此项后重试。关闭此项不主动清除已有文件或原压缩包的标记。

同名跳过保留原文件及原标记；显式替换会使用本次解出文件的标记。复合压缩包读取原始 TAR.GZ/TAR.XZ 的来源，不依赖缓存 TAR；缓存源变化时拒绝使用过期内容。单卷 ZIP/7Z 修改通过 Windows 事务替换保留原压缩包已有命名流。

拖出时暂存文件同样保留来源标记，并向接收应用提供 Windows 的“不可信拖放”标识；虚拟文件内容流本身不携带 NTFS 命名流。目标应用是否保留最终文件的来源标记仍由它决定，实际 Explorer 行为尚待验收；需要确认保留标记时使用普通解压。此机制保留 Windows 后续提醒能力，不等于病毒扫描或安全认证。

安装版本可在 **设置 → 压缩与解压 → 压缩包打开方式** 注册 One，再点 **设置默认应用**，在 Windows 中选择由 One 打开的文件类型。注册覆盖 ZIP、7Z、RAR、R00、TAR、TGZ、GZ、TXZ、XZ；不注册通用的 `.001` 扩展名，避免接管其他软件的分片文件。`.7z.001` 可在 One 页面或右键入口打开。

注册只把 One 加入可选程序，不更改原有默认应用。取消注册和卸载只清理属于当前 One 安装的注册信息；开发版禁用真实关联注册，避免覆盖正式版。

ZIP、7Z、RAR、R00、TAR、TGZ、GZ、TXZ、XZ 各自使用 One 绘制的文件图标，通过格式标签和颜色区分，提供 16–256 像素多尺寸资源。只有在 Windows 中选择相应格式由 One 默认打开后，资源管理器才使用这些图标；仅注册候选程序不会替换其他软件的图标。旧版共用的 `One.Archive` 打开方式仍保留可用，并使用通用压缩包图标；如需各格式图标，重新注册并在 Windows 默认应用中重新选择对应格式。

## 解压风险确认

选中内容达到 10 万项、声明展开量达到 64 GiB、展开量至少 64 MiB 且已知压缩比达到 1000∶1，或包含疑似压缩包时，One 会先显示确认窗口。窗口列出原因并允许调整本次单层展开上限与解压时限；取消不发布内容。默认上限为每层 64 GiB、30 分钟，允许明确提高，时间最高 24 小时。确认只针对当前压缩包修订；文件变化后需重新确认。拖出时确认后需要重新开始同一组文件的拖拽。

检查统计全部选中内容及目录子项，不只检查当前页。疑似压缩包按扩展名识别，不递归解压或证明文件有害。TAR.GZ / TAR.XZ 的预期单个 TAR 包装层不单独触发嵌套提示，但其大小和已知压缩比仍受检查；批准后准备的缓存不会静默授权未批准的请求。GZ/XZ 未报告压缩大小时使用完整原始流的文件大小保守估算。固实格式的选中项可能没有独立压缩大小，此时不伪造压缩比。

实际写入仍检查声明大小、本层字节上限、时间与磁盘余量，允许继续不会关闭这些检查。普通解压的时限包括同一请求中的复合格式准备，最终发布不被中途强制结束；拖出按实际准备内容的写入时限检查，不把用户或接收应用的等待时间当作解压时间。内存、条目数等引擎硬上限仍有效。

## 命令行与批量任务

独立的 `One.Cli.exe` 已支持创建、列出内容、解压、校验、单卷及分卷 ZIP/7Z 修改和批处理，不打开主窗口或文件夹。用法、密码输入、JSONL 输出及退出码见 [压缩命令行](压缩命令行.md)。开发构建已提供入口，正式安装发布仍需验收。

## 当前限制

目前可浏览、拖出和手动替换包内条目，尚不支持直接用外部程序编辑包内文件后自动检测并确认写回。更多格式的支持范围见上面的格式表。

“压缩与解压”页面右上角的 **恢复资料** 可查看解压至此，以及分卷修改过程在异常退出后保留的记录。列表区分任务类型，分卷记录另显示暂存位置；发布阶段的检查结果显示原卷数、新卷数。记录独立于普通任务历史和临时解压缓存，重启 One 后仍可查看。点 **检查** 会读取恢复清单，核对格式、顺序、链式校验及目标/恢复目录身份，显示发布或回滚是否有完成记录；可随时停止检查。检查不会验证每个备份的当前内容，也不会还原、覆盖或删除文件。

检查结果中，未确认发布完成或已记录回滚的任务可选择 **还原原文件**。确认后，One 重新核对当前文件，将本次已发布的新内容移入恢复目录的 `.displaced` 文件，再把原文件副本放回目标。文件编号、大小或最后写入时间不符、缺少原副本、文件被占用或目标位置出现新内容时停止，保留已处理部分和其他资料；可停止操作、检查后重试。还原中途异常退出后也可继续。元数据核对不是内容哈希，不检测刻意保留这些元数据的内容篡改。

还原不会删除目录、隔离的新内容和原发布清单；完成后恢复记录仍保留，重新检查显示的是原发布过程。已确认完成发布的任务不提供回滚，可清理其遗留的原文件副本。**查看恢复目录** 仅在点击时打开资源管理器。**移除列表记录** 需要确认，只移除 One 中的索引，保留恢复目录、原文件副本和目标文件；移除前请自行保存资料位置。清单损坏、被截断、目录被替换为链接或身份变化时明确显示无法验证。若另一实例可能仍在处理该任务，则阻止检查、还原、清理与移除。没有完成标记不能证明目标从未写入；已有完成标记也不证明文件后来没有被修改。

确认还原完成后可点 **清理已还原资料**，永久删除恢复目录中隔离的新内容和清单；已完成发布的任务可点 **清理原文件副本**。清理前需要确认，不能撤销；目标文件及目录不会删除。One 先核对完整计划和当前文件，未完成还原、文件发生变化或发现未知内容时停止，并保留剩余资料。删除过程中停止或异常退出后可再次检查并继续清理，已删除的副本不会恢复。这里只核对文件身份、大小和最后写入时间，不是完整内容哈希验证。

清理只处理对应任务中经过核对的恢复和暂存资料，不递归删除、不处理未知文件、子目录或链接；清单缺失时只允许移除真正的空目录。清理结束才移除索引，失败时保留记录；最终空目录和已消失目录也可继续处理。程序不会自动清理这些恢复资料。

辅助进程每两秒报告一次心跳；30 秒失联或 30 分钟没有实际读写/处理进展时，任务停止并清理本次暂存，可查看日志后重试。这个无进展检查之外，解压还受用户选择的总时限限制；其他仍在推进的长任务不因总耗时长而终止。最终保存以及等待用户完成拖出时不会由该机制强制结束。

分卷 ZIP/7Z 已可在页面或 CLI 中修改：ZIP 打开末尾的 `.zip`，7Z 打开 `.7z.001`，其余卷放在同一目录。保存先生成并校验新卷，再备份原卷并替换整组；支持卷数增减和空包，不转换成单卷。ZIP 使用观察到的数据卷大小，最低 1 MiB；7Z 使用首卷大小，仅一个物理卷时也至少使用 1 MiB。无法准确恢复创建时配置的分卷上限。

保存已完成但旧副本清理失败时，会提示 **已保存，恢复副本待清理**，任务详情保留恢复位置。可在恢复资料中检查并清理，不必重复保存。未确认完成的修改可按清单还原：先隔离已发布的新卷，再放回整组原卷，包括旧尾卷；清理保留当前目标卷组。生成新卷时失败或取消，可能留下尚无完整清单的部分暂存；缺少可验证来源记录时，不提供暂存清理，也不会自动删除资料或移除记录，请保留列出的目录。

新执行的分卷修改会在生成新卷前保存来源记录。生成中断时可在恢复资料中检查，结果显示 **仅有新卷暂存**、现存文件数、大小和缺失数量，只提供 **清理新卷暂存**，不提供还原。清理必须使用当前窗口刚检查的结果并再次确认；包括中断后手工修改在内的当前暂存内容会被永久删除。程序在排队后重新核对记录与文件状态，变化、未知内容或发布清单会阻止仅清理暂存；清理中断后重新检查可继续。检查依据文件身份、大小和修改时间，并非内容哈希。

生成结束到保存开始之间也保留恢复记录。完整发布清单已经生成时，进入卷组还原/清理流程；即使交接中断留下两份记录，也只有原生程序核对二者的文件身份绑定后才允许处理。取消或失败并成功回滚后，新卷暂存的清理依据会保留，可检查并确认清理。旧版本没有来源记录的暂存、尚未登记的文件或损坏资料仍保持保留，不会根据目录名称自动删除。

更多 RAR 密码/分卷组合、恢复资料的硬件断电行为、拖出功能的系统交互、目标程序崩溃恢复，以及文件关联和右键的正式安装版入口仍需完善或发布验收。异常退出留下的拖出暂存会在下一次启动或拖出时检查，超过 24 小时且不再被辅助进程使用才回收。完整范围见 [实现计划](../development/压缩与解压实现计划.md)。
