# 压缩与解压

以下能力已在开发版实现，尚未随新的安装器发布。侧边栏“文件”分组最后一项为 **压缩与解压**。

## 创建与解压

“创建压缩包”中添加文件或文件夹，填写保存路径并选择格式。ZIP、7Z 支持密码和分卷；TAR、TAR.GZ/TGZ、TAR.XZ/TXZ 可容纳多个项目，GZ/XZ 只压缩单个普通文件。RAR 目前只支持读取，不支持创建。

“浏览与解压”中打开压缩包后，可以测试完整性、选择条目或全部解压。旧 ZIP 文件名显示不正确时，尝试选择 GBK、Shift JIS、Big5 或其他对应编码。加密包需要输入密码；密码不会保存在设置或备份中。

解压到同名文件夹会创建以压缩包命名的目录。智能解压时，只有一个顶层项目就直接放入目标目录，多个顶层项目则放入同名文件夹。遇到同名项目会另取序号，不覆盖已有文件。创建压缩包时，已有目标文件也不会被覆盖。

**解压至此** 将内容直接放入上方选择的目标目录。同名文件夹合并，保留其中其他内容；同名文件可选择自动重命名（默认）、跳过或替换。设置页可以保存默认处理方式，当前任务仍可单独调整。文件与文件夹互相占用同一名称时，请选择重命名或跳过；替换模式不会删除整个旧文件夹，也不能替换正在解压的源包或其分卷。

提交到现有目录时可以取消，程序会回滚本次新增和替换。若文件已被其他程序修改或占用，无法恢复的部分会保留，并提示 `.one-recovery-…` 恢复目录；其中包含原文件副本和路径清单。不要把这些目录当作临时缓存清理。此流程不是整个目录的原子替换；系统断电后的自动恢复仍待实现。

压缩和解压完成后，默认只显示结果，不打开资源管理器。页面上的 **完成后打开文件夹** 与 **设置 → 压缩与解压** 使用同一个选项；关闭后，双击智能解压也不会打开结果文件夹。选择会保存，重启后继续生效。

## 浏览目录与搜索

默认按目录查看，可点击目录名称进入，使用上方路径或左侧目录导航返回。未单独记录目录条目的压缩包也会显示文件夹，勾选后可整组解压或拖出。**全部文件** 切换为递归清单；搜索查询当前目录及全部子目录，不限于当前这一页，忽略文件名大小写。

列表每页最多 200 项，翻页、进入目录和搜索都会保留已勾选项目，可在底部清除选择。打开另一个压缩包、调整文件名编码或重新打开时清除选择；已有未保存修改需要先确认。压缩包被其他程序修改后，需要重新打开才能继续浏览或解压，避免使用过期索引。

未单独记录的文件夹暂不能直接重命名或删除；请进入目录选择实际条目修改。目录导航只保留近期浏览分支和当前页目录，前端不会加载完整清单。百万条目的原生目录解析、内存和搜索耗时仍需性能验收。

## 双击压缩包

**设置 → 压缩与解压** 可以选择：

- **智能解压**（默认）：打开后自动解压到压缩包所在目录，遵守上述智能解压及同名保护规则。密码错误等情况会停留在浏览页，处理后可以重新解压。
- **打开并浏览**：只展示文件列表，由用户选择何时解压。

One 内的打开文件操作和关联到 One 的文件双击使用相同偏好。直接拖入压缩页或选择“打开”先展示浏览页。连续收到多个外部请求时依次处理。

## 右键与批量解压

启用 **设置 → 基本设置 → 系统右键菜单 → 解压压缩包** 后，资源管理器的该菜单提供 **智能解压、解压至此、解压到同名文件夹、浏览压缩包** 四种动作。One 文件搜索结果的右键菜单提供同样的动作，以及创建压缩包入口；文件夹和普通文件只显示创建入口。

资源管理器一次可选择最多 128 个受支持的压缩包。批量解压依次处理，默认各自解压到源包所在目录，采用设置中的同名处理方式；一个包损坏或需要密码不会阻断后续包。批量结果分别显示成功、失败和取消，点击失败项的 **处理**，输入密码或调整编码后重新打开并解压。密码不会沿用到下一个压缩包。

多选后选择 **浏览压缩包** 不会自动解压，可在批量列表逐个打开。取消批量解压会停止当前操作并取消尚未开始的包；此前已完成的结果保留。文件夹打开开关同样生效，默认不弹出资源管理器。

这些入口已通过开发版的隔离协议和页面测试，正式安装后的 Windows 10/11 右键显示、更新及卸载行为仍待实际验收。

## 拖出选中内容

在文件列表中勾选多项，再拖动其中任意一项到资源管理器的目标文件夹。直接拖动未勾选的条目会改为只拖出该项。选择文件夹时包括全部子项；同时选择文件夹与其子项不会重复复制。有未保存的包内修改时，先保存或放弃修改。

拖出使用复制操作，不删除原压缩包中的内容。松开鼠标后由接收程序处理同名冲突，按 Esc 可以取消尚未落下的拖放。解压和内容传输由独立辅助进程处理；接收端结束异步操作并关闭内容流后清理暂存文件。压缩包在打开后发生变化时需要重新打开。

当前一次可勾选最多 10,000 项，展开目录后最多 65,536 个描述项。Windows 文件拖放描述中的相对路径须短于 260 个字符；超过时使用普通解压。原生内容流、多格式样本和页面路由已通过隔离测试，实际 Explorer 拖放、管理员启动与正式安装版仍待验收。

## 修改 ZIP 和 7Z 压缩包

打开单卷 ZIP 或 7Z 后，文件列表上方提供 **添加内容、新建目录、重命名、删除选中项**；ZIP 还支持 **备注**，7Z 不支持压缩包备注。修改先进入变更列表，可移除某项或放弃全部；点击 **保存修改** 查看完整预览并确认。重命名或删除目录时会包含全部子项，不限于当前已加载的一页。

添加时可以指定包内路径，例如 `文档/说明.txt`。已有同名目录会合并；只有明确勾选 **替换同名文件** 才会替换文件，文件和目录不会互相覆盖。修改加密包需要正确密码。ZIP 保留未修改条目的加密和压缩数据；新增内容在原包存在加密项时使用 AES 加密，替换项沿用原条目的是否加密状态。

7Z 通过引擎更新原归档，单纯重命名保留原压缩数据块；固实包删除或替换部分内容时可能重新压缩受影响的数据块，耗时与数据块大小有关。加密内容和原有的加密文件名模式会保留；原来可见的文件名不会因输入密码而改为隐藏。新增内容随原包的加密设置处理，不把普通包仅因填写密码而自动改为加密包。

保存会先校验原包，再重写到同目录临时文件并完整校验，最后替换原件。原包在浏览后发生变化时需重新打开，避免用过期条目修改新内容。取消在最终替换之前生效；最终保存期间短暂隐藏取消按钮。正常失败会保留原包并清理临时文件，Windows 替换异常时无法自动恢复的原件副本会保留在同目录，错误信息提供路径。

分卷 ZIP、分卷 7Z、RAR、TAR 和压缩流目前没有修改入口。ZIP64、大文件性能及断电恢复仍需进一步验证。

## 任务中心

概览页的 **任务中心** 会显示压缩、解压、校验、修改和拖出的当前阶段与进度，支持停止仍可取消的任务。停止页面发起的批量解压时，尚未开始的压缩包也会取消，已完成的结果保留。最终保存阶段停止按钮暂时禁用，以保护原文件。切换页面或关闭主窗口到托盘不停止归档任务；退出 One 会取消可取消的任务并等待最终保存阶段结束。

**最近记录** 包含完成、失败和取消的归档任务。点击记录可查看开始时间、耗时、处理数量、压缩包与结果位置，并返回压缩包浏览页；只有主动点击 **查看结果位置** 才打开资源管理器，不受“完成后打开文件夹”的自动打开行为影响。读取目录、翻页与搜索不会新增完成记录。

记录保存在本机，最多保留 100 条归档历史，概览汇总最近 30 条并显示最新六条。记录不保存密码、请求参数或压缩包内部文件清单。上次异常退出时仍在运行的任务会标记为 **上次异常中断**，不会自动重试；该标记不代表输出已完成或已经回滚，需要检查结果及可能存在的恢复副本。

## 文件关联与长期偏好

安装版本可在 **设置 → 压缩与解压 → 压缩包打开方式** 注册 One，再点 **设置默认应用**，在 Windows 中选择由 One 打开的文件类型。注册覆盖 ZIP、7Z、RAR、R00、TAR、TGZ、GZ、TXZ、XZ；不注册通用的 `.001` 扩展名，避免接管其他软件的分片文件。`.7z.001` 可在 One 页面或右键入口打开。

注册只把 One 加入可选程序，不更改原有默认应用。取消注册和卸载只清理属于当前 One 安装的注册信息；开发版禁用真实关联注册，避免覆盖正式版。

双击动作、默认压缩格式、同名文件处理和完成后打开文件夹均会保存在 One 设置中，并随设置备份导出和导入。升级会迁移旧的页面打开文件夹偏好，同名文件处理默认自动重命名。

## 命令行与批量任务

独立的 `One.Cli.exe` 已支持创建、列出内容、解压、校验、单卷 ZIP/7Z 修改和顺序批处理，不打开主窗口或文件夹。用法、密码输入、JSONL 输出及退出码见 [压缩命令行](压缩命令行.md)。开发构建已提供入口，正式安装发布仍需验收。

## 当前限制

分卷 ZIP/7Z 修改、更多 RAR 密码/分卷组合和命令行压缩等级/扫描选项仍在实现中。断电后的恢复界面，拖出功能的系统交互、目标程序崩溃恢复，以及文件关联和右键的正式安装版入口仍需完善或发布验收。异常退出留下的拖出暂存会在下一次启动或拖出时检查，超过 24 小时且不再被辅助进程使用才回收。完整范围见 [实现计划](../development/压缩与解压实现计划.md)。
