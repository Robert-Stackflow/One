# One 0.5 文本处理

更新日期：2026-10-01。参考本机 TextPro 6.5.1.0，路径 `D:\Portable Program\Text Pro\TextPro.exe`。已读取随软件提供的本机 CHM 帮助，未修改其设置或用户文档。

## 操作

现有简繁转换、全半角、整理空白、按行去重/排序、普通与正则替换继续保留。新增行首尾/行末空白处理、删除空行、段间空行、合并段内硬换行、中文段首缩进、简单排版、中文标点、竖排符号转横排、大小写、行倒序/自然排序、删除字母/数字/标点、Unicode NFC 规范化、控制行宽和括号配对检查，共 28 种操作。

段落合并保留空行，以缩进识别新段落；这些是可见的整理规则，并非对任何文档都能自动判断段落。括号检查报告位置，不擅自修改原文。简繁使用 OpenCC 现代词组转换，不承诺 TextPro 古籍、佛经和私有字表等价。

## 处理流程

常用按钮可立即处理；“加入流程”将当前操作及替换参数按顺序保存。流程支持调整顺序、删除、导入和导出，最多 64 步；最后编辑的流程保存在当前用户配置中。

支持 One JSON 流程，以及每行 `查找=替换` 的字面替换表（空行和 `#` 注释忽略）。TextPro 帮助确认其新版简单替换表也采用等号，但复杂规则、旧版空格分隔规则和专有正则字符类未实现兼容迁移。正则采用 JavaScript 语法，单步骤上限 5 秒；其他步骤上限 30 秒，可随时停止并继续下一次处理。

## 比较、批处理与合并

- “打开对照文件”读取到结果侧，“比较差异”显示原文/结果按行增删的位置，可逐组查看，支持忽略行边缘空白。不是三文件合并工具；单次比较最多 2,000 组差异，每组显示前 20,000 字符。
- 批处理接受文件和目录，支持递归、扩展名、输入/输出编码，按流程处理；最多 10,000 个文件。
- 结果写入选定输出目录下新建的 `One-处理-…` 或 `One-合并-…` 文件夹，输入原件不修改。已完成项目保留，失败逐项记录，取消会清理正在写入的临时文件。
- 合并按输入路径顺序执行；每个目录内部按自然路径顺序排列，可设置分隔文字。建议将输出位置放在输入树以外，避免下次递归把以前的结果再次纳入。

## 大文本

每个编辑框最多挂载约 50,000 字符，其余内容保存在分页缓冲中；编辑局部页不会丢失其他页。复制、保存和转换针对整份内容。分页边界保留 CRLF 与 UTF-16 代理对，读取、编辑后保留当前片段的换行形式。

转换、比较、批处理在可复用 Worker 中执行，停止会终止当前 Worker；下一任务重新创建。文件读取上限 20 MB，处理内容上限 1,000 万字符，合并结果同样有界。撤销最多 10 个快照、总计 2,000 万字符。

自动编码仅接受 UTF-8、带 BOM 的 UTF-16；GBK/Big5 等应明确选择。不能无损编码时拒绝保存。

开发环境实测：280 万字符/35 万行整理约 43 ms，界面心跳最大间隔约 18 ms；这是本机单次暖 Worker 数据，不是所有规则和机器的速度承诺。端到端回归还覆盖灾难性正则取消、取消后恢复、完整多页复制、批处理原件不变和有序合并。最终发布包实测见 [0.5 验收](../history/验收-0.5.md)。
