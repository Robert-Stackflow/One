# One 0.12 验收：统一预览侧栏与连续阅读

日期：2026-10-01。项目：`D:\Repositories\One`。
发布程序：`release\0.12.0\win-unpacked\One.exe`，保留完整目录。

## 本轮变化

- 移除预览右侧详情栏。左侧统一文件、详情、目录；无文字目录时隐藏目录页签。PDF、DOCX、PPTX 另有概览，以页面缩略图导航。
- 侧栏和源码 / 预览使用主界面同款胶囊分段选择器。侧栏折叠、置顶、保持集中在左上；保持使用 Lucide SquareMousePointer 图标。栏宽、页签、置顶与保持自动记忆；旧右侧详情选项迁移到左侧详情。
- 文件页签下，单击文件夹仅预览，双击进入。目录导航不随单击预览强行改变。图标位于文件名前，使用 VSCode Icons 扩展官方 SVG，包含按名称分类的打开 / 关闭文件夹和明暗变体。
- 打开方式从 Windows 注册处理程序读取真实应用图标，以 PNG 数据直接传输；图标不可用时回退。主窗口、搜索、文件选择和预览统一自绘窗口按钮，保留 Windows 原生厚边框、缩放与 DWM 阴影。
- PDF / 幻灯片改为连续滚动页面；可见页按需绘制，远端页面释放。Word 使用连续文档，概览缩略图按需生成。概览随当前阅读页更新选中状态。
- Word 目录读取 OOXML 标题样式、大纲级别、中文样式名和继承关系。PDF 优先真实书签；无书签时尝试按字号识别标题。文字目录与“第 X 页”概览分离。

## 具体边界

- 没有书签的 PDF 使用字号启发式识别前 300 页，标题可能不完整；扫描型 PDF 未提供 OCR。查找范围为前 2,000 页，缩略图只在打开概览并进入可见范围时绘制。
- Word 页数遵循 docx-preview 的分页与文件中的分页信息，不保证与 Microsoft Word 完全一致。复杂排版 / 图表、PPT 动画 / SmartArt / 组合变换仍受原渲染器能力限制。
- 本轮针对 DOCX / PPTX；旧二进制 DOC / PPT 仍显示文件信息并提供系统打开方式。不会执行宏、脚本或嵌入程序。
- 系统提供的推荐程序才进入打开方式列表，不保证枚举全部安装应用；缺少有效图标的程序使用回退图标。

图标来源：[VSCode Icons](https://github.com/vscode-icons/vscode-icons)。完整格式范围见 [预览与外观](../user-guide/预览与外观.md)。
