# One 0.15.1 发布记录

日期：2026-10-02。发布目录：`release\0.15.1\win-unpacked`。

## 修复

- 修复退出时两次“Object has been destroyed”报错：两个预加载的搜索窗口关闭后，清理代码仍读取它们的 `webContents.id`。现在在创建时保存标识，关闭后只清理缓存和状态；同时释放当前搜索引用、延迟回复及资源管理器附着位置计时器。
- 系统右键菜单返回时使用事先保存的所属窗口标识，允许在等待系统菜单时退出或关闭所属窗口。
- 自定义文件右键菜单的子菜单箭头改用统一的 Lucide 图标。
- 菜单根据实际菜单项高度撑开，重新打开和缩短内容不会沿用旧窗口的留白。超过屏幕工作区减去上下留白时才滚动。
- 打开方式子菜单省去重复标题；没有推荐应用时不显示空分隔线，只保留“选择其他应用”。

## 验证

- 旧 0.15.0 发布包复现两次相同的退出异常，堆栈均指向搜索窗口的关闭处理。
- 类型检查与 49 项自动测试通过。
- 源码退出回归通过：正常退出及打开搜索、预览、右键主菜单/子菜单后退出，均没有未捕获异常或错误弹窗；主进程自然结束，退出码为 0。
- 菜单布局回归通过：反复打开高度一致，最后一项到底部保持 7 DIP 内边距；空打开方式子菜单没有多余标题或分隔线，不出现滚动条。
- 最终 0.15.1 发布包通过正常退出、关闭并重建两个搜索窗口后退出、打开预览和级联菜单后退出三种回归；异常数均为 0，主进程均自然结束，退出码均为 0。
- 发布包版本、主程序/预加载代码及 7 个原生辅助程序与本次构建一致。
- 最终发布包的搜索、右键重命名、真实打开方式列表、子菜单向左展开、屏幕边界滚动限制及原有界面回归通过。

## 使用

退出托盘旧版后，打开 `release\0.15.1\win-unpacked\One.exe`。保留整个目录，沿用现有配置和索引。
