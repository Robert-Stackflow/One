# One 0.15 发布记录

日期：2026-10-02。发布目录：`release\0.15.0\win-unpacked`。

## 本次修改

- 搜索结果使用自定义右键菜单，主菜单立即显示常用操作，不等待 Windows Shell 菜单扩展枚举。支持打开、快速预览、打开方式、资源管理器定位、复制、剪切、复制路径、重命名和移入回收站；完整系统功能仍可通过“更多系统操作”进入。
- 打开方式采用独立级联子菜单，悬停或点击展开，主菜单保持原位；屏幕右侧空间不足时自动向左展开。支持方向键、Esc、鼠标跨菜单操作，应用图标按需读取并缓存。原有多级快捷菜单继续以独立浮窗逐级展开。
- 菜单按内容撑开，不设置固定小高度；超过所在屏幕工作区高度减去上下各 8 DIP 留白时才出现滚动条。父菜单与子菜单分别测量、约束高度。
- 双按 Ctrl 和搜索快捷键打开的独立搜索增加程序、设置筛选。读取 Windows AppsFolder 注册的桌面及商店应用，通过系统入口启动；Windows 设置提供 52 个常用入口，支持名称、别名和拼音搜索。文件索引未配置时也能搜索程序与设置。附着搜索和文件夹跳转保持文件范围。
- 程序目录与设置入口仅存于内存，不加入文件索引的磁盘快照和文件计数；程序目录后台刷新，刷新失败时保留原结果。
- 修复多个搜索窗口共享查询取消状态的问题。取消按窗口隔离，旧查询明确返回取消标记；界面等待新查询完成后再替换结果，取消响应不被显示为“没有结果”。隐藏窗口不再因索引状态通知重复查询。
- 独立搜索去掉额外绘制的圆角内边框，保留 Windows 原生外边框和阴影。附着搜索内容精确填充窗口，保留一层细边框，去掉底部溢出的留白。
- 置顶页面左右卡片同高，由设置卡片确定高度；右侧列表独立滚动，滚动条贴卡片内边缘，标题固定。窄窗口改为上下布局。
- 文件复制和剪切使用 Windows 文件剪贴板数据格式；重命名不覆盖已有同名文件。连续打开菜单与子菜单的焦点、过期操作回复均有隔离。

## 验证

- 类型检查与 49 项自动测试通过。
- Rust 6 项测试通过；百万条目性能测试保持按需运行，不作为普通回归。
- 原生搜索回归：60 个不同窗口的并发查询互不取消，同窗口 50 次快速查询保留最后结果；程序/设置分类、拼音、文件夹过滤和重启不持久化程序目录通过。
- 本机读取到 219 个注册程序，包含 QQ；AppsFolder 程序图标、文件复制/剪切格式只读检查和重命名拒绝覆盖通过。
- Electron 界面回归：QQ 文件与程序结果稳定、程序/设置筛选、右键重命名与打开方式、无滚动条的普通菜单、屏幕留白约束、独立级联与向左展开、单层边框、等高卡片及贴边滚动条通过。

- 最终 0.15.0 发布包通过上述界面回归及原有搜索交互回归；版本、主程序/预加载代码与 7 个原生辅助程序校验一致。发布包右键菜单首次显示测试约 133 ms（含测试操作与验证开销）。

## 使用

退出托盘中的旧版本，再打开 `release\0.15.0\win-unpacked\One.exe`，保留整个目录。正式配置与文件索引沿用原位置。

本轮验证使用隔离测试目录和配置。程序入口、设置 URI 和剪贴板协议已验证；没有为测试启动 QQ、修改 Windows 设置或覆盖用户剪贴板。特殊 Shell 扩展仍通过“更多系统操作”调用原生菜单。
