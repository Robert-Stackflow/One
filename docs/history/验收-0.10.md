## 使用

1. 从托盘退出旧版 One，再运行新版 `One.exe`，保留完整 `win-unpacked` 目录。
2. 预览左上角控制文件/目录侧栏，右上角详情图标控制详情栏；拖动中间分界调整宽度。
3. 图钉控制置顶，书签控制保持；这两个开关与栏宽会在下次打开时恢复。
4. JSON/YAML 默认源码，格式化按钮只调整展示；“预览”切换结构树，`Ctrl+F` 查找源码全文。
5. 默认打开按钮右侧的下拉可选择系统推荐应用；“选择其他应用”使用 Windows 提供的应用选择窗口。

## 边界

Office 仍以基础内容预览为目标，复杂图表、SmartArt、动画和全部排版保真未实现。工作表保留每页 100 行的网格；普通文本/代码已取消翻页。旧二进制 DOC/PPT/XLS、RAR/7Z 仍未支持。格式化与渲染视图上限为 5 MB，超过使用连续源码视图。

音乐仅显示文件实际包含的封面/标签，或同名 `.lrc`；不下载封面和歌词。音视频容器中的编码仍需 Chromium 支持。源码预览为只读，不保存文件。支持矩阵及全部上限见 [预览与外观](../user-guide/预览与外观.md)。

验证环境为本机 Windows 11 x64；多屏混合缩放、干净机器安装及不同系统关联应用的调用仍需扩大兼容验证。
