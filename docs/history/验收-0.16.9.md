# One 0.16.9 后台页面与缓存校验

发布目录：`C:\Users\ruida\Documents\Codex\2026-09-13\dioa\release\0.16.9\win-unpacked`。运行 `One.exe`，保留整个目录。四项文件工具与概览已包含在发布包中；本轮继续优化后台工作与菜单生命周期。测试使用独立资料目录，不修改或结束用户正在运行的旧版实例。

## 本轮变化

- 主进程提供真实窗口可见状态。概览、系统信息、写入活动及相关操作增强信息在隐藏或最小化时停止展示采样，重新显示后恢复；延迟到达的请求不能重新启动隐藏页面的写入枚举。
- 后台容量告警、主动文件跟踪及已启动的文件工具任务继续运行。系统信息分组任务可以完成并缓存数据；隐藏期间不反复改写页面。
- 概览合并重叠刷新，丢弃过期响应，仅更新实际变化的数据。隐藏搜索窗口取消待发查询，闲置时启用后台节流，显示时恢复交互更新。
- 离线目录校验提前按根目录、排除目录和缓存目录筛选，每批最多检查 8,192 条缓存记录；共享路径存储，批次间释放锁并保留取消检查。空索引范围不再检查无关目录。
- 菜单失焦的延时关闭核对窗口可见状态与当前会话，避免旧菜单的回调关闭后来展开的新菜单。共享初始快照订阅保留后到的新事件，避免旧的初始读取覆盖刚展开的菜单内容；共享窗口就绪状态记住首次绘制，避免误用加载状态而再次等待已经发生的就绪事件。首次绘制可以早于加载完成，依据 [Electron 窗口显示文档](https://www.electronjs.org/docs/latest/api/browser-window#using-the-ready-to-show-event)。

## 普通隐藏状态的短窗口对照

0.16.8 与本轮版本依次使用同一份 200 万项冻结缓存、独立配置、开启容量监控，关闭通知和全局输入挂钩。使用真实发布程序，短暂连接主进程诊断观察器后断开，再隐藏窗口并采样约 30 秒；没有连接渲染器调试器、模拟焦点或关闭 Chromium 后台限制。两次采样的进程集合均稳定，整个测试进程树纳入统计。

| 指标 | 0.16.8 | 0.16.9 本轮候选包 |
| --- | ---: | ---: |
| 单核 CPU 百分比 | 2.244% | 0.520% |
| 隐藏主页面 DOM 变化次数 | 2,912 | 0 |
| 隐藏后私有提交 | 1,196.2 MiB | 1,116.8 MiB |
| 隐藏后物理驻留 | 1,237.4 MiB | 1,154.5 MiB |
| 缓存加载完成 | 1.98 秒 | 2.09 秒 |
| 离线校验就绪 | 12.73 秒 | 2.09 秒 |

该单次样本 CPU 下降约 76.8%、私有提交下降约 6.6%；不代表小时级后台或所有机器的稳定降幅。物理驻留受 Windows 回收影响。缓存样本的根目录设置为空：本轮直接跳过无关目录校验，不能据此宣称真实百万目录的启动校验只需 2 秒。两个版本都在缓存加载后即可检索；有实际索引范围时仍须检查相关目录，发生变化的目录集合仍可能较大。

上述采样发生在最后的菜单失焦修复之前；采样涉及的可见性、监控和索引代码与最终包相同，期间未操作菜单。两次观察程序均自然退出码 0。

### 之前采样方法的补充说明

0.16.8 的 Playwright 发布包测试没有注入开发程序的后台启动参数，但渲染器连接启用了焦点模拟。之前记录的隐藏 CPU 因此属于受控测试环境，不能当作普通后台空闲指标；同一测试方法下的内存对照仍保留原始范围。此次改用断开调试连接后的原生隐藏状态检查，未更改或删除之前的数据。
