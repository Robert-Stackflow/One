# One 0.16.6：大型文档全文搜索

发布入口：`release\0.16.6\win-unpacked\One.exe`。请保留整个目录，旧版先从托盘退出。

本包包含概览、重复文件查找、文本/二进制/文件夹 diff、PowerRename 风格批量重命名及撤销、文档全文搜索，保留 0.16.1–0.16.5 的改进。

## 本次变化

Office 正文按 ZIP 条目及 XML 片段连续读取，不再先解压所有正文、再建立完整节点树。正文每段最多 16,000 字符，保护 Unicode 字符边界；Word 段落、换行和制表符、表格共享/内嵌富文本、数值和公式、PPT 数字页序，以及 OpenDocument 文本均有回归验证。大型 Excel 的共享文本使用 SQLite 临时表，限制临时页缓存，不把全部文本保留为 JavaScript 对象。

EPUB 按章节逐一提取，不再同时保留全部解压章节。PDF 与解析器共用文件字节存储，减少整份文件的额外复制；逐页提取，释放页面资源，显示提取页数，加载失败也释放解析任务。PDF 仍读取整份文件，解析器自身存在内存成本，不宣称所有格式都为恒定内存。

正文搜索结果的行号改为实际匹配所在的提取文本行，修复只显示索引片段起始行的问题。界面中 PDF 显示真实页码，PPT 显示幻灯片张数，Word 等正文显示行位置，Excel 另显示工作表位置。Word 的行号表示提取正文行，不是 Word 的版式页码；Excel 每个单元格对应一行。

停止索引会终止自己的后台任务，未完成的单份文档事务回滚，保留此前索引；再次更新可正常完成。损坏和没有文字的 PDF 会列为未完成项，不妨碍有效文档索引。

升级已有正文索引后，请在“文件工具 → 全文搜索”点击一次“更新索引”。旧缓存会按新提取版本刷新，即使文件修改时间没有变化；成功后继续复用未变化的文档，不在启动时强行进行大型索引。

## 边界

保留现有大小限制：Office/电子书压缩文件最多 50 MB，单份正文条目最多 32 MB、选中正文解压总量最多 64 MB；PDF/普通文本最多 100 MB，HTML/RTF 最多 20 MB。新增 ZIP 目录 100,000 项保护。正文索引不提供图片 OCR，不处理加密文档及旧二进制 DOC/XLS/PPT。共享文本临时表需要可用磁盘空间；本次没有降低正文大小限制来规避大型文件。

## 验证与性能

原先支持的 UTF8/GBK/UTF16、Word、PPT、Excel、EPUB 和 PDF 回归通过；新测试覆盖富文本/实体/Unicode/换行、UTF16 XML、OpenDocument、损坏文档、解压上限、停止后的索引恢复与旧缓存升级。

最终代码通过类型检查及 83 项自动测试。发布包的四项文件工具、概览、Word/Excel/PDF 提取中触发真实停止按钮、保留旧索引后重试、旧缓存刷新及后续复用，以及 Word 第 70,000 行的界面标注均通过，无页面异常。143 项代码/样式/后台入口与 7 个原生辅助程序一致性校验通过。

同机、隔离资料目录的源码初测：7 万段 Word 索引约 3.48 秒 → 0.91 秒；任务新增私有提交峰值约 247 → 40 MiB，新增私有物理驻留约 234 → 23 MiB，末段行号正确为 70,000。12 万行、24 万单元格 Excel 的旧发布包达到后台线程内存上限，无法完成；新版约 1.94 秒完成，新增私有提交峰值约 24 MiB，末尾标记正确搜出。旧包失败信息已另一次单独复核，不能把失败耗时当作成功性能。

约 60 MB / 500 页含图 PDF 单独冷启动对照：旧 0.16.5 约 1.45 秒，新源码约 0.92 秒；任务新增私有提交峰值约 224 → 154 MiB，新增私有物理驻留约 167 → 107 MiB。末页标记匹配在第 500 页。20 ms 页面心跳 P95 约 21–22 ms；导航约 29–36 ms。

内存为本测试初始进程树的峰值增量，100 ms 采样，包含 Electron 及原生辅助程序；不是软件长期后台总占用。Word/Excel 为相同顺序工作流，PDF 为单独冷启动对照；源码数值不混作最终发布包保证。证据：`work/document-large/before-0.16.5.json`、`before-0.16.5-sheet.json`、`source-streaming.json`、`before-0.16.5-pdf.json`、`source-shared-pdf.json`。
