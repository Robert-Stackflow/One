# One 0.16.1：文件工具、概览与索引内存

发布入口：`release\0.16.1\win-unpacked\One.exe`。旧版先从托盘退出，保留整个发布目录后启动。

## 功能入口

默认进入「概览」，可查看索引状态、磁盘容量、常用工具和最近任务。四项新功能统一位于「文件工具」：重复文件、文件对比、批量重命名、文档全文搜索。

重复文件完成全内容 SHA-256 校验；对比支持文本、二进制与目录；重命名先预览、检查冲突，支持撤销；全文搜索在本机提取正文并建立增量索引。格式、限制与操作说明详见 [0.16 功能验收](验收-0.16.md)。扫描型 PDF 暂无 OCR，旧 DOC/XLS/PPT 暂不支持正文索引；批量重命名为 One 的 PowerRename 风格实现。

## 内存与搜索对照

改为从路径直接取得文件名，仅需要时存储小写名称；非中文文件不保留空的拼音容器，中文拼音采用紧凑数组。保留旧版磁盘缓存与通信协议，升级无需重新建立全部索引。

测试取自当前 200 万项真实缓存的只读副本。旧、新辅助程序交叉运行两轮，统一缓存内容与查询；在副本中移除扫描根以固定结果，仍进行目录签名验证。没有改写用户缓存或停止用户运行的软件。以下只计索引辅助进程，不是整个 Electron 软件：

| 指标 | 结果 |
| --- | --- |
| 验证完成后私有内存平均 | 1,399 → 1,036 MiB，降低约 26% |
| 加载时驻留内存平均 | 降低 25.6% |
| 运行期间峰值驻留平均 | 降低 25.2% |
| 缓存加载两轮 | 旧版 1.93 / 1.85 秒；新版 1.96 / 1.52 秒 |
| 10 类查询 | 每类重复 3 次，总数与前 100 条内容/顺序全部一致 |
| 中文/全拼/首字母/类型/路径/容错 | 均通过，测试中查询中位耗时约 152–495 毫秒 |

Windows 会回收工作集，验证完成后瞬间驻留没有稳定下降，不将该数字当作后台常驻优化结论。查询是两百万项线性扫描，结果耗时不等于窗口弹出耗时；没有宣称所有大规模搜索均低于这些数值。原始数据位于 `work\index-memory\latest.json`，可用 `tests\index-memory-benchmark.cjs` 对相同缓存复验。

## 回归验证

- Rust 7 项测试通过：路径切片、多语言名称、中文/拼音/模糊匹配、程序与设置显示名、缓存压缩/恢复；1 项大规模人工基准默认跳过，另以真实 200 万项对照验证。
- 59 项应用测试通过，类型检查通过。
- 实时新增、删除、目录改名、仅大小写改名；离线新增/删除/改名；追加日志、内容写入不重建；损坏尾部恢复、联接边界和扫描取消后的补漏均通过。
- 程序/设置搜索及拼音、60 个独立查询作用域、50 次连续查询保留最后结果通过。

## 实际发布包验证

- 包内版本为 0.16.1，139 项编译代码/样式和 7 个原生辅助程序与当前构建逐项一致。
- 概览、重复文件、Diff、重命名执行/撤销/规则更新预览、全文搜索、任务历史和 SegmentTab 键盘导航通过，无页面异常。
- 本次小样本重复查找约 117 ms，8 份文档首次提取与查询约 1.36 秒；两份 128 MB 文件校验期间导航约 31 ms，20 ms 心跳的 P95 间隔约 21 ms，最大约 39 ms。该场景 Electron 驻留快照约 838 → 843 MB，未计原生辅助程序，不代表后台驻留对照。
- QQ 文件与程序结果稳定、类型/设置筛选、独立级联菜单与左右翻转、菜单按屏幕限制滚动、单层边框、窗口卡片高度和附着搜索底边通过；菜单首次展示约 131 ms。

整个应用后台内存、各主要页面交互与剩余大文件任务继续优化；本版只报告已经实测的结果。
