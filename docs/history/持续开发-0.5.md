# One 持续开发目标

开始：2026-10-01。基线：已验证的 Electron 0.4；项目位置 `D:\Repositories\One`。

## 本轮范围

1. 参考 PowerToys 源码实现唤醒、外部窗口始终置顶、File Locksmith 文件占用检测与结束占用进程。
2. 扩展预览类型，为表格、电子书、字体等常见类型提供专用视图，并改善代码/大文本阅读。
3. 研究本机 TextPro 6.5.1，补充文本处理、规则和大文本性能；长任务可取消，不在渲染线程完成整份转换。
4. Listary 重新纳入范围，优先：资源管理器直接输入搜索、独立文件搜索窗口、资源管理器空白处双击菜单、打开/保存对话框跳转到已打开目录及目录搜索跳转。此前“不纳入 Listary”的约定由本轮指令替代。

保留现有原生窗口控件、Lucide 图标、自定义表单、简洁文案及明暗设计。先实现和验证可用功能，再打包；不能将占位界面或尚未验证的系统集成计为完成。

## 开发顺序

- 参考软件与源码调研，固定功能清单和失败边界。
- Windows 工具：唤醒与窗口置顶，再做独立辅助进程中的文件占用扫描。
- 文件搜索索引与查询，然后接入资源管理器和文件对话框。
- 扩展文本与预览，执行大文件性能和实际窗口回归。
- 更新使用说明、兼容边界、验收记录，交付新的目录包。

## 调研依据

PowerToys 源码提交：`661596e6dd9f789bbba9c44458610499e64ab9cf`。

- Awake：`src/modules/awake/Awake/Core/Manager.cs`，SetThreadExecutionState、锁屏状态、限时和截止时间。
- AlwaysOnTop：`src/modules/alwaysontop/AlwaysOnTop/AlwaysOnTop.cpp`，SetWindowPos、重复触发取消、排除规则和窗口跟踪。
- File Locksmith：`src/modules/FileLocksmith/FileLocksmithLibInterop/NtdllExtensions.cpp`，系统句柄、复制句柄、文件路径及模块枚举；源码明确记录部分原生查询可能挂起，因此扫描必须与主进程隔离，并明确超时和未完成项。

官方来源：[PowerToys 源码](https://github.com/microsoft/PowerToys/tree/661596e6dd9f789bbba9c44458610499e64ab9cf/src/modules)、[Awake](https://learn.microsoft.com/en-us/windows/powertoys/awake)、[置顶](https://learn.microsoft.com/en-us/windows/powertoys/always-on-top)、[File Locksmith](https://learn.microsoft.com/en-us/windows/powertoys/file-locksmith)。

本机 Listary 6.3.5.93：已查看选项中的菜单与集成入口，菜单包含文件夹、分组、分隔线和命令；官方文档确认空白处双击触发、目录建议、Ctrl+G 和搜索目录跳转。不会读取或迁移用户现有私有命令配置。

[文件搜索](https://help.listary.com/search-file)、[Quick Switch](https://help.listary.com/quick-switch)、[双击菜单](https://help.listary.com/options-menu)。官网当前包含 v7 的新增语法，实施时区分本机 v6 已有体验与扩展能力。

本机 TextPro 6.5.1.0：读取安装目录中的 CHM 帮助，核对段落整理、替换表、文本比较、批处理和文件合并等操作。One 0.5 实现 28 种操作、流程、行差异、批处理和合并；复杂私有规则与古籍字表不视为已迁移。对应规则及编码边界见 [文本处理](../user-guide/文本处理.md)。
