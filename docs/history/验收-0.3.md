## 具体证据

- 导航、菜单、目录树、加减、勾选和浮层统一使用 Lucide。预览工具栏的“打开”为带悬停名称的图标；最小化、最大化/还原、关闭仍使用原自绘窗口图形。
- 浅色侧栏为 `rgb(246, 246, 246)`、工作区纯白；深色侧栏 `rgb(20, 20, 20)`、工作区 `rgb(24, 24, 24)`。
- Windows 11 关闭 DWM 外沿描边的原生调用返回成功。
- 原生 HUD 截图的角落 alpha 为 **0**，内容中心 alpha 为 **245**。音量/亮度浮层与组合键键帽均检查截图。
- 12 类真实样本：TXT、Markdown、HTML、JSON、YAML、CSV、文件夹、ZIP、APK、DOCX、PPTX、PDF。图片与音频另由回归流程验证。
- Markdown 本地图片成功解码；HTML 移除脚本与跳转；JSON/YAML 可切换结构与源码；Office 展开超限样本显示错误；APK 二进制清单正确读取包名和版本。
- PDF 自绘翻页、查找、文字层及旋转通过。旋转后的高亮与文字位置一致；未嵌入 Chromium 原生阅读器。
- 预览默认隐藏文件列表；保持后失焦不关闭，关闭保持后失焦自动关闭；置顶实际改变原生窗口层级。双侧面板与长行正文没有导致窗口横向溢出；盘符根目录可以浏览和返回上级。
- 从实际桌面色块拾取 `#123456`，剪贴板结果准确为 `#123456`；截图纵横比与屏幕一致。通过任意一个取色窗口的原生关闭事件取消时，所有屏幕上的取色窗口一并关闭。
- 实际目录扫描处理 **13,636** 个文件，收到 **10** 批渐进结果；另一轮取消后保留 **1,483** 个已扫描文件，随后重新扫描成功。
- 只读启动项检查返回 **85** 条记录。硬件亮度只读检测：内置 NE160QDM-NYJ 为 90%；外接 P27H2R 当前接口不可用。测试未调节用户的系统音量或亮度。

## 已知边界

DOCX/PPTX 支持基础内容，复杂 Office 排版、图表与动画未完全覆盖；旧 DOC/PPT、RAR/7Z、XLS/XLSX 暂不支持。PDF 为单页阅读，未提供 OCR、批注编辑和密码输入。

取色为 SDR 8 位采样；HDR、广色域、远程桌面、更多混合缩放与显示器排列仍需兼容验证。自定义热角动作的配置与参数通过验证，具体外部应用的快捷键行为仍须按目标应用验证。

系统维护仍为只读检查，本轮不包含注册表删除和启动项禁用。完整格式边界与实现方式见 [预览与外观](../user-guide/预览与外观.md)，后续范围见 [开发计划](../development/开发计划.md)。
