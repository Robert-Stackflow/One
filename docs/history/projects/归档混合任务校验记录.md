# 归档混合任务校验记录

## 范围与环境

本阶段基于 `9d5a5a8`，补充压缩归档计划中的混合任务验收及完整解压等待诊断；未修改产品调度器或引擎。沿用[固实包阶段](归档固实包校验与修复记录.md)的 4.125 GiB 单固实块样本，同一 Windows 本地磁盘环境，服务默认任务资源为 1 线程、256 MiB。样本、诊断组件哈希、各轮计数与混合任务摘要保存在[测量数据](measurements/archive-mixed.json)。

## 真实混合任务

`tests/archive-mixed.cjs` 启动三个独立 Node 服务进程，复用产品跨进程预算组件及真实原生辅助程序。测试使用私有预算作用域，避免改变正在运行的 One 实例。大任务选择固实块尾部的 1 KiB 文件，必须解码此前约 4.125 GiB 数据；小任务使用 128 项 ZIP 和 8 MiB 确定性输入。

| 场景 | 已验证行为 |
| --- | --- |
| 并发 2、内存 512 MiB、线程 2 | 浏览、ZIP 创建及校验均在固实尾项完成前返回；浏览约 48 ms，尾项约 2.15 s。尾项与新 ZIP 解压结果均核对 SHA-256。 |
| 并发 1 | 运行中的尾项占用槽位，随后创建与校验按 FIFO 完成；取消队列中的另一创建任务后，没有输出文件，后续任务继续。 |
| 并发 3、内存 512 MiB | 384 MiB 解码任务运行时，256 MiB 队首任务等待，后来的 128 MiB 浏览也等待；取消队首后，浏览在解码完成前返回。覆盖三个独立进程之间的内存预算与不插队行为。 |
| 并发 3、总线程 2 | 两线程解码运行约 300 ms 后，单线程校验仍等待；取消解码后，校验完成，解压目录为空，三个服务均可继续校验。 |

最终四个场景通过，共四次输出哈希核对。该结果覆盖本地磁盘及上述资源组合，不代表桌面界面、所有格式、慢盘或网络盘混合负载全部验收。

## 完整输出等待诊断

先前未插桩的基线有两轮完整输出耗时 13.76–14.98 s，CPU 时间与正常轮次接近。本次将旧基线 `ab5aaf8` 与修复版的 `sevenzip.cpp`、`extract-space.cpp` 分别编译为独立诊断程序；保留各自原有 7z 引擎及预算库，未覆盖正式组件或先前冻结样本。以 A-B-B-A-A-B 顺序各测三轮完整输出，每轮核对三个文件哈希，共 18 次核对。

六轮完整服务请求耗时 3.79–3.98 s，未复现长等待。被插桩的两个编译单元中，文件写入累计 1.42–1.59 s，最大单次约 23.4 ms；磁盘空间查询累计 26.7–29.8 ms。提取区间约 3.76–3.94 s，计时范围从调用 SDK Extract 前至 `seven_extract` 返回，包含该函数收尾，不包含外层启动、发布或稍后的输入句柄析构。API 统计不覆盖全部系统调用，进程 I/O 计数也不等于物理磁盘流量。

由于慢轮次未出现，现有统计不能定位先前等待发生的位置，不能归因为杀毒软件、磁盘缓存、驱动或本次修复，也不据此宣称吞吐提升。诊断程序会影响运行时序，本次正常区间不能证明原波动已消失。若再次出现慢轮次，应使用相同计数并增加线程等待跟踪，而不是改写此前测量结论。

## 复现、证据与清理

先执行正常构建，保留固实样本与 `manifest.json`，再运行 `npm run test:archive-mixed`；也可运行 `node tests/archive-mixed.cjs <样本目录>`。生成大样本的方法见固实包阶段记录。可通过 `ONE_ARCHIVE_MIXED_REPORT` 将最终摘要与有界事件写到一个尚不存在的路径；测试拒绝覆盖现有报告。该测试依赖大样本，未加入默认离线测试集合。

本地完整混合事件及日志位于 `work/current/archive-solid/mixed-final.json`、`mixed-final.log`。诊断构建、计数头及驱动脚本为同目录的 `build-profile.cjs`、`profile.h`、`run-profile.cjs`、`profile2-probe.cjs`，六份报告为 `profile2-1-probe.json` 至 `profile2-6-probe.json`；追溯哈希在测量数据中。原始诊断首次未产生统计，后改为显式局部报告对象；失败日志保留，未作为测量数据。

最终混合测试、脚本语法、文档链接与差异检查通过。正常轮次的临时输入、输出及服务进程均已释放；首次诊断中断遗留的私有解压临时目录也在核对名称、尺寸、真实路径和非链接属性后回收，释放 4,429,190,144 字节。保留压缩样本、冻结组件及小份证据，供后续波动复现使用。
