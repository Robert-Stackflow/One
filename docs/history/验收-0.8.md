# One 0.8：即时设置、搜索入口与菜单

日期：2026-10-01。项目：`D:\Repositories\One`。发布程序：`release\0.8.0\win-unpacked\One.exe`。

## 本轮改动

- 侧栏底部只保留“设置”，移除 One / 退出行。设置采用分类与内容双栏，包含基本设置、外观和关于；侧栏折叠有宽度与标签过渡，支持系统减少动态效果。
- 所有功能页共用 1120 px 最大内容宽度。输入、数字和快捷键控件的聚焦只改变自身细边线；分段页签统一胶囊圆角。移除重复说明、手动保存按钮和“已保存”等常驻状态文案。
- 设置逐字段自动保存，主进程串行合并与校验，不覆盖其他页面同时修改的字段。完整配置接口保留用于迁移和测试；产品界面使用局部更新。开关和选择立即提交，文字输入短暂防抖，失焦时提交。
- 文件搜索分为搜索、索引、快捷菜单三个页签。菜单采用层级树与属性面板，支持五层嵌套、添加子项、同级排序、拖入子菜单、选择上级、显隐、导入与导出。现有项目修改自动生效，新增项目补齐内容后添加。
- 本地 Lucide 图标选择器包含 2,113 个名称，可用英文和常用中文词搜索，支持键盘移动；分批显示结果，菜单配置保留图标名称。
- 搜索钩子不再过滤所有注入事件，仅排除自身重放。这样远程桌面和本机物理输入共用同一逻辑。快捷键录入结束、窗口失焦后恢复监听；搜索辅助进程异常退出最多自动重连三次。
- 取色浮窗移除屏幕捕获排除，远程桌面可显示浮窗；增加窗口就绪时的显示保障，重做放大镜、色值和操作提示。仍为实时采样，鼠标穿透、不抢焦点。

## 验证

- TypeScript 检查通过；26 项逻辑测试通过，包括五层菜单深度限制。
- 新增即时设置流程：检查九个页面等宽、无保存设置按钮、聚焦边线、并发字段更新、重启持久化、嵌套菜单、图标搜索选择和侧栏动效。
- 36 种布局组合：九页 × 浅/深色 × 840/1240 窗宽，无横向溢出；32/28 px 控件尺寸一致。
- Computer Use 在本机 Windows 11 / Parsec 环境实测：资源管理器输入首字符后出现附着搜索框并保留输入；双击空白处出现快捷菜单，右方向键展开子菜单；双 Ctrl 和独立快捷键打开搜索窗口；地址栏输入不触发搜索；取色浮窗可见且不抢焦点，Esc 取消。
- 13 组最终发布包流程全部通过，汇总见 `work/regression-0.8.0/final-result.json`。首轮发布包验证发现新窗口较晚到达的重置事件可能清除早期输入，已分离首次初始化与复用窗口重置，并用就绪握手重放资源管理器首字符。复测验证首次输入、再次打开清空及真实 Explorer 首字符保留；另模拟监听辅助进程中断，观察到自动启动替代进程。首轮源码检查中的旧测试曾要求“操作监听已开启”文案非空，该文案按本轮需求移除，测试改为检查实际设置与监听状态后通过。

原生操作记录：`work/redesign-0.8/native-verification.json`。截图位于 `work/preferences-smoke`、`work/ui-polish-smoke`、`work/redesign-smoke`。字体专项仍读取实际中文字形来源，而非只检查 CSS 字体名称。测试均使用独立配置，未覆盖正式用户配置或旧发布目录。

## 边界

菜单文件夹动态展开、命令参数和环境变量沿用原有执行规则。更深菜单不能导入；自绘文件对话框、管理员窗口和全部 IME / 混合 DPI 组合未穷尽验证。取色仍为 SDR 8 位采样。系统维护仍为只读检查；本轮没有增加注册表删除或启动项禁用。
