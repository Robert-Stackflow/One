# One 0.4 验收记录

日期：2026-10-01。项目：`D:\Repositories\One`。环境：Windows 11 x64、Electron 44.5.1、Node.js 22.16。

发布目录：`release\0.4.0\win-unpacked`。运行 `One.exe`，保留完整目录。EXE 文件版本为 0.4.0、产品版本 0.4.0.0。运行前退出正在驻留的旧版 One，避免单实例机制打开旧窗口。

## 本轮交付

| 用户要求 | 实现与结果 |
| --- | --- |
| 重新设计 UI | 重写设计系统，统一按钮、输入、下拉、开关、排版和留白；重新组织媒体和取色页面；明暗主题、紧凑窗口、轻量动效及减少动态效果支持 |
| 音视频打开/关闭/拖动 | 打开自动播放；切换时暂停、清除 src 并释放媒体；原生 close 先静音后销毁。修复文件协议分段响应和进度回写冲突 |
| 原生窗口外观 | 主窗口、预览、文件选择均使用 Windows 原生最小化/最大化/关闭及边框阴影；标题内容自定义，不再覆盖 DWM 外沿颜色 |
| PowerToys 式实时取色 | 查阅官方源码后重写为局部 GDI 持续采样及光标旁小浮窗；不冻结桌面、不抢焦点；支持按键录入、16 种颜色编码、显示格式及默认复制偏好 |

附带修复：自绘下拉菜单滚动时跟随锚点，菜单内导航不再滚动整个页面；取色快捷键恢复失败时仍能退出录入暂停状态。

## 验证结果

类型检查通过，19 项逻辑测试全部通过。颜色转换覆盖黑白、原色、BGR/ARGB 编码与旧配置迁移；文件协议覆盖范围读取、尾部读取、HEAD 和 416 拒绝。原有文本、编码、扫描、筛选、布局和热角状态测试继续通过。

以下四组流程直接运行发布目录中的 `One.exe`，使用独立测试配置，不改写正常用户设置：

| 流程 | 结果 | 核验内容 |
| --- | --- | --- |
| electron-smoke | PASS | 自绘控件、文本处理、自绘文件选择及保存；只读启动项扫描得到 85 项 |
| refinement-smoke | PASS | 原生标题栏能力、最大化/最小化、渐进扫描、取消保留、预览与紧凑布局；扫描 13,636 文件、10 批增量 |
| experience-smoke | PASS | TXT/MD/HTML/JSON/YAML/CSV/文件夹/ZIP/APK/DOCX/PPTX/PDF 共 12 类；PDF 查找/旋转；保持/置顶、双侧面板；透明 HUD |
| redesign-smoke | PASS | 原生标题栏与实际窗口截图、实时像素、原生点击拦截、快捷键录入/全局唤起/Esc 取消、16 种格式、实际 WAV 与 WebM 播放/拖动/关闭 |

实时取色：光标保持不动，下方色块从 `#123456` 改为 `#ABC123` 后浮窗正确更新；选取后剪贴板一致，下层点击计数为 0。浮窗不可聚焦、没有整屏画布；通过真正的 Windows 全局快捷键唤起并用 Esc 取消。

媒体：30 秒 WAV 自动播放，按住并拖动进度不会被时间更新拉回，释放后跳转至 21 秒以后；切换 Markdown 后旧媒体暂停且 src 被清除。8 秒、640×360 WebM 自动播放并跳转到 5 秒；关闭原生窗口后预览窗口销毁。关闭音频窗口也检查预览实例清零。

HUD 原生截图透明度：四角 alpha 为 0，中心 alpha 为 245；不再有白色背景块。

日志：`work/{electron-smoke,refinement-smoke,experience-smoke,redesign-smoke}/packaged-result-0.4.txt`。同目录 PNG 为本次发布程序的截图。构建有预览资源块大于 500 KB 的体积提示，不影响构建结果。

## 未覆盖与既有限制

- 取色的 HDR、广色域、远程桌面、受保护内容、管理员应用及混合 DPI 多屏仍需兼容验证；目前使用 SDR 8 位采样。CIELAB 为 D65 数值，CMYK 不含打印机配置。
- 音视频仍受 Chromium 解码器支持范围约束；并非所有容器内编码都能播放。
- Office 为基础渲染，复杂排版、动画及部分对象不完整；其他格式限制见 [预览与外观](../user-guide/预览与外观.md)。
- 系统维护仍为只读扫描，未加入注册表清理或启动项禁用；Listary 不在范围。
- 音量/亮度测试只读接口，未为测试修改当前音量或亮度。外部应用输入、更多多屏组合及独立干净机器尚未全面验证。
- 此版本为未签名的 Windows x64 目录包。

设计规则见 [设计规范](../development/设计规范.md)，PowerToys 源码研究见 [取色实现调研](../research/取色实现调研.md)。
