# 优化与测量

本页维护性能与交互的验收方法。当前剩余事项统一见[开发状态与待办](TODO.md)；历次优化实现及测量见[阶段记录](../history/projects/优化与文件工具阶段记录.md)。历史记录中的版本、测试数和机器路径仅表示当时的环境。

## 验收原则

- 使用同一机器、数据集、设置、权限及可复现步骤比较；分别报告冷启动、首次进入、重复操作和持续负载。
- 内存区分主进程、界面、原生辅助进程及整个应用，区分驻留、私有内存和峰值；不将单项容器下降比例等同于整体下降。
- 长任务记录首个反馈、完成时间、取消延迟、句柄释放与临时数据回收；大结果检查底层内存和首屏响应，不能只看分页或可见节点数。
- 交互检查主题、窗口尺寸、键盘、焦点、减少动画及反复打开/关闭；真实外部应用和跨权限另行验收。
- 性能结论注明数据性质。稀疏/零数据、本机 NTFS、小规模样本和受控夹具不能代表慢盘、网络盘或所有真实文件。
