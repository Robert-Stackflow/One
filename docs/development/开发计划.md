# One 开发计划

版本：0.12.1（Electron）
更新日期：2026-10-01

## 0.12.1 已实现

- 字体预览使用唯一滚动区与固定字号栏，预览浅色侧栏纯白，详情紧凑排列并将操作收进更多菜单。
- 移除标题栏文件类型和快速预览格式说明；界面文字默认不可选，编辑器、文档和可复制信息保留选择能力。
- 增加字体预览明暗、宽窄、菜单键盘及文字选择回归。结果见 [0.12.1 验收](../history/验收-0.12.1.md)。

## 0.12 已实现

- 统一预览左侧文件 / 详情 / 目录 / 页面概览，移除右侧栏；分段选择器、图标按钮与窗口控件统一。
- 文档连续阅读、按需缩略图，修复 Word 标题样式和 PDF 文字目录读取；文件夹单击预览、双击进入，打开方式应用图标。
- 保留长文本虚拟化和媒体关闭停止行为，验证明暗 / 窄窗口 / 侧栏拖动 / 窗口选项记忆。
- 当前限制：扫描型 PDF 未做 OCR，字号标题识别仅前 300 页；复杂 Office 排版 / 图表仍须以实际文件持续改善。记录见 [0.12 验收](../history/验收-0.12.md)。

## 0.11 已实现

- 完成后台维护任务、页签自动扫描和 Rust 缓存清理；磁盘剩余容量告警及进程写入观察。
- 完成 12 类系统信息页签、设备细项、缓存、逐组加载及本地导出。
- 本机普通权限验证容量 / 进程 I/O、页面流畅度与夹具清理。ETW 管理员模式、不同品牌传感器 / 蓝牙 LE 及 Windows 10 仍需跨设备验证。
- 记录见 [0.11 验收](../history/验收-0.11.md)。

## 0.9 当前实现

- 空间分析以矩形图为主体，目录选择/刷新/停止位于页头；选择后自动扫描，完成后监听变更并增量更新祖先统计，停止时保留结果。
- 维护分为启动项、注册表、磁盘清理。支持启动项禁用、缺失目标注册表项清理及持久备份/恢复；缓存按扫描清单处理，回收站独立确认。pagefile/swapfile 通过系统虚拟内存设置管理，hiberfil 通过 Windows 关闭休眠释放。
- 操作增强合并原桌面工具，新增独立输入法、Caps Lock、Num Lock、Scroll Lock 提示设置及拖动定位。置顶边框独立绘制，支持不透明度、粗细、声音及原生标题菜单入口。
- 取色位置跟随与像素采样分离，直接传输小幅 BGRA 像素，减少编码/解码延迟。
- 索引项上限可设为 1,000–10,000,000。缓存采用单写入线程、两秒合并、固定临时文件、排除自身监听、独占文件锁、历史残留清理及失败清理；512 MiB 缓存上限，写前检查可用空间并保留至少 64 MiB。
- 搜索采用 v6 共享路径前缀缓存与有界增量日志，不重复写入名称/小写路径/拼音。实时变更局部校验，重启按目录修改时间补漏；完整扫描不逐个读取文件内容或大小。空间分析在内存中维护，不写持久索引。
- 本节替代下文仍含旧版阶段说明的条目；具体使用范围及验证结果以 [验收-0.9.md](../history/验收-0.9.md) 为准。

## 2. 下一阶段顺序

1. 0.4 重做设计系统，修复音视频自动播放/拖动/关闭，恢复原生窗口控制，取色改为实时小浮窗；19 项逻辑测试与四组发布包流程按验收记录执行。
2. 验证输入和外部预览：浏览器/编辑器复制时序、Explorer 重命名/搜索/多标签、输入法、多屏缩放、全屏、焦点和热角冷却，先修复误触发。
3. 完善空间分析：分配空间、硬链接、大目录性能、标签、报告及刷新。文件删除须实现回收站及对象确认。
4. 维护修改先做持久备份与恢复页面，再做少量启动项禁用/恢复；隔离环境验证冲突和失败后加入注册表清理。
5. 0.5 已补充文本差异、流程、批处理/合并与预览扩展；后续继续依据实际样本改善复杂格式和规则兼容。
6. 完成许可、安装/升级、开机启动、日志与无开发环境机器验证。

## 3. 工作量口径

原估算以一位熟悉 Windows 的开发者全职投入：首版 3–5 周，五类模块补全约 12–21 周。改用 Electron 后只作为粗估背景，不根据已有页面数量推算完成比例。

系统维护恢复可靠性、外部应用输入兼容、Office 等格式预计仍是主要工作量，完成当前兼容验证后再收敛工期。

## 4. 验收门槛

- 文本、编码、扫描、矩形面积及热角状态测试通过。
- 实际 Electron 窗口完成文本处理、扫描/取消、预览、设置保存及只读系统检查。
- Win32 与输入监听加载、停用释放；外部应用完整流程在人工验证后标记通过。
- 包内 One.exe 脱离开发依赖目录运行，代表性功能通过。
- PDF 检查实际显示，不能仅以窗口存在判定成功。
- 系统修改先验证备份、恢复、权限与部分失败、目标并发变化及恢复冲突。
