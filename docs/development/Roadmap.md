## 快速预览 SQLite 与 SQLCipher 数据库

2026-10-10 按用户要求整体延期，暂无日期，不再作为当前执行任务；保留以下范围供重新排期。当前优先已有格式体验，见 [预览调研](../research/预览格式支持与体验调研.md)。目前仅有前期引擎资料，不代表数据库查看器已实现。

- [ ] 快速预览新增数据库查看器，覆盖 `.sqlite`、`.sqlite3`、`.db`、`.db3`、`.s3db`、`.sl3` 等常见后缀，并结合文件内容识别；不能把所有 `.db` 都当作 SQLite，也不能只靠扩展名判断。
- [ ] 支持 SQLCipher 加密数据库。提供密码/密钥输入、解锁与重试，考虑不同 SQLCipher 版本和加密参数的兼容配置；区分密码或参数不匹配、文件损坏与不支持的格式。密码和密钥不写入日志、任务历史或普通设置备份。
- [ ] 提供表和视图列表、切换数据表、字段信息和数据分页；正确展示 NULL、Unicode、64 位整数、长文本与 BLOB，长内容按需查看，避免精度丢失或一次展开巨大单元格。
- [ ] 支持执行用户输入的 SQL，显示结果集、列信息、受影响行数、耗时和错误。默认以只读方式预览；写入语句如开放，应由用户明确启用，并提供事务、提交/回滚及文件占用处理，不能把外部文件中的 SQL 自动执行。
- [ ] 查看建表语句、索引定义、主键/外键、字段类型、默认值等结构信息，支持复制 DDL；兼顾视图、触发器与系统对象的浏览。
- [ ] 优化大数据库、大表与复杂查询：数据库操作放到独立 worker/辅助进程，限制返回行数、单元格及总结果大小；支持查询取消、超时和有界缓存，页面切换或关闭时释放语句、连接与任务。
- [ ] 分页不一次加载整张表；评估深分页、无主键表、稳定排序和大表行数统计的成本，避免打开时强制全表 COUNT 或扫描。性能目标及分页策略在实现方案中明确。
- [ ] 处理正在使用的数据库、只读文件、WAL/SHM 配套文件和一致性读取；预览不得主动修改源数据库、执行 checkpoint 或删除辅助文件。需要快照时明确其成本和生命周期。
- [ ] 调研 SQLite/SQLCipher 引擎及 Electron 集成方式，核对开源许可、Windows 原生打包、版本兼容和资源预算，不以普通 SQLite 可打开代表 SQLCipher 已支持。
- [ ] 验收包含多后缀/无后缀识别、非数据库 `.db`、普通与加密样本、错误密码与兼容参数、表切换/分页/SQL/DDL、WAL 数据库、只读/锁定文件、大表深分页、查询取消和关闭后文件可释放。

## 重新排期条件

用户提出实际使用场景或真实样本后，才选择对应条目进入 TODO，并明确具体支持范围、独立验证工具、许可、失败处理和交付验收条件。优先修复常见格式中可复现的使用问题；没有真实需求时不继续穷举冷门格式、加密方法或卷结构。RAR 写入及只读格式的创建/编辑等能力需另行确认，不作为默认承诺。

更大字典、全部压缩级别、慢盘/网络盘、硬件断电及更多文件系统的完整矩阵同样保留为后续按需工作。真实外部编辑器、跨窗口拖出、跨权限及安装升级卸载等未完成验收仍在 TODO 单独列明，不能因移入 Roadmap 而宣称已通过。
