# Roadmap

本页记录延期和候选扩展，不是当前执行队列。按用户 2026-10-10 的要求，压缩与解压本轮以 ZIP、7Z、RAR 为重点，兼顾 TAR、GZ/XZ 及复合 TAR；其他格式保留已实现能力，暂不继续主动扩展。当前任务及验收状态见 [TODO](TODO.md)，当前使用能力以[用户指南](../user-guide/压缩与解压.md)为准。

## 其他归档格式与特殊变体

下列项目统一延期、暂无日期；不阻挡常见格式的功能实现设计收尾。已有支持不撤销，也不把待验收误写成尚未实现。

| 编号 | 当前已有范围 | 后续按需扩展 |
| --- | --- | --- |
| ARCH-ALZ | v10 单卷/关联分卷，Store、Deflate、BZip2-DLZ、ZipCrypto 与 CP949 | 未知尺寸、额外尾部描述符及其他版本/标志变体目前拒绝。待真实需求、完整样本及独立解码依据再扩展；不猜测格式规则。 |
| ARCH-EGG | 五种方法、AES/LEA/ZipCrypto 内容加密、非加密固实及关联分卷 | 加密文件名、加密固实流尚不支持；AZO x86 等更多真实变体待验收。父路径、链接/特殊文件及未知头部拒绝仍属于安全边界。 |
| ARCH-VOLUMES | CAB 单卷及关联分卷已接通，MSZIP/LZX/Store 三组四卷通过服务及桌面检查，见[CAB 记录](../history/projects/归档CAB分卷实现记录.md) | 分割 WIM 及 `.swm` 入口尚未开放；更多 CAB 写入器组合按实际需求补充。分割 WIM 需真实完整卷组、命名/关联卷、版本检测和缺卷诊断一起验证，不能只凭引擎支持标记产品已支持。 |
| ARCH-ZIPX | 既有只读压缩方法、AES 及独立密码编码已接通，JAR/APK 按 ZIP 容器只读 | 更多外部工具及方法/加密组合待按样本验证；不自动开放 ZIPX/JAR/APK 修改或 APK 安装。 |
| ARCH-LHA | LHA/LZH level 0/1/2/3 普通文件只读及显式编码，已有五份真实 level-3 样本 | 更多旧工具、名称编码和方法组合；OS/2 扩展属性恢复当前不提供，是否新增另行确认。 |
| ARCH-ISO-WIM | ISO9660/Nero Joliet 及单卷 WIM 的既有只读能力 | ISO 的 UDF/Rock Ridge/启动镜像及 WIM 多镜像选择待真实样本验收，不能笼统认定未实现。挂载、创建/修改镜像及 WIM 系统部署不在当前设计范围。 |
| ARCH-STREAMS | BZ2/ZSTD 及 TAR.BZ2/TAR.ZST 等已接通只读 | 更多拼接帧、字典及损坏变体待验收。未知尺寸单流继续先解压后拖出。 |
| ARCH-RAR-COMMENT | 常规 RAR4/5 备注及 RAR 加密内容读取已有实现 | RAR4 加密头部备注、独立加密或分卷 CMT 尚不支持；属于边缘备注兼容扩展，不影响已有密码解压能力。 |

## 重新排期条件

用户提出实际使用场景或真实样本后，才选择对应条目进入 TODO，并明确具体支持范围、独立验证工具、许可、失败处理和交付验收条件。优先修复常见格式中可复现的使用问题；没有真实需求时不继续穷举冷门格式、加密方法或卷结构。RAR 写入及只读格式的创建/编辑等能力需另行确认，不作为默认承诺。

更大字典、全部压缩级别、慢盘/网络盘、硬件断电及更多文件系统的完整矩阵同样保留为后续按需工作。真实外部编辑器、跨窗口拖出、跨权限及安装升级卸载等未完成验收仍在 TODO 单独列明，不能因移入 Roadmap 而宣称已通过。
