# 自动主题切换实现计划

2026-10-10。按 [TODO](TODO.md) 的 Light Switch 需求推进；已接入开发版设置、调度、快捷键和各窗口外观；本页分别记录实现、隔离验证与尚未完成的真实 Windows 验收。

## 行为与范围

| 项目 | 设计 |
| --- | --- |
| 自动计划 | 固定本地时间、按位置估算日出日落、跟随 Windows 夜间模式三种方式；默认关闭，不改动现有主题。 |
| 作用范围 | One 自身、Windows 支持主题的应用、Windows 系统界面分别选择；默认仅 One。Windows 设置仅在用户选择对应范围并启用或执行手动切换后改变。 |
| 手动操作 | 提供浅色、深色、恢复计划及快捷键切换。手动覆盖持续到下一个实际计划边界；夜间模式以状态变化作为边界。关闭自动计划后仍允许明确的手动操作。 |
| 现有 One 外观 | 保留当前配色、字体、密度和正常模式。自动主题只提供运行时模式，不每次改写设置。用户通过原有模式按钮停止 One 的自动管理时，不连带停止其他已选 Windows 范围。 |
| 位置 | 当前手动经纬度；下一步增加用户主动触发的 Windows「获取当前位置」，拒绝、关闭或超时保留手动输入。不在后台进行 IP 定位或隐式申请定位权限。分别设置日出/日落前后 180 分钟偏移；未设置位置时保持当前主题并说明原因。Windows 定位入口尚未实现，不能作为当前能力承诺。 |
| 时间与生命周期 | 按当前绝对时间重算，启动、恢复、时区或时钟变化后补同步，不要求恰好在某一分钟触发。DST 缺失时间按下一个有效本地时间，重复时间不倒退已过边界。30 秒检查加下一边界定时；自动计划关闭时没有周期计时器。 |
| 不可用与退出 | 读取夜间模式失败时保持当前主题；手动切换仍可用。停止时取消外部请求并禁止过期状态发布。Windows 应用/系统写入分别报告失败，不假装已全部成功。 |

Windows 夜间模式以当前激活状态作为输入，包含系统计划与用户手动开关；其未来计划时刻不自行猜测。PowerToys 当前实现读取 CloudStore 的二进制状态，这不是稳定公开 API。本项目按 Bond CompactBinary v1 信封及内部状态结构解码，不依赖固定字节偏移；限制 64 KiB、8 层嵌套和 4096 个字段，校验已知字段类型并跳过可识别的未知字段。缺失、未初始化、不支持、损坏或设备不可用时明确提示，不能把解析失败当作夜间模式已关闭。

日出日落使用 NOAA 近似方程，显示为估算时间；天气、地形及折射可改变实际日出。极昼/极夜不虚构固定切换时刻，会寻找前后真实太阳边界；手动覆盖不能因为计算窗口滚动而提前失效。

`tests/theme-schedule.cjs` 已通过 269 项检查，含 UTC、上海、纽约、奥克兰四个时区，DST 跳时/重复时段、跨午夜、暂停后追赶、连续手动切换、过期配置和服务关闭。`tests/fixtures/theme-solar-reference.json` 的 72 组经纬度/日期由 NOAA 独立的 Julian-century 计算器生成；当前样本最大差异 4.35 分钟，不是全球所有日期的精度保证。生成方式为 `node scripts/build-theme-reference.mjs`，默认复用已下载参考，明确加 `--refresh` 才重新下载；产物记录来源和 SHA-256。这组检查证明调度核心；适配器和页面另有独立验证。

`node scripts/build-theme.mjs` 构建生产辅助程序与仅在 work 中保存的隔离测试变体；常规原生构建已接通，生产程序加入 asar 解包清单，测试变体不打包。`tests/theme-windows.cjs` 在专属 HKCU 测试键验证仅应用/仅系统/两者范围、空范围不写入、状态解析、超长原生值拒绝、取消和生产程序不能选择测试注册表位置。协议检查包含已发表的 off 状态样本、不同长度时间戳、未知字段、错误类型、每个截断位置、重复字段、版本、设备不可用及深度预算。测试结束删除本次测试键；不广播测试主题。

本机当前夜间状态仅有 13 字节的未初始化信封，适配器按不可用处理，不作为真实夜间开启/关闭样本。设置页已显示该原因，并允许固定时间、手动位置计划或手动切换；真实 Windows 主题通知和完整夜间状态的桌面验收仍单独记录。

`tests/theme-automation.cjs` 验证设置迁移/往返、One 临时外观、范围变更、快捷键、未知夜间状态恢复与退出。`tests/theme-automation-ui.cjs` 使用独立 Electron 配置，只选择 One 范围，验证真实页面、自定义时间组件、自动持久化、校验保留输入、无多余分隔线、预览窗口同步、录制暂停、唤醒与重启。窗口宽 1242/1000 时检查面板无横向溢出。Windows 实际主题不会被这组桌面检查写入。

定位参考已核对 PowerToys：[`LightSwitchPage.xaml.cs`](https://github.com/microsoft/PowerToys/blob/main/src/settings-ui/Settings.UI/SettingsXAML/Views/LightSwitchPage.xaml.cs) 使用 `Geolocator.RequestAccessAsync` / `GetGeopositionAsync`，取得坐标后调用 `SunCalc`；[`ThemeScheduler.cpp`](https://github.com/microsoft/PowerToys/blob/main/src/modules/LightSwitch/LightSwitchService/ThemeScheduler.cpp) 在本地计算太阳时间。当前 One 的自动定位入口仍待接入。
