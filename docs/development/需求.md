## 0.9 当前实现

- 空间分析以矩形图为主体，目录选择/刷新/停止位于页头；选择后自动扫描，完成后监听变更并增量更新祖先统计，停止时保留结果。

- 操作增强合并原桌面工具，新增独立输入法、Caps Lock、Num Lock、Scroll Lock 提示设置及拖动定位。置顶边框独立绘制，支持不透明度、粗细、声音及原生标题菜单入口。

- 索引项上限可设为 1,000–10,000,000。缓存采用单写入线程、两秒合并、固定临时文件、排除自身监听、独占文件锁、历史残留清理及失败清理；512 MiB 缓存上限，写前检查可用空间并保留至少 64 MiB。
- 搜索采用 v6 共享路径前缀缓存与有界增量日志，不重复写入名称/小写路径/拼音。实时变更局部校验，重启按目录修改时间补漏；完整扫描不逐个读取文件内容或大小。空间分析在内存中维护，不写持久索引。

## 1. 项目目标

开发一款 Windows 桌面工具，将磁盘空间分析、系统维护、操作增强、文本处理和快速预览整合到统一入口，减少在多个软件之间切换。

本项目参考 SpaceSniffer、CCleaner、MouseInc、TextPro、QuickLook 的使用体验，自行实现所需能力，并按需采用可分发的成熟组件。核心功能应可在未安装这些参考软件时使用；依赖系统预览处理器或可选扩展的格式须明确标注。2026-10-01 重新纳入 Listary 的文件搜索与目录联动，同时加入 PowerToys 三项桌面工具；参考软件均不是必需依赖。

### 1.1 已确认的功能来源

| 来源 | 纳入范围 |
| --- | --- |
| SpaceSniffer | 磁盘扫描、空间矩形图、逐层定位、筛选与文件操作等空间分析能力 |
| CCleaner | 重点为注册表、启动项等扫描与清理 |
| MouseInc | 按键/输入状态回显、边缘滚动、边缘角触发 |
| TextPro | 中文文本转换、整理、查找替换、比较合并与批处理 |
| QuickLook | 空格快速预览、多文件连续查看及格式扩展 |
| PowerToys | 唤醒、始终置顶、File Locksmith |
| Listary | 直接输入搜索、独立搜索窗口、空白双击菜单、文件对话框目录联动 |

### 1.2 规划假设

- 产品暂名 One，中文界面优先；名称可在后续调整。
- 首要支持 Windows 11 x64。Windows 10、ARM64 的支持范围在技术验证后决定。
- 单用户、本地使用优先；核心功能不要求账户或云端服务。
- 一个托盘入口、一套设置、一个主窗口；常用功能通过模块页面、快捷键和浮动窗口访问。
- 分期交付表示各模块的开发先后；Listary 自 0.5 纳入本轮里程碑。下文是目标范围，尚未全部实现，当前状态见开发计划和 README。
- 主应用改为 Electron，界面参考 Codex 的浅灰侧栏、白色工作区和黑白按钮。旧 .NET 实现归档并停止使用。

### 1.3 当前首版边界

已接入基础文本转换与编码文件处理、目录扫描和矩形图、启动项与 App Paths 只读检查、四项操作增强、文件预览。注册表/启动项清理、完整 TextPro 专有规则兼容、复杂 Office 格式保真、完整磁盘占用统计仍待实现。基础 DOCX/PPTX/归档预览已接入；0.5 新增工作表、电子书、字体、Notebook，按行比较、批处理与流程也已实现。输入和外部预览兼容需单独验证，不能以已有开关判定兼容已完成。

| DISK-01 | 渐进扫描选定磁盘或目录；扫描期间持续更新统计、矩形图和列表，可导航；停止后保留部分结果，支持重新扫描 |
| DISK-02 | 按大小绘制嵌套矩形图；支持进入目录、返回上级、面包屑定位及大小列表 |
| DISK-03 | 按文件名、扩展名、大小、时间筛选，支持组合条件和临时颜色标记 |
| DISK-04 | 显示大文件、大目录；支持打开、定位、复制路径、移动、删除和系统右键菜单 |
| DISK-05 | 区分逻辑大小与磁盘占用；处理硬链接、稀疏文件、压缩文件、目录连接与符号链接，避免循环和重复统计误导 |
| DISK-06 | 展示无权访问、离线、扫描失败等状态；统计不完整时明确说明 |
| DISK-07 | 支持结果文字/CSV 报告、多个扫描视图、局部刷新和文件变化更新 |

验收重点：使用有已知文件大小和链接关系的样本验证统计；扫描被拒绝或跳过的项目有记录；删除前展示具体对象，回收站不可用时不能静默转为永久删除。

### 4.2 注册表

| 编号 | 功能要求 |
| --- | --- |
| REG-01 | 按规则扫描应用路径、卸载记录、文件关联等疑似失效引用或残留；规则类型可独立启停 |
| REG-02 | 每条结果显示注册表位置、值名、原值、关联程序、命中规则及判定依据 |
| REG-03 | 区分“可处理候选”“需人工检查”“无法判断”，支持勾选、忽略和重新检查 |
| REG-04 | 修改前保存相关键值和恢复所需信息；备份失败则不执行对应修改 |
| REG-05 | 执行前重新核对目标是否变化；变化项重新扫描，禁止沿用过期结果删除 |
| REG-06 | 恢复前检查当前值，防止覆盖扫描后其他程序写入的新设置；提供冲突说明 |
| REG-07 | 日志记录每项成功、失败和跳过原因；不以扫描数量推导提速效果 |

验收重点：首先在隔离测试环境使用人为构造的启动项和注册表项验证扫描、禁用、删除、恢复。目录离线、路径访问失败、共享组件和无法解析的命令不得仅凭单一现象自动删除。

## 5. 操作增强

### 5.1 按键回显

- INPUT-01：以浮动层显示按键和组合键，支持位置、字号、颜色、透明度、保留时间设置。
- INPUT-02：提供一键启停、“仅显示组合键”模式和应用排除列表；默认不持久记录输入内容。
- INPUT-03：支持多显示器和不同缩放比例，不抢占当前窗口焦点。
- INPUT-04：密码界面识别只作为辅助，不能承诺对所有软件自动识别；提供明确的暂停状态。

### 5.2 边缘滚动

- INPUT-05：上、右、下、左四个边缘独立设置关闭、音量或亮度，每边独立步长；亮度仅作用于鼠标所在屏幕，提供硬件支持检测。
- INPUT-06：支持边缘范围、灵敏度、步长、触发修饰键、指定显示器设置。
- INPUT-07：支持应用排除和全屏暂停，处理多屏内部接缝与外侧边缘的区别。
- INPUT-08：内置屏幕使用 WMI、外接屏幕使用可用的 DDC/CI 接口；不支持时明确提示，不用全屏遮罩冒充硬件亮度。后续再增加静音、快捷键等映射。

### 5.3 复制增强

- INPUT-09：选中文字后快速按两次 Ctrl+C，在鼠标附近弹出菜单；触发间隔可配置。
- INPUT-10：菜单提供网页搜索、复制纯文本、简繁转换、去重与排版，复用文本处理模块。
- INPUT-11：处理结果可查看、复制或送入文本工作台；搜索时显示目标搜索服务。
- INPUT-12：非文本、复制失败或剪贴板未更新时明确处理，不把旧文本误当新选择。
- INPUT-13：可选择保留原剪贴板；取消菜单不得改变原复制行为。

### 5.4 边缘角触发

- INPUT-14：提供屏幕左上、右上、左下、右下四个角的触发热区；鼠标进入并停留达到设定时间后执行动作，各角可独立启停和配置。
- INPUT-15：动作可配置为显示桌面、任务视图、锁屏、唤起 One 主窗口或发送自定义快捷键，复用统一动作服务。
- INPUT-16：支持热区大小、停留时间、冷却时间和可选修饰键；同一次进入仅触发一次，移出后重新进入才可再次触发。
- INPUT-17：支持指定显示器、不同缩放比例、应用排除和全屏暂停；区分多屏内侧接缝与桌面外侧角点。
- INPUT-18：与边缘滚动共用配置和冲突判定；在角部执行滚轮动作时取消本次角触发，移出热区后重新进入才重新计时，避免一次操作触发两种动作。

验收重点：四角分别触发正确动作；停留不足不触发，持续停留不重复触发；多屏、缩放、全屏暂停、应用排除及边缘滚动冲突行为符合设置。四角动作默认关闭，由用户按需启用。

不纳入本轮范围：完整鼠标手势、截图、贴图和 OCR。

## 7. 快速预览

| PREVIEW-05 | 超大、损坏、加密、不支持及离线文件显示明确状态，允许取消加载 |
| PREVIEW-06 | 解析失败不能使主程序退出；切换文件时释放文件句柄和上一项资源 |
| PREVIEW-07 | 文本输入状态不拦截空格；先支持资源管理器，再验证第三方文件管理器和文件对话框 |

## 8. 非功能要求与边界

- 本地优先：核心文件、文本和输入数据默认在本机处理，日志默认不保存完整剪贴板内容。
- 权限：普通功能以普通用户身份运行，系统级修改按需提升权限；用户取消后显示未执行。
- 性能：后台任务可取消并限制并发；以实测记录扫描规模、扫描耗时、内存、CPU 和预览耗时，阈值在技术验证阶段确定。
- 可恢复：修改有结果和备份；恢复是尽力恢复具体项目，不承诺替代完整系统备份。
- 兼容：建立 Windows 版本、显示器、缩放、文件系统、对话框和文件格式支持表。
- 分发：不将参考软件的专有程序、图标或规则库直接打包；第三方组件逐项记录来源和许可证。
- 本轮暂不包含 CCleaner 的驱动更新、云盘清理、浏览器缓存大全，也不包含跨平台、云同步或 AI 助手。
- Listary 本轮优先文件搜索和目录联动；应用启动器、拼音、模糊匹配、插件市场、命令体系等不作为 0.5 验收范围。
- 保留其他模块自身需要的能力：空间扫描结果筛选、TextPro 文本内查找替换、复制增强菜单的选中文字网页搜索、QuickLook 式资源管理器空格预览。这些能力不依赖 Listary 搜索模块。

## 9. 首版与完整目标

首版集中交付统一入口、基础预览、四项操作增强和常用文本处理。空间分析、注册表与启动项维护按后续里程碑落实。当前目标包括原有五类能力及新增的 PowerToys 桌面工具、Listary 文件搜索入口。尚未完成的功能必须标记为计划中，不以占位界面计作功能完成。

开发顺序与交付条件见 [开发计划.md](开发计划.md)；各模块实现方式见 [技术栈.md](技术栈.md)。本文是后续实现和验收的功能基线，变更时同步更新两个配套文档。

## 13. 0.6 性能与搜索交互修订

- 索引、搜索、磁盘扫描、注册表与启动目录检查迁入 Rust；磁盘继续渐进更新、取消后保留已收到的结果。
- Explorer 文件列表输入时显示附着式紧凑输入/结果框，避免打开大独立窗口；独立搜索入口仍保留。
- 支持全拼、首字母、多音字有限组合、模糊缩写和轻微拼写错误，按匹配质量排序，可分别关闭。
- 空白处双击必须打开指针附近的快捷菜单。支持自定义文件夹、文件/程序、网址、命令参数、工作目录、占位符、图标、分组、分隔线、隐藏、排序与导入导出。
- 缓存重启后的离线删除、改名、排除项、循环目录连接与扫描取消都需要验证。性能数字来自标明数据规模的实测。

本节替代 0.5 中暂不纳入拼音/模糊搜索的限制。注册表清理和启动项禁用仍待备份恢复机制完成后实现；本轮 Rust 迁移的是现有检查范围。
## 0.8：统一设置与搜索交互

- 侧栏底部仅保留设置入口；设置采用基本设置、外观、关于的左右双栏结构。侧栏折叠包含平滑宽度与标签动画。
- 各功能页面共用内容宽度。输入、快捷键和数字控件聚焦采用自身细边线；分段页签使用一致的完整圆角，清除重复说明。

- 文件搜索以搜索、索引、快捷菜单三个页签组织；独立窗口、双 Ctrl、Explorer 直接输入与空白双击入口均须以实际桌面操作验收。
