# One 界面设计规范

更新日期：2026-10-02。通过 Computer Use 实际查看 Codex 外观页、字体菜单、高级数字项和键盘快捷键页，同时参考用户截图；用必要的控件、内容层次和留白组织页面，不添加装饰文案。

## 视觉系统

| 项目 | 约定 |
| --- | --- |
| 浅色 | 白色工作区 `#ffffff`，侧栏及辅助背景 `#f6f6f6` |
| 深色 | 工作区 `#181818`，侧栏及辅助背景 `#141414` |
| 按钮 | 普通按钮、输入、下拉、数字和快捷键框统一 32 px；紧凑模式 28 px；工具栏小图标 28 px；主操作实色、次操作细边框、辅助操作透明 |
| 字体 | 系统无衬线；正文与控件 13 px、说明 12 px、辅助 11 px；页面标题 24 px |
| 留白 | 主要内容横向 36 px；窄窗口 20–24 px；所有功能页居中且最大 1120 px；菜单、控件和区块分别使用统一间距 |
| 圆角 | 基础圆角默认 10 px；表单控件采用基础圆角，面板加 4 px；分段选择器外壳和选项均为完整胶囊；避免在每个元素外再套一层卡片 |
| 侧栏 | 默认 208 px；窄窗口降至 184/168 px；可收起为 56 px 图标栏，按钮 40 × 40 px，重启保留；底部只保留设置入口 |
| 图标 | 所有功能图标为 Lucide；One 品牌独立；文件列表采用 VSCode Icons 官方素材；窗口按钮为共享自绘方形控件，边框和阴影交给 Windows |
| 分隔 | 低对比度细线；阴影用于浮出菜单和浮层，不用浓重阴影堆叠普通卡片 |

样式入口统一为 `styles.css`，空间分析补充 `disk.css`，预览内容/窗口补充 `preview.css` 和 `preview-chrome.css`。旧样式叠加文件已移除。

## 窗口与控件

主窗口、预览、独立搜索及文件选择窗口使用共享自绘方形窗口按钮，保留 Windows 原生边框、阴影与调整大小。拖动区和操作区分开；不自绘重复外边框，不覆盖 DWM 边框颜色。

下拉菜单、勾选、开关、数字调节、文件/目录选择和覆盖确认采用应用内统一样式。下拉菜单支持方向键、回车、Esc、首字母定位；页面滚动时跟随锚点定位，选项只滚动菜单内部。开关拥有独立轨道及滑块尺寸，不能继承普通输入框定位。

图标按钮带悬停名称和无障碍标签。表单保留可见焦点。禁用态仍保留布局，不用隐藏文字代替解释失败原因。快捷键录入期间明确显示录入状态，结束后恢复监听；热键被其他应用占用时也必须退出暂停状态。

## 页面组织

主导航将概览独立放在顶部，其后依次为“文件”（文件工具、文本处理、文件搜索）、“工具”（操作增强、空间分析、快速预览、屏幕取色）、“系统”（系统维护、系统信息）。使用 11 px 浅色 caption 与小间距分隔，不添加分组折叠控件；收起时 caption 隐藏，分组间距保留。高度不足时仅导航内容滚动，品牌和设置保留。

- 文本页：文件工具栏、并排原文/结果、常用处理、查找替换。编辑区域随窗口高度变化。
- 空间页：目录、扫描状态与统计、导航/筛选、矩形图和结果列表；渐进更新不打断当前位置。
- 系统维护：只读状态、扫描入口与结果。未实现的清理操作不放置假按钮。
- 操作增强：四边屏幕示意、回显/复制、四角、应用范围分别分组；修改即时生效。
- 取色：颜色样本与可复制格式并列，快捷键/复制格式设置和历史独立成组。
- 设置：左侧分类，右侧基本设置、外观或关于；外观包含模式缩略图、颜色、字体、密度和圆角；预览同步使用相同语义变量。

页面标题仅出现一次。说明用于操作条件、参数含义及真实限制，不添加口号或重复描述。

界面文字默认不可选，避免拖动或 Ctrl+A 高亮导航、标题、按钮和整页布局。输入框、代码编辑器、文档正文、表格值和可复制的详情显式保留文字选择；Ctrl+A 只作用于当前内容区。快速预览入口不列举格式说明。

## 预览与媒体

预览左栏在浅色使用纯白，与正文工作区保持一致。详情按文件标识、元数据和位置排列，不堆叠操作按钮；复制路径与查看占用收进标题栏右上角的更多菜单。标题栏不重复显示文件类型。字体预览固定字号工具栏，正文与字形列表共用一个滚动区，样张输入框按内容增高。

预览标题栏紧凑排列左栏开关、置顶、保持、文件名、定位、打开方式、更多和自绘方形窗口控件；保留 Windows 原生边框与阴影。左栏默认关闭，切换文件 / 详情 / 目录 / 概览，长文件名及文本不能撑开外框。

媒体使用深色舞台、两行轻量控制区：第一行时间/进度，第二行播放/跳转/音量。轨道 3 px、命中区域 24 px，拖动时不被播放进度事件拉回。打开自动播放；切换和关闭时释放播放资源。

音量/亮度/按键回显根节点透明，鼠标穿透、不抢焦点。取色仅有光标旁小浮窗，显示像素放大镜和当前色值，不覆盖或冻结桌面。

## 动效与验收

文件工具结果随配置下方的可用高度伸缩；较短窗口统一滚动整页，不让同一路径存在页面与结果的嵌套滚动。窄窗口重复组与成员纵向排列，保留返回当前组的操作。共享页签采用单一 Tab 焦点，方向键及 Home/End 切换；布局读取与样式写入分开，只更新受影响的控件。

按钮颜色过渡约 120 ms，无按压位移和整块亮度滤镜；菜单约 120 ms，最多 2 px 位移；页面约 140 ms 淡入；面板约 160 ms。遵从系统减少动态效果设置。

验收覆盖浅色/深色、840×780 最小宽度与 1240×780 常用窗口、原生标题按钮、菜单滚动、预览双侧面板、真实视频/音频、实时取色与透明浮层。以实际 Electron 截图和交互流程核验，不能只看静态页面。

## 系统字体加载

Windows DirectWrite 枚举字体族，并解析选中字体的实际文件、PostScript 名称与字体集索引。独立 TTF/OTF 通过受控本地协议加载为 FontFace；TTC 字体集按其面名加载，避免误取字体集第一项。加载完成后应用到界面，不仅保存 CSS 字体名称。样张延迟加载，已加载字体最多保留六个，并保留当前选中的字体。

验证中文字体时使用 Chromium 的实际字形来源检查，不能用 `font-family` 计算值或 `document.fonts.check()` 代替。代码与文档正文可保留专用字体。

0.8 补充：输入聚焦只改变自身的 1 px 边线；复合控件只有一圈边框。侧栏宽度用 240 ms 过渡，标签同步淡出；系统减少动态效果时停用。菜单编辑采用层级树与详情双栏，图标选择器支持搜索和键盘移动。
