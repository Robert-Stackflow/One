ZIP/7Z 外部编辑针对单个普通文件，大小不超过 256 MiB。RAR 及新增只读格式不提供创建、修改或外部编辑回写；不提供 ISO/WIM 挂载、WIM 系统部署、目录整体外部编辑及 LHA 的 OS/2 扩展属性恢复。未知尺寸单流须先解压再拖出，超出拖出数量或 Windows 描述符路径限制时使用常规解压。

本轮压缩归档的新增功能与实现设计按上述日常范围收尾；后续以真实日常问题修复为主。其他格式的已支持范围、缺口和重新排期条件只在 [Roadmap](Roadmap.md) 维护；具体设计见[实现与验收设计](压缩与解压实现计划.md)。真实环境及安装交付验收与源码实现分别记录。
