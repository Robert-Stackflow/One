# 安装器

One 的安装窗口由 `installer/` 中的 Electron 应用实现，实际写入和卸载由 NSIS 安装引擎完成。`npm run package:installer` 会把两者封装为一个 `One-<版本>-Setup-x64.exe`；只需单独构建 NSIS 引擎时运行 `npm run package:installer:engine`。

安装位置可直接编辑，也可点击“浏览”选择。升级会先备份旧版程序；若安装失败，会恢复旧程序、注册表项和开始菜单快捷方式。用户配置不会随程序卸载或升级而删除。

安装前，窗口会检查 One 是否仍在运行，并尝试通过单实例通道请求正常退出。旧版无法响应时，可先从托盘菜单退出；正常退出失败后才会提供明确的强制退出选项。写入程序文件前会请求 Windows 管理员权限；若取消授权，旧版安装保持原状。

升级时旧版卸载程序会收到 `--updated` 标记，保留用户数据和文件关联，待新版安装完成后恢复关联。普通卸载的文件关联清理在后台运行，不显示 PowerShell 控制台。

安装前通过文件系统接口检测实际安装父目录所在卷的可用空间，至少需要 1 GiB。检测失败会提示无法读取可用空间，不会当作空间不足；不依赖 PowerShell 的 `Get-PSDrive.Free`，避免该属性为空时误报。

## 构建与验证

```powershell
npm run package:installer
npm run test:installer:ui
```

安装界面测试不写入正式安装目录。要验证真实安装、迁移位置、失败恢复和卸载，先运行 `node tests/installer-lifecycle.cjs` 创建隔离身份，再运行 `npm run test:installer:integration`。这些测试使用独立的应用身份，不覆盖正式版 One。
