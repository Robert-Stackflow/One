# 原生表格预览

2026-10-10 开发版。按用户要求，XLSX 不再由 One 自绘表格，改由本机注册的 Windows 预览处理器展示。数据库预览继续延期；DOCX/PPTX 的后续优化单独推进。

## 范围与行为

- 当前接入 `.xlsx`。XLSM、XLTX、ODS 仍使用已有只读网格，不把 XLSX 的接入视作全部表格格式已经验证。
- 在 One 预览窗口内承载组件，保留文件导航、详情、置顶、保持窗口和默认程序打开。组件内部的工作表切换、样式、图表及搜索能力取决于已安装处理器。
- 默认关联失效时，XLSX 可使用本机已经注册的 Excel 预览组件；仍无可用组件时提供说明、重试和默认打开。不回退自绘网格，不自动安装/注册/修复 Office。
- 加载失败、超时或组件退出后可以重试；切换文件、重载、渲染进程异常、关闭和退出会结束对应宿主。

## 实现

`src/main/preview-service.ts` 将 XLSX 路由为 `native-office`，跳过旧工作簿解析和大型单元格 IPC。主进程给当前文件生成独立 token；`native-preview-start/bounds/stop` 仅允许预览窗口调用，启动还校验当前文件 token，renderer 不能指定任意路径或宿主 HWND。

`src/main/native-preview.ts` 管理每窗口一个会话，依次尝试 64 位、32 位宿主。每次激活最长 12 秒；加载中取消会结束等待，正常关闭先发送卸载指令，800 毫秒后仅对仍存活的自有宿主执行终止。迟到状态、过期停止指令不影响新文件。

`native/preview-host.cpp` 从 Windows 文件关联查询预览 CLSID，核对当前位数下 COM 注册；XLSX 额外核验 PreviewHandlers 中已经注册的 Excel 预览类，供关联残留或激活失败时回退，不猜测程序路径或修改注册表。使用 `CLSCTX_LOCAL_SERVER` 激活系统代理，不把处理器 DLL 加载进 Electron。优先 `IInitializeWithStream` 只读流，其次是处理器提供的 Item/File 初始化接口；不因支持的流接口初始化失败而盲目改用其他入口。原生宿主设置 `IPreviewHandlerFrame` 站点、父窗口和显示区域，然后调用 `DoPreview`，退出调用 `Unload` 并释放站点、流和对象。不会终止共享 prevhost 或用户 Office 进程。

`src/renderer/native-office-view.ts` 立即返回清理函数，不等 COM 加载结束。区域由 DOM 测量，经 Electron zoom 和父 HWND DPI 转为物理像素；窗口和侧栏改变时更新区域。宿主维持在 Chromium 内容子窗口上方，避免 Excel 已加载但被遮住。打开方式、更多菜单或模态对话框显示时，将原生区域暂时置零；关闭后恢复。

统一 tooltip 显示或移动时，`NativeTooltipService` 用属于当前预览窗口的透明浮层展示提示，复用 `.one-tooltip` 样式、位置、箭头和字体；浮层不抢焦点、鼠标穿透，坐标随 Electron zoom 换算。原生预览不裁剪、不缩小，也不会因 tooltip 露出白色背景。提示关闭、窗口失焦/移动/缩放/隐藏时隐藏浮层，预览重载、异常、关闭或退出时销毁。打开非原生预览时继续使用原来的 HTML tooltip。原生组件将 Esc 交给宿主时关闭预览，其他键盘行为保留给组件。

## 构建与验证

- `scripts/build-preview.mjs` 构建 `One.Preview.exe` 和 `One.Preview32.exe`，已接入完整构建、dev 产物检查和 asar 解包配置。
- `npm run test:native-preview`：50 项检查，构建专用测试宿主，核验只读初始化、32 位回退、区域/DPI、原生子窗口层级、顶栏/底栏透明 tooltip 显示与关闭、不抢焦点、角落像素透明度和未裁剪的原生区域、菜单避让、重载、超时、取消、异常退出、角色/token/提示参数校验、失败重试和关闭后文件可移动。正式宿主缺组件检查使用无关联的测试扩展名。测试组件仅通过编译宏启用，不注册 COM、不修改文件关联；测试路径覆盖也只在 `ONE_TEST_MODE=1` 启用。
- `node tests/native-preview-missing.cjs`：6 项检查，使用专门的缺组件测试构建核验错误页面、重试、无自绘回退和默认打开请求，与本机 Office 安装情况无关。测试拦截打开请求，不启动真实 Office。
- `node tests/native-preview-office.cjs`：12 项检查，在本机真实 Excel 组件中预览完整 OOXML 样本，核验加载、无自绘网格、顶栏/底栏透明 tooltip、预览主体可见且未裁剪、关闭后文件可移动及源文件哈希不变；界面截图保存在 `work/current/native-preview/office/`。
- 原有自绘网格 UI 回归改用 XLSM/ODS，XLSX 底层解析样本保留给仍复用该解析器的功能。测试前应构建当前 main/preload/renderer。

本机默认 XLSX 关联指向未注册的 WPS 组件，但另有有效的 Excel 预览类。加入已注册组件回退并修正子窗口层级后，真实 Excel 已显示合并表头、中文字体、金额、1904 日期、百分比、前导零、缓存公式与两个工作表标签。此结论来自真实预览截图，不把默认关联失效等同于整机没有 Office。WPS、图表、工作表操作、低完整性代理、跨位数组件、组件焦点、密码文件和多显示器 DPI 切换仍需真实环境验收。
