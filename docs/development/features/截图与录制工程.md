# 截图与录制工程格式

本文件定义 One 新工程的存储契约；实施状态统一维护在 [TODO](../TODO.md)。来源业务模型基于 Frame `3b6db75883c2fa49ea9a9fe62dd97e8f630dce51`，One 起始提交为 `587b8cd59d69f61e3ffae0e45ab0eff40e974350`。

## 界面与共用控件

截图窗口在后台预热但不采集桌面。触发后先对齐目标屏幕物理范围，避免 Chromium 在混合 DPI 下把尺寸反复转换为逻辑坐标，导致多出像素并缩放屏幕内容；预览接近原尺寸时直接使用原图像素，缩小组合图像时限制画布大小。首帧完成绘制与合成后才显示，页面加载和首帧超时共用有界等待。字体发现不阻塞首次展示，输出仍等待字体准备完成。

当前截图处于采集、编辑或输出阶段时，再次触发只保留这一会话；已显示的截图可以回到最前，不排队创建第二个截图，也不弹出重复会话错误。采集、页面加载或首帧失败后释放窗口与会话，下一次可以重试。

剪贴板贴图按图片内容、文字或文件列表复用已有记录；隐藏的记录可恢复，同一内容连续触发不会新增贴图。再次显示时置前并用短暂描边和提示反馈，提示描边贴合内缘、四角单独裁剪，不改变系统窗口边框与阴影。Toast 在两种主题下均保持深色背景、浅色文字且不带描边；Tooltip 在深色主题中也保留黑底白字。

素材页支持勾选和全选当前搜索结果；切换类型或搜索条件会清空选择。图片支持批量贴出、导出 PNG 和删除，录制支持批量导出 `.onerec` 工程和删除。批量导出只选择一次目录，使用独占创建和重名后缀保留已有文件。删除统一确认，沿用正在编辑的素材保护；部分失败会显示数量与原因，失败项保持选中。贴图页在批量显示、隐藏、恢复交互、移动分组之外支持批量删除；删除贴图保留素材和引用原文件。专项回归入口为 `tests/collections-feedback-smoke.cjs`。

截图、录制与素材页的 SegmentTab 使用与开发工具相同的 One 公共高度、内边距和选中样式，录制设置页签按内容收缩。录音使用单栏表单，声音来源与设备测试在上，格式、延迟和音质集中在下；不显示画面占位与基本/音质页签，切回视频复用原控件并恢复分类。窗口来源加载仅显示进度图标与一行提示；贴图页将分组标题、数量和筛选分层，空状态只保留图标与一句提示，添加操作保留在页面标题区。自定义截屏按显示器、尺寸与预设、位置、延迟排列，预设管理按需展开；内容可滚动，标题与底部操作保持可见。

截图、图片编辑和录制工具栏共用分栏标注按钮。通用 SVG 尺寸不覆盖 One 数字输入的 13 px 加减图标和下拉的 14 px 箭头，录制专用字体菜单也使用同一箭头。水印三个设置、输出效果和更多菜单在弹层显示后依据 CSS 宽度定位，外框、阴影和无缩放淡入归 One 的 `popup-surface.css`；关闭后重开不缓存零宽度。录制原生工具菜单共用窗口淡入，保留单层 Windows 外框。图片与录制编辑器的窗口按钮右侧留白与主窗口一致。录制编辑器的成对字段分列、颜色和下拉按字段排列，标注显隐与说明分行，底部不重复显示标题。

截图与录制选区沿用 Frame 已确认的窗口呈现修复：在 Electron 就绪前设置 `wm-window-animations-disabled`，关闭 Aura 对透明浮窗施加的缩放淡入。移动录制区域的独立浮条显示移动图标、操作名与像素尺寸，使用 232 × 40 DIP 的原生窗口；原有拖动、像素尺寸和显示器边界约束保持。界面调整不改变截图、标注与录制的数据模型。

文字描边由截图、录制预览与合成导出共用绘制器，根据每行文字所处的背景颜色与对比度调整色调、透明度和宽度：文字清晰时保持轻薄，融入背景时增强。每次绘制只读取一次最长边 256 px 的背景缩略图；取样使用文档坐标，跟随文字移动、旋转，独立于界面缩放。录制标注在需要背景时复用当前画面预览帧；未拿到画面时使用柔和的回退描边。文字选择范围预留最大描边宽度，避免裁切。

标注偏好保存在 One 设置的 `capture.annotationStyles`，随设置保存和备份。截图、图片编辑器、录制分别按工具恢复颜色、线宽、笔刷大小、字型、字号、字重、斜体、描边、填充和线型；水印继续使用自己的内容与布局预设。选择已有对象只显示其样式，主动调整才更新该工具的偏好，不保存文字内容或对象。旧设置自动补齐默认值，重新打开窗口和重启应用后恢复；原有图片和录制工程的标注数据保持独立。

文字编辑框按可见字形计算边界，保留必要的描边空间和斜体外伸，不把输入行高中的留白算入边框。占位文字与正文共用画布绘制，原生文本域处理输入、选区和输入法，独立光标使用稳定的字形高度。首字输入及清空保持最小编辑框，换行按行距扩展；空占位不会写入工程。截图、图片编辑器和录制标注共用实现。`image-editor-window-smoke.cjs` 实测 96 px 粗斜体的占位留白、首字光标和换行；`annotation-renderer-smoke.cjs` 检查描边像素、移动与缩放取样、录制画面一致性和重启后的偏好。

## 格式身份与目录

| 工程 | 扩展名 | 8 字节 magic | project.format | project.version |
| --- | --- | --- | --- | --- |
| 图片 | `.oneimage` | `ONEIMAGE` | `one-image` | `1` |
| 录制 | `.onerec` | `ONERECRD` | `one-recording` | `1` |

身份常量由 [media-project.ts](../../../src/shared/media-project.ts) 统一定义。读写两端同时校验 magic、模型身份和版本；不识别来源产品的 magic、格式身份或录制 v2/v3，不添加转换、别名或格式猜测。One 的录制 v1 直接包含来源最新版的独立音轨和可编辑光标能力。

图片模型位于 `src/shared/capture/`，录制模型位于 `src/shared/recording/`；文件读写分别位于 `src/main/capture/`、`src/main/recording/`。共同使用 `src/main/media-file.ts` 的 Windows 同目录提交操作。截图与录制的模块语言由 `capture/i18n.ts` 管理，使用 One 身份；当前来源英文词典为空，保留原有中文回退行为。

## 工程文件入口

One 冷启动和单实例唤醒识别普通 `.oneimage`、`.onerec` 文件参数，也支持 `--one-project=<文件路径>`；扩展名不区分大小写，带空格和中文的路径保留完整。相对路径按发起实例的工作目录解析，同批重复参数及仍在处理的相同文件只执行一次，多文件进入 One 既有启动操作队列。内部资源 URL、其他开关和旧产品扩展名不作为工程启动参数。

启动分发先检查普通文件，再交给 One 图片编辑或录制宿主，复用完整工程校验和退出任务等待。图片编辑已有内容时保留当前窗口并提示先关闭；录制先完整校验新工程，有未保存内容时确认替换，取消或新文件损坏均保留当前结果。文件搜索选中工程和通用文件打开 IPC 直接走同一业务入口。冷启动导航等待页面加载，主预加载层在页面订阅前暂存导航消息，避免主界面动态加载期间丢失“进入录制页”的请求。

`media-project-launch.test.cjs` 的 3 项检查覆盖参数边界、来源工作目录和真实主预加载层的有序消息重放。`media-project-entry-smoke.cjs` 使用独立 profile 验证两种工程冷启动、带自启动参数的显式工程请求、重复参数、真实 Electron 单实例锁转发相对路径、图片编辑保留、实际素材写入失败后的录制替换取消/确认、损坏文件保留当前结果、旧预览撤销和通用文件打开；原始工程字节保持不变。单实例发送端为受控 Electron 进程，安装后的资源管理器关联入口继续在 P9/P10 验收。

## 工程安装关联

安装器以 One 身份登记 `.oneimage` → `One.ImageProject`、`.onerec` → `One.RecordingProject`，共用 One 可执行文件图标，打开命令为 `"<One.exe>" "--one-project=%1"`。脚本 `src/main/media-associations.ps1` 经 UTF-8 BOM 输出到 `dist/main/` 并作为 asar 解包资源分发；复用构建时检查源文件与构建脚本一致。

注册只作用于这两类新工程：没有默认值的扩展名默认打开 One，已有默认值、其他 OpenWith 候选和 Windows `UserChoice` 保留。NSIS 安装完成后登记，普通卸载按可执行文件路径核对归属再清理；升级卸载保留关联，旧目录卸载不能删除新目录的登记。未提供路径或缺少 One 归属标记的键不会被清理。验证安装器使用独立产品身份，不登记正式 One 工程类型。

自定义安装器在文件校验后确认关联完整；升级失败先移除新位置拥有的关联，再恢复旧程序及其原有关联。旧版本没有此能力时不在恢复过程中补写关联；首次安装失败也清理新建关联。压缩包关联仍按原有选择恢复，不因新工程安装而默认启用。

`media-associations.test.cjs` 联同既有安装操作检查共 9 项，涵盖生产脚本的 30 项隔离注册表断言和实际安装事务函数的成功移动、同目录/异目录失败恢复、旧版缺少关联及首次安装失败；不写正式产品注册表。NSIS 安装/卸载宏分别以正式和验证身份编译，压缩包关联隔离回归通过。`media-project-entry-smoke.cjs` 支持 `ONE_TEST_EXECUTABLE`，在实际目录包中复用工程冷启动、单实例、替换与损坏隔离验收。目录包、安装核心和自定义安装界面候选按 P10 单列记录，真实安装后的 Explorer 双击和升级/卸载验收尚未完成。

## 截图设置契约

`settings.capture` 纳入 One 的默认设置、校验与局部更新：`shortcuts` 保存八类全局快捷键，`workflows` / `workflowId` 保存输出预设和默认流程，`watermark` 保存水印，`custom` 保存定位/尺寸/延迟和尺寸预设，`remoteCompatible` 保存远程桌面采集选项。`uiScale` 保留 100/110/125/150 四档；由对应页面和窗口消费，不改 One 全局外观；独立窗口的完整 DPI/视觉验收仍在 TODO 中跟踪。

输出流程保留有序的复制、保存、贴图、存入素材、识别、翻译动作，校验预设唯一性、动作重复及翻译目标；无效更新整体拒绝。One 自身已有设置缺少该功能字段时补默认值，不读取来源产品的设置字段。翻译语言与请求结构位于 `src/shared/recognition/translation.ts`；密钥不进入 `settings.capture` 或普通设置备份，使用下述 One 安全连接设施，已接通识别窗口与截图输出流程宿主。

One 设置新增“截图与录制”分类：四档功能缩放、远程控制兼容、自定义截屏、素材目录入口及完整输出流程编辑。流程支持新增/删除、选择默认项、动作排序、翻译目标和圆角/边框/阴影，复用 One 下拉与编辑器效果控件；样式仅作用于功能区域。普通设置写入失败回显已保存值，流程编辑失败保留当前编辑并显示失败，可修改后重试。备份导入后刷新已挂载的表单，重新进入和重启都读取 One 持久化设置。导出等待此前已接收的设置写入完成，避免慢磁盘下备份仍保存修改前的值。

“恢复截图设置”经确认后只重置 `settings.capture`（包括快捷键），保留 One 其他设置、素材、草稿、贴图和识别服务连接。来源录制页的来源/设备选择与临时参数仍为会话状态，不为这些状态新增全局字段；素材和贴图索引、识别加密连接仍由各服务维护。跨功能草稿恢复与缓存清理继续在 P8 跟踪。

`capture-preferences.test.cjs` 验证局部修改、数据往返、默认值隔离和无效输入；`shortcut-capture-backup-smoke.cjs` 覆盖实际备份导入/导出、快捷键冲突和重启。新增 `capture-settings-smoke.cjs` 在真实 One 主窗口验证流程动作/目标/效果、默认流程与选择切换、自定义截屏、真实写入失败及重试、慢写入并发导出、重置取消/确认、素材与独立数据文件保留、导入后表单刷新、重启回显、反复激活和窄窗口布局。

## 快捷键、托盘与搜索命令

One 主进程统一注册区域截图、截屏并复制、自定义截屏、显示器截图、贴出剪贴板、隐藏/显示全部贴图、切换贴图分组和打开录制八类快捷键。默认区域截图为 `Ctrl+Shift+F8`、贴出剪贴板为 `Ctrl+Shift+F9`，其余为空；保留 F1–F24 单键和 Windows 组合键能力。自定义截屏打开配置对话框，录制快捷键进入录制页。

录入复用 One 快捷键控件和原生捕获，期间暂停这八类注册；结束、失焦、开发刷新或主 renderer 退出后恢复，真正退出时注销自身注册。已失效的回调不能执行；不会注销其他功能拥有的键。One 内部重复和外部占用显示对应错误，保存值保留并支持重试；设置写入失败保留原注册和当前输入，后续状态通知不抹掉失败提示。

托盘和搜索命令直接调用同一业务服务，支持四个功能页面以及区域/复制/自定义/显示器截屏、编辑剪贴板图片和贴图操作；搜索支持中文及拼音。IPC 继续限制窗口角色。扩展后的托盘使用既有滚动容器和键盘导航，退出项可达。

`capture-shortcuts.test.cjs` 的 8 项检查覆盖注册归属、重复/占用、暂停/停止、失效回调、异步失败、设置及命令匹配。`capture-system-entry-smoke.cjs` 使用独立 profile 和真实 Electron 注册，验证外部进程占用与释放、原生录入暂停/恢复、录入中刷新恢复、实际写入失败后重试、四页搜索分发、角色拒绝、托盘、贴图分组、剪贴板图片编辑及重启。入口测试中的桌面采集与剪贴板内容使用受控输入，未读写系统剪贴板；不能替代 P10 的真实采集、设备、多屏和安装关联验收。设置备份、原生快捷键录入、托盘及搜索既有专项回归通过。

## 识别窗口与服务

`src/main/recognition/` 保留来源 OCR、敏感区域、翻译/公式、表格模型及输出算法。Tesseract.js 固定为 7.0.0，runner、worker、engine 分别构建；语言包保持官方固定版本、大小和 SHA-256 校验，读取状态或执行识别不会自动联网下载。敏感检测仅返回类型和矩形，不返回识别出的私人文本。生产语言包安装由识别窗口中的下载动作主动触发。

翻译和公式连接存于 One `ai-data.json` 的独立用途字段，使用系统加密及 One 原有原子保存设施。`one-recognition-connection` 首版记录校验用途、版本、地址及加密内容，renderer 可见配置不含密钥或密文；两个用途各自维护版本令牌、重填密钥及清除语义。更换服务地址必须重新提供密钥，失败保存保留原配置。共用请求设施禁止重定向和环境凭据，不创建聊天会话或历史；保留完整 Chat Completions 地址及 Azure Translator 请求语义。

表格保留重建、合并拆分、校正、剪贴板格式与 Excel 导出；导出必须接受 One 数据路径保护并检查目标文件变化。公式预览使用统一 KaTeX 0.19.0，保留命令限制与宏隔离。主进程工作线程及 Tesseract/core 的资源已进入构建、dev 复用检查和打包配置，目录包实际资源验收仍待后续执行。

`recognition.test.cjs` 的 32 项检查覆盖业务校验、取消/超时/并发、真实本机 HTTP、Azure 请求、结果校正、Excel 结构与文件提交、One 加密存储和失败回滚。`recognition-ocr.test.cjs` 的 3 项检查通过真实中英文图片、Tesseract 工作线程、敏感邮箱区域、取消后再次识别以及损坏模型拒绝；官方语言包测试缓存复用在 `work/current/fixtures/recognition-models`。识别窗口由 One 创建并授予 recognition 角色和专用 preload，只暴露识别及必要的公共窗口接口；四个结果页签、下拉和服务表单使用 One 共享组件，公式预览 worker 由 Vite 构建。图片资源通过 One 的受控路由读取，校验窗口、文档和当前令牌；独立窗口禁止嵌入页面，出现子文档时拒绝业务和资源访问，覆盖 Electron 将空白子文档请求归到主文档的情况。关闭、崩溃或退出撤销资源并取消、等待活动请求，未安装语言包时不会自行下载。

## 素材存储契约

图片缩略图缺失或尺寸/PNG 文件头无效时，读取操作先校验原图哈希，再按需重建缓存，原图、工程和索引保持不变。重建与删除共用操作队列，避免删除后重新生成缓存；链接或非普通文件占用缓存位置时拒绝覆盖。缓存写入失败仍可返回已生成的预览，不影响查看完整原图。

## 图片容器

容器依次为 8 字节 magic、4 字节小端 JSON 长度、UTF-8 JSON、原始 PNG。JSON 包含 `project`、PNG 字节数及 SHA-256；存在撤销/重做历史时，使用有解压上限的 gzip/base64 字段保存。元数据最多 16 MiB，解压后的历史最多 128 MiB；原图沿用 64 MiB、4,000 万像素、最长边 16,384 像素限制。

`ImageProject` 保留原图尺寸、可编辑标注、自由/多边形选区、裁剪与旋转/翻转变换、输出效果、水印，以及完整撤销/重做分支。新建工程可以没有历史；这不提供旧产品工程读取能力。工程保存要求当前裁剪已应用或取消。

读入验证数据边界、PNG 头、SHA-256 和读取期间文件身份。保存先在目标目录创建排他暂存文件并同步，再检查目标是否变化，最后提交；取消和写入冲突不得覆盖其他写入。现有图片工程的覆盖仅在调用方选定目标且文件未变化时进行。

## 录制服务与主客户端契约

`RecordingService` 接收 One 数据目录、窗口工厂及功能注册器，绑定唯一的 One 主窗口客户端。原独立录制窗口、WCV 嵌入与布局入口已移除；服务不创建私有 session，也不自行覆盖 One 的权限或网络处理器。媒体权限回调和 `one-file` 资源授权由 One 中央调度接入，校验客户端、顶层 frame、窗口角色、当前令牌和录制状态。闲置的声音测试与摄像头预览随页面停用释放，晚到结果撤销；活动录制继续接收心跳和媒体块。

`finishCapture()` 合并并发停止请求，等待原生采集完成或 WebM 尾块写入，再保留结果供保存决策使用。普通 `dispose()` 拒绝清理未保存结果；调用方完成保存或明确放弃后才能释放。取消与释放均不重载或销毁 One 主窗口。工程快照使用 One v1 身份，外部文件提交仍经 One 目标保护。

`node tests/recording-service-smoke.cjs` 使用隔离 Electron、真实 IPC 与录制桥接，验证客户端/子页面隔离、重复媒体授权拒绝、预览撤销、切页持续写入、停止尾块、取消和工程保存，并从真实服务加载 WebM、呈现视频帧后读取画布像素。WebM 由真实 MediaRecorder 录制合成画布，原生录音由 One 辅助程序采集合成声源；摄像头和来源枚举使用替身。测试不证明真实设备、完整 UI 或实际 One 主窗口装配已通过。服务接线、中央权限路由与退出流程的实际 One 验证见下节。

## 录制主窗口装配与退出

One 的 `windowFor()` 按录制角色选择八个专用 preload，工具栏菜单共用工具栏桥接，区域边框没有 preload。播放器接入 One 窗口控制；外观、字体与诊断仍按角色授权。六类录制资源在中央 `one-file` 路由按客户端、令牌、角色及顶层 frame 校验，媒体授权与原有预览全屏权限共存，不开放普通网络访问。素材页可导入录制工程/视频、打开编辑和删除；录制与素材使用同一个库。

## 录制容器

容器同样以 magic、小端 JSON 长度、UTF-8 JSON 开始，随后按清单顺序存储原始媒体。每项包含轨道种类、字节数和 SHA-256，流式读写，无需将全部媒体载入内存。元数据最多 64 MiB，每条原始媒体最多 1 GiB；保持来源模型的时长和时间轴上限。

轨道顺序为主画面/声音、可选摄像头、可选系统声音和麦克风。工程保留摄像头布局、键鼠事件、标注时间轴、光标形状与事件、速度、声道增益、GIF 帧及输出设置。独立声源继续校验 48 kHz 双声道 PCM 及样本时长；新格式要求显式提供系统声音和麦克风播放增益，不保留旧版本补字段逻辑。

临时媒体沿用 AES-GCM 分块封存和退出释放能力。保存采用同目录暂存、校验、同步和原子提交，拒绝未经业务流程处理的目标覆盖。打开失败或取消会释放已导入临时轨道；主画面预览仅提供受管理素材解析后的原片字节范围，不将元数据作为媒体返回。
