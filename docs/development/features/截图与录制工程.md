# 截图与录制工程格式

本文件定义 One 新工程的存储契约；实施状态统一维护在 [TODO](../TODO.md)。来源业务模型基于 Frame `3b6db75883c2fa49ea9a9fe62dd97e8f630dce51`，One 起始提交为 `587b8cd59d69f61e3ffae0e45ab0eff40e974350`。

## 格式身份与目录

| 工程 | 扩展名 | 8 字节 magic | project.format | project.version |
| --- | --- | --- | --- | --- |
| 图片 | `.oneimage` | `ONEIMAGE` | `one-image` | `1` |
| 录制 | `.onerec` | `ONERECRD` | `one-recording` | `1` |

身份常量由 [media-project.ts](../../../src/shared/media-project.ts) 统一定义。读写两端同时校验 magic、模型身份和版本；不识别来源产品的 magic、格式身份或录制 v2/v3，不添加转换、别名或格式猜测。One 的录制 v1 直接包含来源最新版的独立音轨和可编辑光标能力。

图片模型位于 `src/shared/capture/`，录制模型位于 `src/shared/recording/`；文件读写分别位于 `src/main/capture/`、`src/main/recording/`。共同使用 `src/main/media-file.ts` 的 Windows 同目录提交操作。截图与录制的模块语言由 `capture/i18n.ts` 管理，使用 One 身份；当前来源英文词典为空，保留原有中文回退行为。

## 截图设置契约

`settings.capture` 纳入 One 的默认设置、校验与局部更新：`workflows` / `workflowId` 保存输出预设和默认流程，`watermark` 保存水印，`custom` 保存定位/尺寸/延迟和尺寸预设，`remoteCompatible` 保存远程桌面采集选项。`uiScale` 保留 100/110/125/150 四档；后续仅应用于截图与录制对应页面和窗口，不改 One 全局外观。

输出流程保留有序的复制、保存、贴图、存入素材、识别、翻译动作，校验预设唯一性、动作重复及翻译目标；无效更新整体拒绝。One 自身已有设置缺少该功能字段时补默认值，不读取来源产品的设置字段。翻译语言与请求结构位于 `src/shared/recognition/translation.ts`；密钥不进入 `settings.capture` 或普通设置备份，使用下述 One 安全连接设施，已接通识别窗口与截图输出流程宿主。

`capture-preferences.test.cjs` 验证局部修改、数据往返、默认值隔离和无效输入。扩展的 `shortcut-capture-backup-smoke.cjs` 已在独立 One profile 验证实际备份导入/导出、拒绝无效更新和重启保留。截图快捷键、其余功能设置及界面绑定仍待后续接入。

## 识别窗口与服务

`src/main/recognition/` 保留来源 OCR、敏感区域、翻译/公式、表格模型及输出算法。Tesseract.js 固定为 7.0.0，runner、worker、engine 分别构建；语言包保持官方固定版本、大小和 SHA-256 校验，读取状态或执行识别不会自动联网下载。敏感检测仅返回类型和矩形，不返回识别出的私人文本。生产语言包安装由识别窗口中的下载动作主动触发。

翻译和公式连接存于 One `ai-data.json` 的独立用途字段，使用系统加密及 One 原有原子保存设施。`one-recognition-connection` 首版记录校验用途、版本、地址及加密内容，renderer 可见配置不含密钥或密文；两个用途各自维护版本令牌、重填密钥及清除语义。更换服务地址必须重新提供密钥，失败保存保留原配置。共用请求设施禁止重定向和环境凭据，不创建聊天会话或历史；保留完整 Chat Completions 地址及 Azure Translator 请求语义。

表格保留重建、合并拆分、校正、剪贴板格式与 Excel 导出；导出必须接受 One 数据路径保护并检查目标文件变化。公式预览使用统一 KaTeX 0.19.0，保留命令限制与宏隔离。主进程工作线程及 Tesseract/core 的资源已进入构建、dev 复用检查和打包配置，目录包实际资源验收仍待后续执行。

`recognition.test.cjs` 的 32 项检查覆盖业务校验、取消/超时/并发、真实本机 HTTP、Azure 请求、结果校正、Excel 结构与文件提交、One 加密存储和失败回滚。`recognition-ocr.test.cjs` 的 3 项检查通过真实中英文图片、Tesseract 工作线程、敏感邮箱区域、取消后再次识别以及损坏模型拒绝；官方语言包测试缓存复用在 `work/current/fixtures/recognition-models`。识别窗口由 One 创建并授予 recognition 角色和专用 preload，只暴露识别及必要的公共窗口接口；四个结果页签、下拉和服务表单使用 One 共享组件，公式预览 worker 由 Vite 构建。图片资源通过 One 的受控路由读取，校验窗口、文档和当前令牌；独立窗口禁止嵌入页面，出现子文档时拒绝业务和资源访问，覆盖 Electron 将空白子文档请求归到主文档的情况。关闭、崩溃或退出撤销资源并取消、等待活动请求，未安装语言包时不会自行下载。

素材“识别文字”、图片编辑器的识别动作与敏感文字遮盖、截图的识别/翻译输出均已接通。翻译先在本机 OCR，再向明确配置的服务发送文字；失败或取消可返回原截图重试，已经完成的复制不重复。敏感检测与应用遮盖保留一次撤销语义。

`recognition-window-smoke.cjs` 覆盖真实中英文识别、文字校正/复制、表格编辑与导出路径保护、加密配置、完整请求地址、主动发送公式图片、受限预览 worker、外部窗口/子文档权限、重开、150% 对话框边界、敏感遮盖/撤销及活动请求退出。`recognition-capture-smoke.cjs` 使用自有原生窗口验证截图输出、缺少服务配置、取消/返回/重试及已完成输出不重复。One AI 与 Markdown 相邻回归通过。完整来源视觉、功能语言与目录包资源仍待迁移收口；当前通过的窗口测试不代替这些验收。

## 截图采集基础

`src/shared/capture` 保留截图会话校验、元素候选、物理像素合成布局和有容量上限的原生 PNG 帧协议；`src/main/capture` 提供多屏/多窗口采集事务、元素探测进程、持续原生采集和输出收据。多来源采集在身份/尺寸改变、失败或取消时整体拒绝替换；输出重试只继续未确认的动作，已经完成的复制/保存等副作用不重复执行。

`native/capture` 保存来源的窗口采集、桌面采集、PNG 传输和元素探测算法。构建产物统一为 `One.CaptureProbe.exe`、`One.SingleCapture.exe`、`One.ScrollCapture.exe`，采用 One manifest 与物理像素坐标。Win32 封装按需初始化，负责窗口/进程身份、显示器边界、DWM 刷新、鼠标坐标和受限辅助进程；没有新增全局应用入口。

`scripts/build-capture.mjs` 接入 One 原生构建，缓存摘要包含全部本地 include、manifest、编译参数、库及工具链版本；同时核验输出文件摘要，避免缺失或损坏的 exe 被当作缓存。开发复用构建检查与打包 `asarUnpack` 清单登记三个辅助程序。此处已验证本地构建与原生进程，目录包和安装环境仍待完整迁移验收。

`capture-acquisition.test.cjs` 运行 20 项来源业务检查；`capture-acquisition-native-smoke.cjs` 只对自有测试窗口执行真实元素探测、单张/持续采集、像素变化和遮挡验证，同时检查错误窗口进程身份拒绝及进程释放。

## 截图服务与独立窗口

`src/main/capture/service.ts` 保留来源的采集会话、选区、刷新、标注及输出收据，`host.ts` 将窗口、设置、素材、贴图、保存和剪贴板接入 One。独立截图层使用 `one://app/index.html?view=capture` 和专用受限 preload；复用 One 控件、外观、字体与标注组件，不装配独立应用壳。主窗口命令与截图窗口内部命令分别校验角色；截图与屏幕取色、条码框选互斥。

`one-file://capture/<会话>/<修订>` 仅允许当前截图窗口的主 frame 访问，刷新、取消或完成后旧资源失效。字体访问须先在当前会话选择已安装字体。退出先执行编辑器关闭确认，再等待已开始的截图输出并取消采集；截图结束后才停止素材与贴图服务，预热窗口的数据等待不会阻塞退出。

复制、保存、贴图输出和素材归档已接通，原图、可编辑标注与历史一起保存；保存取消可继续截图并重试，已完成动作不重复执行。`capture-window-smoke.cjs` 覆盖真实原生来源、权限、标注、输出重试、素材/编辑器/贴图交接、资源撤销与活动截图退出；系统对话框、剪贴板使用测试替身。OCR/翻译宿主已接通，相关窗口链路见本节前的识别验证；完整来源视觉及多屏验收待办。

`src/renderer/capture-view.ts` 按 One 的 page/setup/activate 模式直接挂载普通 DOM，标题动作位于 One 既有页头。保留来源的区域、显示器、窗口、多窗口、全屏、长截图、自由、折线八个模式，以及来源卡片、刷新、主窗口保留/隐藏选项和图片导入入口；长截图连接滚动采集宿主，其余方式连接截图服务。

多窗口组合保留来源的拖动、物理坐标、智能排列、恢复位置、上下层级、撤销、搜索与透明空隙模型；自定义截图保留位置、尺寸、预设及可取消倒计时，配置保存到 `settings.capture.custom`。分段页签、搜索、选择框、数字控件、对话框与弹层使用 One 公共实现，来源卡片和组合布局按功能作用域保存。页面失活使旧来源请求失效，移除组合视图时释放观察器，活动截图由主进程继续管理。

## 长截图服务与控制窗口

`scroll-service.ts`、`scroll-worker.ts` 与 `shared/capture/scroll-*` 保留来源的连续原生采集、滚动稳定性判断、拼接与撤销算法。区域选择复用 One 独立截图层；控制窗口使用 `one://app/index.html?view=scroll-capture`、专用受限 preload、One 外观/窗口控件/对话框。命令检查窗口角色、主 frame、来源 URL 和会话令牌，不安装来源应用的 session 或全局网络规则。

`scroll-host.ts` 负责互斥、素材与图片编辑器交付、退出确认。开始前拒绝与截图/取色/条码框选或已有图片编辑器冲突；退出准备先暂停自动采集、取消待定选区并等待已开始的输出，再确认未保存内容。取消退出后结果可继续编辑；确认退出后才停止截图、素材等服务，避免交付中提前关闭存储。拼接 worker 被等待释放，控制窗口关闭按来源规则进入复查或取消。

15 项业务与宿主检查覆盖算法及等待/取消边界；实际 One 窗口测试验证原生像素、裁边、两帧拼接逐像素输出、撤销、编辑器/素材交付及退出取消/确认。One 窗口 150% 缩放和底栏已检查，多屏/远程桌面与完整来源视觉仍在整体迁移验收范围。

## 素材存储契约

`src/main/materials/library.ts` 接收由调用方从 One 当前 profile 解析的素材根。图片统一保存于 `materials/images/`，包括同一 ID 的 PNG、缩略图、`.oneimage` 及 `index.json`；录制位于 `materials/recordings/<id>/`，保存 `project.onerec`、播放设置与可选缩略图。图片索引身份为 `one-image-materials`，录制标记身份为 `one-recording-material`，版本均为 1。

图片文件和工程写完后才提交索引；索引失败会回滚新文件并保留此前内容。录制工程先经 One 工程元数据校验，再提交状态标记；未提交的录制文件保留且不进入列表，后续恢复与缓存清理阶段处理。索引替换使用排他临时文件、同步与原子替换，不通过先删除旧索引重试。录制播放设置独立更新，已有素材 ID 不允许再次写入原片。

`src/main/materials/service.ts` 已从 One 当前 profile 的 `materials` 目录装配服务，接入 One IPC/preload、操作日志和退出等待；损坏索引会返回明确错误并保留原文件，不阻断 One 其他功能。图片变更完成索引提交后才更新可读状态。没有旧数据扫描、旧格式接管或自动转换；素材 UI 已接入，草稿恢复入口仍待办。

持久化索引不存资源 URL。服务按请求窗口签发 `one-file://materials/<token>/…` 地址；One 既有 session 请求入口校验令牌归属与主 frame，协议入口只读取已登记素材，录制预览复用工程媒体范围读取。窗口关闭、导航、renderer 退出和素材删除会撤销令牌。已有 One 网络与全屏权限规则保留，不安装第二套来源产品 session handler。

`capture-materials.test.cjs` 验证图片原图/历史/缩略图重开、稳定 ID、索引失败回滚、损坏检测、录制播放设置更新、未提交文件保留和旧格式拒绝。

`materials-service-smoke.cjs` 在独立 One profile 验证主进程/preload/资源协议、图片操作、重启、权限边界和退出等待；文件对话框与剪贴板输入为模拟数据，录制字节用于范围读取检查，真实采集和解码仍按后续阶段验收。

## 图片编辑服务

`src/main/capture/image-editor.ts` 保留原图、可编辑文档、撤销/重做历史和保存状态；素材保存、复制、PNG 导出、`.oneimage` 保存/重开及水印图像选择沿用来源业务。`image-editor-host.ts` 已接入 One 窗口创建、角色注册、关闭确认、字体列表、任务等待和素材写入；服务本身不安装独立 session、主题或全局权限规则。退出时先等待编辑操作并确认未保存修改，取消后素材服务和 One 其他功能保持可用。

编辑窗口使用 `one:image-project-*` 与 `one-file://image-editor/<token>`。每次 IPC 同时检查编辑窗口身份、主 frame 和精确 One 页面地址；资源令牌绑定编辑窗口，关闭或失效后不能继续读取原图。图片以受控 CORS 加载，画布可复制/导出。受限 `src/preload/image-editor.ts` 仅暴露编辑能力和公共窗口/外观接口；标注选用的安装字体通过 One 既有字体服务授权，不包含主窗口的设置修改和素材管理权限。

`image-editor-service-smoke.cjs` 在独立 Electron fixture 中验证真实 preload/IPC 和资源读取、其他窗口拒绝访问、原图与标注/历史往返、取消保存、素材目录保护、水印解码、继续编辑/放弃关闭，以及进行中操作失效。文件对话框、复制出口和识别回调使用测试替身。

`image-editor-window-smoke.cjs` 加载实际 One 主程序、编辑 renderer 和受限 preload，验证绘制、文字及字体、水印菜单、素材/PNG/工程输出、重开历史、100%/150% 缩放、禁止删除活动素材和取消退出。原有编辑器业务模块位于 `src/renderer/editor`，重叠控件与弹层使用 One 公共实现；本地同类匹配 worker 由 Vite 构建。当前可从 One 素材页卡片和“打开工程”标题动作创建窗口；OCR、敏感文字识别服务、完整视觉对照和复杂组合仍待后续验证，不能据此宣布完整迁移完成。

## 贴图存储、窗口与管理页

`src/main/pins/host.ts` 从 One 当前 profile 的 `pins` 目录装配服务。`workspace.json` 使用 `one-pin-workspace` 身份及版本 1，拒绝缺失或其他身份；保存图片/文字/文件内容、分组、几何及显示变换。图片以 SHA-256 标识保存独立 PNG，多个贴图可共享同一内容；最后一个引用移除后才回收。素材删除不影响已创建的图片贴图；文件贴图保留原路径，删除贴图不删除原文件。

索引经串行原子提交后更新内存状态，写入失败保留原索引和当前状态。重开恢复分组与变换，默认隐藏并解除鼠标穿透。退出先执行 One 图片编辑关闭确认，再等待贴图任务、销毁窗口并刷新存储；取消退出不关闭贴图服务。

独立 `pin` / `pin-controls` 窗口由 One 创建，受限 `pin.cjs` preload 仅提供当前贴图及公共窗口/外观能力；窗口 IPC 同时验证已登记 owner、主 frame 和精确 One 页面地址。`one-file://pins/<token>` 由 One 唯一 session 请求入口校验所属窗口，关闭或服务停止后不能继续读取。未引入来源应用 session、主题或通用样式副本。

`pins-view.ts` 按 One setup/activate 模式挂载管理页。图片、文字、文件卡片、搜索/分组/显示筛选、多选批量操作及上下文菜单保留来源业务，使用 One 下拉、对话框、提示与弹层。页面隐藏时释放预览观察并关闭弹层，返回刷新最新状态；独立贴图继续存在。标题动作接入文件和剪贴板；素材卡片可直接贴出图片；One 内置页面命令及托盘管理/恢复交互/全体显隐/切换分组已接通。

`pins-workspace.test.cjs` 验证身份、重开、真实原子写入失败、引用回收及缩放几何；`pins-window-smoke.cjs` 验证实际 One 窗口、令牌隔离、素材独立副本、三类内容、旋转/镜像/透明度、原内容复制与导出、分组、穿透恢复、托盘、缩放和重启。文件对话框与剪贴板采用替身；系统文件剪贴板、文件拖出、不同 DPI/多屏、全局快捷键和完整来源视觉对照仍需后续验收。素材页与图片编辑窗口的相邻回归通过。

## 图片容器

容器依次为 8 字节 magic、4 字节小端 JSON 长度、UTF-8 JSON、原始 PNG。JSON 包含 `project`、PNG 字节数及 SHA-256；存在撤销/重做历史时，使用有解压上限的 gzip/base64 字段保存。元数据最多 16 MiB，解压后的历史最多 128 MiB；原图沿用 64 MiB、4,000 万像素、最长边 16,384 像素限制。

`ImageProject` 保留原图尺寸、可编辑标注、自由/多边形选区、裁剪与旋转/翻转变换、输出效果、水印，以及完整撤销/重做分支。新建工程可以没有历史；这不提供旧产品工程读取能力。工程保存要求当前裁剪已应用或取消。

读入验证数据边界、PNG 头、SHA-256 和读取期间文件身份。保存先在目标目录创建排他暂存文件并同步，再检查目标是否变化，最后提交；取消和写入冲突不得覆盖其他写入。现有图片工程的覆盖仅在调用方选定目标且文件未变化时进行。

## 录制容器

容器同样以 magic、小端 JSON 长度、UTF-8 JSON 开始，随后按清单顺序存储原始媒体。每项包含轨道种类、字节数和 SHA-256，流式读写，无需将全部媒体载入内存。元数据最多 64 MiB，每条原始媒体最多 1 GiB；保持来源模型的时长和时间轴上限。

轨道顺序为主画面/声音、可选摄像头、可选系统声音和麦克风。工程保留摄像头布局、键鼠事件、标注时间轴、光标形状与事件、速度、声道增益、GIF 帧及输出设置。独立声源继续校验 48 kHz 双声道 PCM 及样本时长；新格式要求显式提供系统声音和麦克风播放增益，不保留旧版本补字段逻辑。

临时媒体沿用 AES-GCM 分块封存和退出释放能力。保存采用同目录暂存、校验、同步和原子提交，拒绝未经业务流程处理的目标覆盖。打开失败或取消会释放已导入临时轨道；主画面预览仅提供受管理素材解析后的原片字节范围，不将元数据作为媒体返回。

## 验证范围

`node --test tests/capture-image-project.test.cjs tests/capture-recording-project.test.cjs` 通过 One 现有 esbuild/Node 测试入口运行迁入的业务用例和新格式用例，并由 `npm test` 自动发现。

- 图片：原图字节、标注/变换往返、80 次操作的撤销重做、损坏/截断/超限、取消、覆盖竞争及暂存清理。
- 录制：原始轨道字节、系统/麦克风独立声源、错误采样率、范围预览、取消恢复及残留清理。
- 新格式：旧 magic、缺失或错误身份、未知版本均拒绝；同一 One v1 工程包含摄像头、光标、键鼠、标注和 GIF 编辑，重开后修改并再次保存不丢失。

这些验证使用合成样本，只证明模型和文件往返。真实采集、截图输出工作流、页面/窗口接入、播放解码、实际合成导出及安装包资源按迁移计划后续阶段验收。
