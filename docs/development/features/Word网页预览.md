# Word 网页预览

2026-10-11 开发中。DOCX 改用免费开源 `@silurus/ooxml@0.88.0`，后台解析和分页、可见页面按需绘制，替代此前的 HTML 排版与暂停的原生组件原型。选型依据见 [Office 预览库选型](../../research/Office预览库选型.md)。旧 DOC 不属于本次 DOCX 实现范围。

## 实现

- 保留 50 MB 文件和归档展开限额；资源全部本地加载，关闭外部字体及超链接。
- 独立 worker 提取直接或继承样式的标题级别，在内存副本中补入私有书签；不修改源文件。分页完成后将书签映射到页，目录直接跳页，避免每次扫描文字或驱动 Office 组件。
- 页面按需挂载，支持文字选择与页面概览；纸张阴影关闭，概览选中项随当前页联动。概览通过后台 `renderPageToBitmap` 生成缩略图，绘制到缩略画布后关闭 ImageBitmap；不调用仅支持主线程的 `renderPage(canvas)`。正文至少以 2 倍像素密度绘制；DPI 变化时重建页面查看器、保留当前页和缩放。页面纸张大小、字体与原文样式保持文档语义，不通过加粗代替分辨率处理。
- 提供加载、取消、重试和默认程序打开；换文件或关闭时释放查看器、文档和目录 worker。目录准备可立即终止；库的静态 `DocxDocument.load` 尚无 AbortSignal，已开始的该阶段须等返回或超时后释放，不承诺同步中止。

## 验证

`npm run test:docx-preview` 包括目录规则检查与隔离完整 One 窗口。自有连续 120 段、多页样本已验证继承标题、首尾章节定位、错误 XML 提示、再次打开、换到文本、源文件哈希不变和离线加载。扩展检查中 9 个 worker 均终止；隐藏窗口的自动化跳转等待不代表前台操作耗时。

证据位于 `work/current/office-preview/docx-integration/results.json`。125% 显示缩放下页面 CSS 宽度 1066、实际绘制宽度 2132，达到 2 倍密度；模拟 2.5 倍 DPI 后重新绘制并保留目录页，目录 worker 准备中取消通过。实际概览页签验证了 270×382 缩略图含非白色文字像素，并可点击导航；样本目录从真实点击事件到目标文字就绪约 54 ms，该数值仅代表本轮自有样本。对照截图确认文字正常显示，但自有样本不能证明用户文档的全部字体与清晰度表现。真实复杂 Word 排版、字体替代、图表和高倍率缩放仍待验收；不宣称与 Word 像素一致。

2026-10-11 补验用户的两份实际文献 DOCX：分别分页为 1 页与 3 页，16 段与 46 段非空正文均在逐页浏览中找到，所有页面概览含有效文字像素且可跳转。125% 显示缩放下，后台绘制完成的正文画布均为 2 倍像素密度；首次看到的 1 倍画布是尚未提交位图的空白初始画布，不能当作正文清晰度结果。人工检查第一页文字显示正常。无页面错误，源文件 SHA-256 不变；证据位于 `work/current/office-preview/real-documents/word-results.json`，用户文件与截图不入版本库。
