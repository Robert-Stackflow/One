# XLSX 网页预览

2026-10-10 开发中。原生预览加载与目录体验未通过用户验收，当前源码将 `.xlsx` 切换到免费开源 `@silurus/ooxml@0.88.0` 的现成查看器。无需本机安装 Office；库负责表格画布和交互，One 不重写网格。选型及样本限制见 [调研报告](../../research/Office预览库选型.md)。

## 当前实现

- 主进程检查文件大小（50 MB），在已有预览 Worker 中校验归档：最多 20,000 项、单项 32 MB、解压合计 128 MB，并检查工作簿入口文件。预检有 15 秒超时。
- 通过当前窗口拥有的 `one-file:` 地址读取文件，库使用本地打包的 WASM 和 worker。关闭在线字体和外链跳转，保持原有 CSP，不新增普通 `unsafe-eval`。
- 解析一次并复用 `XlsxWorkbook`，交给 `XlsxViewer.fromWorkbook` 展示。先检查首张可见工作表的 `parseError`，切表时继续检查，避免把诊断页当作成功。
- 工作表标签及 One 目录只列出可见表，显式设置 `hiddenSheetMode: 'skip'`，目录激活入口也检查可见性。库直接跳表 API 本身允许隐藏索引，不将其当作权限边界。
- 保留现成工作表切换、选择、复制、滚动、冻结与缩放，关闭列宽调整；库界面颜色继承 One 外观，单元格保持文档格式。
- 提供加载状态、取消、失败重试与默认程序打开。切换文件或关闭时撤销读取并销毁查看器/文档；失效异步结果不会重新挂载。
- 静态 `XlsxWorkbook.load` 没有 AbortSignal：取消时界面立即退出，已开始的解析在结束或库内超时后销毁，不能宣称后台 worker 一定同步终止。继续评估更快的中止路径。

## 本轮验证

`npm run test:xlsx-preview` 会生成自有文件，在独立输出目录构建主进程预检、完整 renderer 和查看器探针，再用隔离 Electron 窗口、实际 `one:` / `one-file:` 协议验证：

- XLSX 路由及空工作簿；损坏 ZIP、缺入口和超过 50 MB 的文件被拒绝。
- 中文、合并表头、前导零、金额、缓存公式与错误值；隐藏工作表不会进入标签或目录，目录可切到最后一张可见表。
- XML 损坏的诊断提示、加载失败后的恢复、加载中取消与再次打开；关闭后 DOM 清空，本轮 5 个 worker 创建并终止。
- 原有 CSP 下无页面异常、无外部请求。类型检查和隔离生产 renderer 构建通过，所需 WASM/worker 已生成。

记录位于 `work/current/office-preview/integration/results.json`。探针调用实际源码组件和主进程预检，不等于完整 One 预览窗口、真实用户文件、前台滚动帧率或安装版验收通过。隐藏窗口的取消检查直接触发实际按钮处理，避免把后台动画帧调度当成响应时间测量。

`npm run test:xlsx-window` 另行启动隔离的完整 One 应用，使用实际主进程、预加载、文件路由和预览界面。已验证顶栏/底栏 tooltip 与统一 toast 位于工作簿上方、主窗口设置驱动深浅色同步、侧栏切换可见工作表、下一文件导航、切到文本后 worker 全部释放，以及窗口缩放和关闭。测试等待颜色过渡结束，避免把动画中的旧色判为失败。记录位于 `work/current/office-preview/window/results-1.json` 和 `results-1.25.json`；100%/125% 缩放通过。运行中窗口保持隐藏，未测前台输入延迟或多显示器切换。

## 剩余范围

更多 DPI 与跨显示器场景；真实复杂表格及图表；大表响应与中止；筛选等交互。当前采用主线程绘制路径，worker 绘制的研究样本仍有主线程长任务，未据此承诺不卡顿。

XLSM/XLTX/ODS 继续使用现有路径，旧 XLS 单独评估。Word/PPT 的替代引擎尚未接入；[原生宿主记录](原生表格预览.md)保留作此前试验的证据。
