# One

One 是一款面向 Windows 的桌面工具箱，集中提供文件处理、搜索与预览、系统检查和日常操作增强。应用基于 Electron，主要操作在本机完成，无需账户。

## 安装与开始使用

从交付的 `One-<版本>-Setup-x64.exe` 启动安装。安装器可以更改安装位置；升级时会保留现有设置。若 One 正在运行，先按安装器提示退出，再继续安装。

首次使用可以按下面的顺序操作：

1. 打开 **文件搜索 → 索引**，添加希望搜索的文件夹。程序、系统设置和 One 命令不需要文件索引。
2. 按 `Ctrl+Alt+F` 打开命令面板，输入名称搜索；输入 `>` 只查看 One 命令。命令面板快捷键可在 **文件搜索 → 搜索** 中修改。按 `Ctrl+Alt+O` 可打开主窗口。
3. 在 **设置 → 基本设置** 调整关闭窗口后的行为；默认关闭主窗口后仍驻留托盘。**设置 → 备份** 可以导出或导入设置。

安装包和可运行目录是两种不同的产物。自行构建安装器使用 `npm run package:installer`，输出到 `work/installer-output/<版本>/One-<版本>-Setup-x64.exe`。`npm run package` 生成 `release/<版本>/win-unpacked/` 目录；使用目录版时须保留整个文件夹，不能只复制 `One.exe`。

## 功能

| 分类 | 主要功能 |
| --- | --- |
| 文件 | 重复文件查找、文件和目录比较、批量重命名与撤销、文档全文搜索、空间分析、文件占用检查 |
| 搜索与预览 | 文件索引与命令面板、资源管理器快捷入口、右键复制文件路径；预览图片、音视频、PDF、Office 文档、代码、Markdown、表格和压缩包等 |
| 系统 | 启动项与注册表检查、磁盘清理与容量告警、写入活动、端口与服务、硬件和网络信息、代理与网站连通性检测、DNS 快速检查 |
| 操作增强 | 鼠标连点、边缘操作、快捷音量与复制粘贴、按键提示、唤醒、窗口置顶、屏幕取色和屏幕尺 |
| 设置 | 外观与字体、托盘和开机启动、管理员模式、设置备份与恢复 |

系统右键菜单和资源管理器集成可在 **设置 → 基本设置** 管理。文件占用、系统维护等操作可能需要管理员权限；以管理员身份运行时，Windows 不允许从普通权限的资源管理器向 One 拖入文件，按需使用设置页的权限切换入口。

在文件搜索结果上右键可以复制完整路径、相对路径、文件名或带引号的命令行路径。相对路径优先以最深的已索引目录为基准；文件不在索引目录内时，相对于其所在文件夹。屏幕尺在 **屏幕取色** 页面启动，默认使用不抢占原窗口焦点的实时画面模式；点击旁边的下拉箭头可切换到聚焦测量层的静态画面模式。拖拽测量，按 Esc 退出。**系统信息 → 代理** 的 DNS 检查会分别向系统配置的 DNS 服务器查询 A、AAAA 和 CNAME 记录，并显示响应时间。

设置与索引保存在用户配置目录 `%APPDATA%\One`。导出备份只包含设置，个人文件和索引数据不会随之复制。代理页的公网出口和网站连通性检测会向所列网站及 IP 信息服务发起网络请求；其他文件处理不需要将文件上传到服务端。

## 从源码运行

开发环境为 Windows x64、Node.js 22。完整构建还需要 Visual Studio 2022 Build Tools（MSVC x64 与 Windows SDK）和 Rust MSVC 工具链；最终用户无需安装这些编译工具。

```powershell
npm ci
npm run dev
```

开发模式使用独立的 `work/dev-profile`，不会修改正式版设置。界面修改会自动刷新；原生 C++ 或 Rust 代码修改后需要重新构建。完整构建或打包前，请先退出正在运行的 dev 实例，以免原生辅助程序占用构建文件。

常用检查与交付命令：

```powershell
npm run typecheck
npm test
npm run check:docs
npm run verify -- proxy-information-smoke
npm run package:installer
```

`npm run package:installer` 会构建主程序与 Electron 安装界面。只需要可运行目录时使用 `npm run package`。`dist/`、`work/` 和 `release/` 是可重新生成的本地目录，不纳入 Git。
