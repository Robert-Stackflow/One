# One

Windows 本地工具箱 One 0.16.15，基于 Electron，项目位于 `D:\Repositories\One`。

本页概述当前源码能力；标注为开发版的改动尚未进入上述发布包。使用说明和开发资料统一见 [文档导航](docs/README.md)。

## 运行

本次发布包位于 `D:\Repositories\One\release\0.16.15\win-unpacked`，打开其中的 `One.exe`。请保留整个 `win-unpacked` 目录，不能只复制 EXE。旧版运行时先从托盘退出旧版，再启动新版。

默认关闭主窗口后驻留托盘，可在“设置 → 基本设置”更改；`Ctrl+Alt+O` 打开主窗口。配置保存在 `%APPDATA%\One\settings.json`，升级会补齐新增设置。软件不要求账户，文件与文字在本机处理。

## 开发与缓存

源码、测试和说明使用 Git 管理；`node_modules`、`work`、`dist`、发布目录和本地环境配置均不入库。日常通过 Electron 开发模式检查界面，发布时才生成交付包，不再为每个小改动复制整个构建目录。

`npm run dev` 启动开发窗口，界面代码和样式更新后自动刷新，主进程/预加载更新后正常退出再启动；原生 C++/Rust 改动需重新运行开发命令。开发配置固定保存在工作区的 `dev-profile`，不修改正式版配置。

`npm run verify -- file-tools-smoke` 等验证复用 `D:\Repositories\One\work\current`（可用 `ONE_WORK_ROOT` 调整），保留结果与截图，测试结束后清理生成的隔离配置。`npm test` 也会在结束后清理单元测试样本。`dist` 只保留当前一次构建，开发时清理过时的界面文件，可随时从源码重新生成。

`scripts/clean-generated.ps1` 默认仅列出清理计划；`-Apply` 执行，`-AllWork` 额外清理历史工作目录和当前可重建的 `dist`，保留一份 Rust 编译缓存及少量验证记录。发布包只保留最新两个可运行版本，统一放在 `D:\Repositories\One\release`。验证结束后最多保留 20 组记录、128 MiB 记录与截图；共用样本缓存最多 192 MiB，超限重建，不累计小版本工作副本。

使用 `Ctrl+Alt+F` 搜索文件、系统已注册的程序和 Windows 设置。程序与设置无需添加索引目录；搜索文件时先添加索引目录。资源管理器直接输入、双击菜单、文件对话框 Ctrl+G 和双按 Ctrl 各自开启，默认关闭，避免与现有 Listary 同时响应。One 不修改 Listary 或 TextPro 的设置。

预览的图钉控制置顶，“保持窗口”采用鼠标指针框图标，选项与栏宽自动记忆。默认失去焦点关闭；保持后可继续阅读。左栏切换文件/详情/目录；没有标题目录时隐藏目录页签。PDF/DOCX/PPTX 另有页面概览，正文可直接连续滚动，缩略图按需加载。文件夹单击预览、双击进入。文件图标直接使用 VSCode Icons 扩展的官方 SVG。JSON/YAML 默认源码，支持格式化与结构树；代码文本最多 50 MB，连续滚动与全文查找。音视频自动播放、关闭停止；音乐支持嵌入封面和 LRC/内嵌歌词。打开按钮右侧列出 Windows 推荐应用及应用自身图标。

字体预览只保留一个正文滚动区，字号栏固定。预览左栏在浅色模式使用纯白；详情以文件标识和信息列表组织，复制路径与查看占用统一放在标题栏右上角“更多”菜单。标题栏只显示文件名，不重复显示文件类型。

“用空格快速预览”开关统一位于“快速预览”页面，修改后立即保存；页面不再展示格式说明列表。导航、标题、按钮等界面文字不可选；输入框、代码、文档正文和可复制的详情仍可选择，Ctrl+A 仅作用于当前内容区域。

“设置 → 外观 → 字体”可选择 Windows 已安装字体，支持中文/英文名称搜索、样张预览和刷新列表。选择后立即保存并应用到各窗口；字体卸载后使用系统默认字体。 字体列表方向键只滚动列表，样张更新合并到绘制帧；共享下拉框跳过禁用项，支持空列表提示及打开期间更新当前选择。数值控件不会因重复初始化出现多层边框。

所有设置修改后自动生效，无需手动保存。文件搜索分为搜索、索引和快捷菜单三个页签；快捷菜单支持五层嵌套、拖动调整层级、即时编辑和 Lucide 图标选择。

独立搜索窗口未输入时是一条靠上居中的搜索栏；输入后展开到约 560 px 高，结果在固定区域滚动，清空后收回。资源管理器附着搜索采用更紧凑的输入与结果布局，结果使用自定义文件右键菜单，包含打开、预览、打开方式、定位、复制/剪切、复制路径、重命名和回收站；其他系统操作保留在“更多系统操作”入口。打开方式在独立子菜单中展开，菜单按内容调整高度，只有超过屏幕上下留白的可用高度时滚动。快捷菜单各层在独立浮窗中展开。搜索输入提前准备并复用；菜单按使用时机准备，隐藏闲置 45 秒后回收，下次使用自动重建。桌面文件列表也可触发。

文件工具的结果区域随窗口剩余高度伸缩；较短窗口共用整页滚动，避免两层滚动条。共享页签支持方向键、Home/End，Tab 只停在当前选项；重复组支持上下键浏览，窄窗口可返回当前重复组。

文件名称索引共享原始路径的检索存储，通过大小写标记保留显示拼写；特殊 Unicode 和路径形式保留完整原文。重新扫描和大小写重命名延续共享关系，缓存格式保持兼容。

概览、系统信息与写入活动在窗口隐藏或最小化时暂停展示采样，重新打开自动恢复；后台容量告警与主动文件跟踪仍按设置运行。索引缓存加载后即可搜索，离线目录校验按索引范围分批进行。

批量重命名的自动预览和全文搜索的待发查询在离开页签、离开文件工具或隐藏/最小化窗口时暂停等待，返回后按最新输入恢复；单纯失焦不会重复扫描，已经手动启动的任务继续执行。文件工具在不可见时只缓存进度与完成结果，返回后恢复；旧查询不会覆盖新输入或清空后的页面，未变化的重复文件结果保留选择和列表滚动位置。

PDF 查找覆盖全部页面，展示扫描进度并可随时停止；修改或清空关键词不会恢复旧结果。连续阅读按需绘制并复用页面画布，离开缓存的页面释放绘图资源，返回时重新绘制。

JSON/YAML 结构树按需读取属性，只绘制当前可见行，取消 6,000 节点上限及“显示更多”分页。支持方向键、Home/End、折叠、复制路径和长值连续阅读；循环引用明确标注。默认仍显示源码，结构解析沿用 5 MB 限制。

CSV/TSV 表格由后台解析，保留完整行列并连续滚动，只绘制可见区域。支持 A1 形式的单元格定位、方向键、Ctrl+Home/End、完整复制，以及长值弹窗；引号内逗号和换行、UTF-16 与不等长行均保留。表格视图沿用 5 MB 限制，较大文件使用连续源码视图。

## 使用说明与边界

完整说明、开发规则和历史验收见 [文档导航](docs/README.md)。

搜索采用目录扫描与变更监听，未使用 NTFS MFT/USN；支持拼音、模糊匹配和自定义菜单命令。文件名称搜索与“文件工具 → 文档全文搜索”的正文索引分别使用；未实现 Listary 全部功能。标准 Explorer 和打开/保存对话框是当前集成目标，自绘对话框、复杂 IME、多标签和混合 DPI 场景仍需继续验证。

文本处理上限 1,000 万字符；编辑器连续滚动且仅渲染可见行，转换/复制/保存操作针对全文；导入和手动编辑保留原换行格式，文本操作可能按各自规则统一换行。TextPro 的专有字表、古籍规则及全部替换语法未完整迁移。Office 预览支持基础内容，复杂排版、图表和动画存在限制；不会执行宏、脚本或 Notebook 代码。

文件占用扫描报告权限不足与超时，不将未完成的检查视为没有占用。当前没有系统右键 Shell 扩展和提权重启按钮。结束进程需要确认，并校验目标身份。

发布包未签名，验证环境为 Windows 11 x64，尚未进行独立干净机器安装验证。硬件音量/亮度测试只读取状态，未修改用户当前值。取色为 SDR 8 位采样，HDR/广色域未验证。

## 开发

```powershell
npm ci
npm run typecheck
npm run check:docs
npm test
npm run build
node scripts/regression.cjs
npm run package
```

当前使用 Node.js 22。Windows 原生辅助进程需要 Visual Studio 2022 Build Tools、MSVC x64 与 Windows SDK，另需 Rust MSVC 工具链（本机 rustc 1.97.1）；使用静态 CRT，发布包已包含辅助程序，最终用户无需安装编译器或 PowerToys/Listary/TextPro。

索引缓存保存在 `%APPDATA%\One\file-index.bin`。新版只保存压缩后的路径、类型和目录时间，不重复存储名称、小写路径或拼音。变更追加到有界 `.delta`，达到阈值后合并；最多一份 `.tmp`，不再为每次变化生成新临时文件。正式缓存上限 512 MiB，增量日志上限 8 MiB；写入前检查空间。空间分析只使用内存，不生成持久索引。

启动后立即加载缓存，通过目录时间校验离线变化；只重新枚举变化目录，新增子树按需扫描。新增、删除、重命名实时更新；仅修改文件内容不重写名称索引。更改索引范围/上限或手动“重新扫描”会完整校验。旧版缓存首次启动会自动重建，并清理已识别的旧版临时文件。性能实测及限制见 [0.9 验收](docs/history/验收-0.9.md)。

发布包回归可设置 `ONE_PACKAGED_EXE` 为完整 EXE 路径后运行 `node scripts/regression.cjs`。测试使用隔离配置，不更改正式用户配置。

新的预览回归使用 `node tests/preview-sidebar-smoke.cjs`、`node tests/preview-redesign-smoke.cjs` 和 `node tests/preview-performance-smoke.cjs`；视频样本生成另需开发机安装 FFmpeg，最终用户的播放不依赖它。

图标提供 SVG、15 档 PNG 和 13 帧 ICO，位于 `assets/icons`。历史实现不参与当前构建。第三方许可见 `THIRD_PARTY_NOTICES.txt` 及随包 Electron 许可文件。
